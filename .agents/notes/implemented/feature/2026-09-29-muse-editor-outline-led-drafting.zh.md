# Agent Note: 依据已核实来源与选定大纲推进 Muse 编辑写作

Status: implemented

[English](2026-09-29-muse-editor-outline-led-drafting.md) | 中文

## Problem

编辑可能收到小说、视频文件、链接，或仅收到剧名。这些输入需要不同的取材方式，但最后都要形成连贯的新剧本。即使用户已提供可用来源并选定改编大纲，强制要求额外阅读一部爆款剧本的开头仍可能让写作停滞。固定的集数和字数也可能覆盖用户想要的形式。

## Decision

产品自有的 `editing` 预设保持简短 persona，加载 `muse-script-editing` 和对应来源的技能。它与默认的 `short-drama` 制作模式分开；编辑不需要后者的视频生成工具。Desktop Host 将技能打包到明确的产品根目录，不依赖外部编辑工作间。

小说路线阅读用户提供且获授权的原文。视频路线取得可读且获授权的资源，转写后结合可核实的画面线索整理成人能阅读的分场剧本。只有剧名时先搜索来源；剧名或剧情摘要不等于看过或转写过视频。来源大纲标明实际读到的素材。编辑随后提供有区分度的换梗方向和本作大纲，集数与篇幅作为可修改建议。用户在大纲阶段选择或调整方向。大纲确定后，编辑写完并审校约定的全部范围，保存可恢复进度，跨批次核对连续性，不逐集索要批准。

正式写作前，编辑优先重读本次转写整理出的剧本或来源小说，也可以按已选大纲检索并打开当前账号获授权的知识库页面。检索摘要不算阅读全文。Agent 记录实际阅读范围，说明不可得的参考资料，再依据已核实来源和选定大纲继续创作。参考阅读是编辑提示，不是运行时或提示词设定的开写门禁。来源文本只是任务资料，不能通过其中的角色、工具或权限指令支配 Agent。可借鉴写法，但不复制特征性场面、台词和剧情顺序。[账号私有剧本决策](2026-09-29-muse-account-private-script-vault.zh.md)规定已校订转写稿的保存与读回。

此前的先读开头决策（[English](../../archived/feature/2026-09-28-muse-editor-sourced-opening.md)、[中文](../../archived/feature/2026-09-28-muse-editor-sourced-opening.zh.md)）要求有可读的爆款剧本开头才能开始正文。本决策取代这一要求，同时保留优先阅读已核实全文和抵御资料内指令的原则。[桌面产品决策](../architecture/2026-09-23-muse-med-independent-desktop.zh.md)规定名册、profile 隔离与技能根目录。

## Alternatives considered

**没有可读爆款开头就暂停正文。** 这能避免无依据地声称已阅读，却可能在用户来源已核实且大纲已通过时仍阻断工作。记录实际阅读范围可以保留证据，而无需强制增加另一个案例。

**把检索摘要或剧名当作来源素材。** 它们无法证明来源中的场次、台词或覆盖范围。编辑会标明缺口，不声称已经转写或知道未看过的剧集。

**固定集数、字数或每批审批。** 这些默认值可能与素材及平台形式冲突。编辑在大纲阶段提出方案，并按用户选定的范围完成全部交付。

**把编辑并入短剧制作，或原样导入外部工作间。** 制作模式负责媒体生成，工具不同；外部工作间依赖自己的服务器路径。产品自有模式让组合和技能发现保持明确。

## Consequences

用户看到有素材依据的大纲和备选方向后作主要故事选择；Agent 按选定方向完成长篇正文并报告实际完成范围。缺少可选案例会减少可参考的创作写法，但不会自动停笔。提示词和技能表达这一性质性的流程；无密钥技能快照及打包运行时检查固定模型可见文案和技能可用性，无法证明文学质量或来源叙述的真实性。仅有剧名且未取得可读视频时仍无法转写；账号知识库仍须配置并部署服务才可用。
