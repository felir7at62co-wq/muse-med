# Agent Note: 剧变模型意图与免费范围配置

Status: implemented

[English](2026-09-21-jubian-model-intent-and-scoped-settings.md) | 中文

## Problem

固定的 Seedance 2.0/720p 选择器会拒绝控制台已配置为 Seedance 2.5/480p 的分镜，也可能替换成操作人没有选过的模型。缓存的选择器 ID 还可能与当前账户目录不同。让调用方拼装请求体批量修改分镜设置，存在改变主体身份或触发生成的风险。

## Decision

实时分镜提供模型、已指定的平台、生成类型、比例、分辨率和时长意图，实时视频目录提供选择器 ID。准备必须精确匹配唯一结果，拒绝歧义与未知时长能力，并保留单条生成、主体身份顺序、项目、指纹及单次 PUT 检查。精确模型 ID 对应的时长表保留现有 2.0 上限，记录操作人确认的 2.5 最长30秒；该上限不声称经过提供方验证，也不泛化到其他模型。不解释未经确认的目录时长字段。

`jubian_model` 把远端只读预览与免费应用分开。本地冻结计划明确列出已有分镜，可按分镜逐个选择、按远端分集 ID 选择，或覆盖一个项目。应用在写入前核对项目绑定、计划指纹、实时成员、设置与保留的非模型数据，并在每个 PUT 前立即回读目标。每次 PUT 强制 `isGenerate=0`。回读检查设置及保留字段，包括有序资产；[已保存 isGenerate 的决策](../bug-fix/2026-09-19-jubian-storyboard-isgenerate-not-a-gate.zh.md)仍独立适用。已有视频及项目默认设置不变。

账本记录整个操作和逐目标尝试。部分完成或结果不明时停止后续写入；重复调用要求已记录的方法和批次请求身份一致，只核对已记录目标，不会继续部分应用的计划。同一运行时里共享已解析账本根目录的申领会串行执行，包括不同账本实例，记录身份共享同一个进程级后缀。这不提供跨进程事务或远端比较并交换能力。

去字幕阶段标记不是成功证据。读取器要求成功的去字幕记录指向当前可用文件；仅仅 URL 不同也不能表示转高清，因为去字幕同样改变 URL。这些元数据检查不能替代字幕视觉审核，也不会修复此前已选入的渲染源。

## Alternatives considered

**保留固定模型和分辨率。** 这与操作人已保存的意图相冲突，也会使提供方支持的设置无法使用。

**选择首个匹配的目录行，或接受未知时长上限。** 平台歧义可能改变预期生成通道，臆测时长上限则可能提交不受支持的收费请求。

**把保存设置与生成合并。** 检查批量配置不应购买视频。生成继续使用独立的准备、提交和对账流程。

**失败后自动重试或回滚批次。** 结果不明时目标可能已经改变；回滚可能覆盖期间操作人的修改。逐目标结果与显式对账保留这种不确定性。

## Consequences

工具展示准确的前后设置并拒绝陈旧预览，但合法的中途修改也需要重新预览。不受支持的模型必须补充有依据的时长能力后，才能用于准备或配置应用。提供方没有覆盖整个项目的事务，因此批次可能部分应用，不声称原子完成。

定向 API 测试覆盖模型规格精确匹配、ID 更新、歧义、2.5的30秒及超限拒绝。工具测试覆盖免费 PUT、项目绑定、目标变化、资产顺序保留、超时、重复调用及同运行时并发；Loader 测试固定模型可见输出与卸载行为。已有收费提交测试保留身份及单次发送覆盖。这些检查不包含提供方收费请求。
