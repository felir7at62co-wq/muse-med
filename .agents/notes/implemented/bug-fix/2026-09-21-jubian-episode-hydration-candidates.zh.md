# Agent Note: 按集限定剧变任务补充读取候选

Status: implemented

[English](2026-09-21-jubian-episode-hydration-candidates.md) | 中文

## Problem

剧变任务列表即使指定项目，也可能返回整个账户。项目 2708 有 101 个没有分镜 ID、但带有集 ID 的视频任务。逐一补充读取所有项目任务会超过 100 个候选的安全上限，即使目标集只有少量任务。

## Decision

原生提交和对账仅在 preview 与任务都声明有效正整数集 ID、且两者不同时，才在补充读取前排除该任务。数字字符串与数值指向同一集。ID 缺失或格式无效的行仍为候选。完整分页快照、重复检测、读取上限、身份检查和最多一次 PUT 的账本均保持不变。

## Alternatives considered

**提高或移除上限。** 这会增加没有明确边界的读取工作，却未利用现有归属证据。

**丢弃集 ID 不匹配的所有行。** 缺失或无效 ID 不能证明任务属于别处；丢弃它们可能隐藏已有提交。

## Consequences

其他集不占用目标集的补充读取额度。匹配或归属未明的候选超过 100 个时仍安全拒绝。原生测试覆盖含 101 个其他集任务的提交和重放、仅一次 PUT，以及 101 个同集或归属未明候选时的拒绝。不需要更改传输或账本格式。
