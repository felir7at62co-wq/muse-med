# Agent Note：剧变缺少预算文件时拒绝计费写入

Status: implemented

[English](2026-09-23-jubian-missing-budget-denies-paid-write.md) | 中文

## Problem

新安装中没有 `<账本目录>/authorization.json`。预算检查此前将计费请求标为 `unauthorized`，但共享写路径仍会记录 intent 并发送给提供方。组员可能在配置项目额度前就产生费用。

## Decision

既没有项目授权文件，也没有已组合的短剧整剧设置提供上限时，`checkBudget` 返回 `refused`。组合短剧设置命名空间后，即使没有设置文件，其默认值也会按 `script_id` 自动提供人民币上限；已有授权记录只可降低上限，已有文件缺少所请求项目时仍拒绝。共享的 `writeUnderLedger` 路径在记录 intent 或发送请求前拒绝该结果；不计费的写入不受影响。没有可用报价或操作人认可的估算时同样拒绝。[短剧制作决策](../feature/2026-09-21-drama-policy-and-result-evidence.zh.md)记录的是另一项运营者本地预设策略，不是执行器级别的授权。

提供方结果为 `unknown` 不能证明没有扣费。任何没有可用报价的计费记录都会阻止其所属项目下一次计费认领；缺少项目归属的计费记录会阻止共享该账本的所有项目。已知项目之间保持隔离。这些检查读取既有账本字段，不需要变更格式或迁移。

## Alternatives considered

**缺少文件时警告并提交。** 首次请求本身就可能收费；提交后才显示无上限状态，对新用户来说太晚。

**把可写文件当作人的同意。** 有文件写权限的 agent 可以修改它。额度可以限制意外的重复消费，却无法验证组员本人已同意；若共享多用户部署声称按归属人授权，则还需要单独认证归属人。

## Consequences

新用户可以进行免费读写。组合短剧设置后，每剧默认预算无需另点确认，即可放行有报价的计费调用；既没有该设置，也没有手工额度时拒绝收费。这改变了此前无上限也可收费的行为。可编辑的文档不是安全边界。共享写路径在同一进程的账本队列里预留已认可的报价或估算，但另一个进程不共享这把锁；因此仅有此改动还不足以让组员安装包开放收费操作。单元和共享写路径测试验证没有预算时既不请求提供方，也不写账本记录。
