# 分集设计方法

以实际来源、用户保留要求和已定大纲为依据，围绕人物选择、事件因果与情绪落点安排集界。小说章节和字数只帮助定位与观察篇幅，不直接决定集数。

已有分法能覆盖来源、情绪落点与承接时直接沿用，不为另一套同样可行的集尾反复推翻。分集只确定支持开写的剧情起止与依赖，不在这里逐场试写完整对白；实际对白、动作和反应在正文稿中打磨。发现明确的遗漏或因果、集界问题时才调整受影响部分。

## 找到剧情单元

识别人物此刻想得到什么、受到什么阻碍、如何选择，以及结果怎样改变信息、关系、资源或危险。把相互依赖的事件组织为有推进、有回报的单元；若一集只重复相同压力或已知结果，考虑合并，若多个转折未展开则保护必要过程再拆集。安静相处、坦白感情和余波也可以承担剧情功能，不强求每集争吵、掉马或反转。

每场让目的、策略、对方回应与局势变化成立，不把大纲写成轮流解释，也不用机械短句或堆动作制造互动。对白、动作与 OS/VO 沿共享写作品质处理。

## 结尾与下集

钩子落在实际动作、对白、选择代价、关系变化或逼近的危险上，保留本集应有的结果与情绪回报，不把整场戏截断来掩盖内容不足。明确观众还在等什么，下集怎样推进或兑现。

钩子属于本集已经发生的正文。下集从实际结束状态继续，已取出的物件、已宣读的信息和已完成的行动直接接后果，不重置后再演一次。必要短接续或有新信息的回忆可保留，不用文字相似度判断剧情是否重复。调整边界时同时处理相关两集，核对人物位置、在场人员、知情、时间、道具与情绪是否接得上，必要时追到受影响后续。

长剧沿既有记录追踪影响后续的伏笔、人物状态与道具流转，标明集场和版本；只更新本轮改变的依赖，不为短稿每个动作建立记录。

## 篇幅与落稿

篇幅沿用户实际要求，没有长度目标时不另建字数统计任务。素材不足先查遗漏、过度压缩和原有冲突可展开的过程，不能用重复解释、长 OS 或新支线补差。无法兼顾约定与素材容量时反馈具体缺口、依据和调整选择，继续完成不受选择影响的部分。

用户只要成稿时直接落实正文，不另造重复方案；用户需要独立方案或长剧需持久记录时保存剧情起止、变化、尾钩及后续依赖。拆合已有稿说明集场对应和未落实范围，不把方案当成完成稿。修订、回读与修改说明沿共享写作品质，不重复执行审校清单。
