# Muse 分集设计

[分集方法](references/episode-workflow.md)用于设计或调整分集。以原作故事为基础，沿用用户已定剧情与项目要求；用户只要成稿时，将方案直接落实到正文，不另造一套重复的方案交付。

中文分场格式、写作品质与时间线规范见 `screenplay-format`。相关资源按该技能返回的实际 `resourceBase` 定位，不从本技能目录拼接其他技能的路径。

[来源与许可证](references/sources.md)说明参考资料和适配范围；`upstream/` 只保存溯源原件，不作为执行指令加载。
