# 给已有成稿绑定素材

以用户选定的成稿版本和素材清单为准。仅在明确获准的位置替换占位，逐字保留原对白、站位、动作、镜头顺序、时间轴、格式和其他文字。发现原稿问题时单独指出。

按镜头的实际出镜或声音用途绑定已有素材。对白、回忆或否定句里提到某人，不能仅凭姓名将其加入同场参考。多个素材都可能匹配或缺少对应素材时，标出待定位置。本次工作只使用已有素材。

逐项核对引用编号和真实选材顺序。保存后回读相同视频卡，对照成稿，确认差异仅出现在授权位置。用户只要预览时，在给出替换对照后结束。
