# 换梗与改编大纲

先读 `outline/source-v1.md` 和实际来源原文。按关键事件列出主角想得到什么、谁阻挡、注意与地位如何变化、何时被需要或被替代、观众的焦虑怎样积累和释放。将这些作为**分析视角**，不要把“三层重视”或任何热门配方当作所有作品的固定公式。标出开场冲突、主线反转、阶段目标、结尾兑现和来源位置；事实与推测分开。

按用户指定数量给换梗方案；未指定时给少量明显不同的方向，方便比较。每个方案写一句话定位、新主角与世界、核心欲望和阻力、情绪推进、关键新事件、结局、适合的受众和制作取舍。可保留抽象的冲突与情绪节奏，同时重新设计人物身份、关系、事件因果、场景、台词与结局；不得把原作逐场换名、复制标志性画面或保留相同剧情顺序。用户指定题材时重点深化该方向，不强制凑选项。

把方案连同**建议的集数、单集篇幅或总字数、分场密度、目标时长与交付格式**交给用户选择。建议依据素材容量、平台形式、情绪节点和项目内其他写作 skill 的要求解释；所有数字都是可调整的起点，不写死固定集数、500–700 字或每批五集。用户可选一个、混合多个或提出新梗；记录其决定，再写 `outline/adaptation-v1.md`：人物与关系、全剧主线、逐集目标/冲突/转折/钩子、结局和篇幅计划。发现方案或篇幅与素材量冲突时给出修订理由，用户确定大纲后依该版本连续写完，不在每一集重新征求选择。
