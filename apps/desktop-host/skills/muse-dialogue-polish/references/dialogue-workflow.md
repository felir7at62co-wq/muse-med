# 白话对白与场景精修

## 读取范围与修改依据

读用户要改的场景、当前版本及已提供的前后剧情。记录稿件路径或版本、集数、场次和实际已读范围；只读片段时仅评价片段，不声称完成全本审校。人物动机或前情缺失时，先从已有材料查找，仍无法确认的内容列为待核实，不用新设定补齐。

明确本场发生了什么、观众需要知道什么、哪些关系或决定在场后改变，以及用户要保留的佳句和固定内容。区分来源事实、已批准的改编设定与待定意见。保留事件结果、人物关系、时间地点、角色掌握的信息及信息揭示顺序；授权的文字润色可以直接完成，需要新事件、新证据或改变剧情方向才能修好的问题列为未解决项。

忠实视频转写按 `screenplay-format` 整理，只修排版与有依据的错字，说话人或词句不明时标记待核实。用户授权再创作后，在其指定范围内应用以下方法；不能把精修指令当作补写来源事实的授权。

## 人物与交锋

对每位说话人明确：此刻想从对方得到什么；已经知道什么、还不知道什么；哪些话不愿说出口；会用什么方式争取目标。这些判断从稿件与已定人物设定提取，不给角色临时添加秘密或背景。

逐轮检查对方上一句带来的信息、压力或机会，本句如何回应，以及回应是否改变后面的说法或行动。避免双方各说各的、重复交代观众已知内容，或轮流发表同一种立场。让解释进入当前争执、试探、求助或协商；确有必要的信息直接讲清，不为制造潜台词藏掉情节所需事实。

区分声口时先区分策略：有人追问事实，有人辩解，有人岔开问题，有人要求立即行动。结合其与对方的关系、职业和当前情绪调整用词、句长、停顿与称呼，不把人物固定为永远短句、永远讽刺或永远绕弯的模板。

保留说得准的原句、必要的直白情感和角色自己的笨拙表达。潜台词适用于角色确实有所顾虑、隐瞒或试探的部分，不要求每句都有双重含义，也不把“我害怕”“我想你”等坦白一律改成谜语。改写之后应能看见人物在做不同的事，而不只是换一组同义词。

## 交付实际改稿

先判断问题是否属于本场表达。根本问题涉及动机、因果或缺失的剧情节点时，加载 `muse-script-doctor`；涉及分集边界、剧情单元或集尾承接时，加载 `muse-episode-design`。用户已授权的局部改稿继续完成，结构上仍无法解决的部分明确指出，不以改台词掩盖。

输出本次修改范围内的完整场景替换稿，保留场次、人物、必要动作和未改的台词，使用 `screenplay-format` 的 `▲`、对白、OS/VO。不要只列改句建议、填“其余同原稿”或套用英文场景标题和角色名全大写格式。只要求评审意见的任务按用户范围给意见。

改后读回，核对本场前后的角色目标、已知信息、关系、承诺和物品状态是否接得上。OS 是未说出口的想法，不让其他角色据此回应；VO 与出镜对白的归属不混用。动作写可见行为，不能为简练删除决定结果或关键因果，也不能添加原稿没有的证据。

改稿后简短说明改变了哪些交锋、人物表达或信息安排，列出待核实和未解决项。说明引用具体集、场或原句，区分表达问题与结构问题；指出哪些佳句、有效回应或必要直白情感得到保留。按影响确定后续修改顺序，不用固定评分或通用好坏词代替依据。

## 局部示例

以下仅演示对白替换，人物与内容不属于用户素材。场次、人物和动作沿用原稿。

原稿：

```text
2-3 医院走廊 夜 内
人物：林遥、周宁
▲林遥拿着检查单，周宁挡在门口。
林遥：我很生气，你为什么把检查结果瞒着我？
周宁：我是不想让你担心，所以没告诉你。
林遥：你这样做是不尊重我。
```

替换稿：

```text
2-3 医院走廊 夜 内
人物：林遥、周宁
▲林遥拿着检查单，周宁挡在门口。
林遥：我的检查结果，为什么轮到你决定我能不能看？
周宁：我不想让你担心。
林遥：我担不担心，我自己决定。
```

变化：林遥把追责落在知情和决定权上，周宁以关心辩解，林遥回应这份关心而继续坚持自主决定；保留周宁的直白表达。未解决：检查结果的内容与后续决定没有提供，本段不补写。
