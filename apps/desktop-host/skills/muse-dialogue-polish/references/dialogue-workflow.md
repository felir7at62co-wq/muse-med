# 白话对白与场景精修

保留原意与人物立场，不把原文的指代错误、接话矛盾和动作冲突一并保留。每段话核对谁在对谁说、谈论的是谁、对方实际听到了什么；结合前后文作最小修正，再检查后续回应是否仍然成立。

## 读取范围与修改依据

读用户要改的场景、当前版本及已提供的前后剧情；小说和视频改编都按实际来源、已定改编设定与当前稿判断。记录稿件路径或版本、集数、场次和实际已读范围；只读片段时仅评价片段，不声称完成全本审校。人物动机或前情缺失时，先从已有材料查找，仍无法确认的内容列为待核实，不用新设定补齐。

明确本场发生了什么、观众需要知道什么、哪些关系或决定在场后改变，以及用户要保留的佳句和固定内容。区分来源事实、已批准的改编设定与待定意见。保留事件结果、人物关系、时间地点、角色掌握的信息及信息揭示顺序；授权的文字润色可以直接完成，需要新事件、新证据或改变剧情方向才能修好的问题列为未解决项。

明确逐字、字幕或历史严格视频整理按 `screenplay-format` 处理，只修排版与有依据的错字，说话人或词句不明时标记待核实。新创作模式故事忠实路径与其他获授权再创作，在其作品范围内应用以下方法；来源账不改成创作版本，不能把精修指令当作补写来源事实的授权。

## 人物与交锋

对每位说话人明确：此刻想从对方得到什么；已经知道什么、还不知道什么；哪些话不愿说出口；会用什么方式争取目标。这些判断从稿件与已定人物设定提取，不给角色临时添加秘密或背景。

逐轮检查对方上一句带来的信息、压力或机会，本句如何回应，以及回应是否改变后面的说法或行动。避免双方各说各的、重复交代观众已知内容，或轮流发表同一种立场。让解释进入当前争执、试探、求助或协商；确有必要的信息直接讲清，不为制造潜台词藏掉情节所需事实。

区分声口时先区分策略：有人追问事实，有人辩解，有人岔开问题，有人要求立即行动。结合其与对方的关系、职业和当前情绪调整用词、句长、停顿与称呼，不把人物固定为永远短句、永远讽刺或永远绕弯的模板。“落地下沉”是通俗、具体、符合身份、年代与处境，不把所有人改成土话、粗话或口号。

长段对白按诉求、信息或情绪的转折，以及对方能够自然接话的位置组织，配合必要的停顿、反应、神态与动作，让人物实际互相影响。保留有力量的连续长台词，不按固定字数切碎，也不为拆段插入没有作用的接话。括注写可表演的具体信息，不把同一句情绪换词重复；用户明确要求每句括注时按该项目格式落实，其余情况按表演需要选择。同步动作的排法沿共享格式，不把话前或话后动作硬改为边说边做。

保留说得准的原句、必要的直白情感和角色自己的笨拙表达。潜台词适用于角色确实有所顾虑、隐瞒或试探的部分，不要求每句都有双重含义，也不把“我害怕”“我想你”等坦白一律改成谜语。改写之后应能看见人物在做不同的事，而不只是换一组同义词。

按人物此刻的处境连读台词，判断它是在对眼前的人说话，还是替作者总结主题。古装人物可以文雅，情绪到位的长句和佳句也可保留；反复讲道理、堆比喻或所有人都说警句时，回到具体的人、事和诉求。OS 同样服从角色当下所想，不用它补字数或重复观众已经理解的画面。篇幅不足时沿共享写作品质反馈实际缺口，不用台词精修暗中扩展故事。

## 交付实际改稿

交付用户所要范围的完整可替换场景，包含未改内容，沿用中文场次、人物、▲动作与 OS/VO，不以“其余同原稿”或泛泛建议代替改稿。只要求评审时给有依据的意见。结构与因果方法见 `muse-script-doctor`，集界方法见 `muse-episode-design`。

修订、核对与修改说明沿共享写作品质：集中处理本轮问题，读回受改内容与必要前后文，复用同版本已完成的检查。正文稳定后简述关键变化、具体位置和未解决项，不重新启动对白审校或逐处统计。

## 局部示例

以下仅演示对白替换，人物与内容不属于用户素材。场次、人物和动作沿用原稿。

原稿：

```text
2-3 医院走廊 夜 内
人物：林遥、周宁
▲林遥拿着检查单，周宁挡在门口。
林遥：我很生气，你为什么把检查结果瞒着我？
周宁：我是不想让你担心，所以没告诉你。
林遥：你这样做是不尊重我。
```

替换稿：

```text
2-3 医院走廊 夜 内
人物：林遥、周宁
▲林遥拿着检查单，周宁挡在门口。
林遥：我的检查结果，为什么轮到你决定我能不能看？
周宁：我不想让你担心。
林遥：我担不担心，我自己决定。
```

变化：林遥把追责落在知情和决定权上，周宁以关心辩解，林遥回应这份关心而继续坚持自主决定；保留周宁的直白表达。未解决：检查结果的内容与后续决定没有提供，本段不补写。
