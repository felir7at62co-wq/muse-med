# 共同自检协议

以当前用户目标和已加载技能定义阶段，不以工具次数或整套短剧流程定义阶段。分段写作、素材导入、资产准备、分镜、剪辑与交付均执行以下检查循环；不影响已授权的独立工具并发。

1. 执行：先核对授权、输入版本和已有结果，完成当前阶段，返回能实际阅读的产物与证据。程序可以检查格式、哈希、引用和覆盖，但不能替代需要实际看图或听音的判断。
2. 检查：等产物进入下一模型轮后，读取当前完整内容或有明确范围的分段，按适用技能逐项检查。技能正文须完整返回并先读到；只看到名称或摘要时先补读。取图成功后须实际在模型上下文看见图像，不能只检查图片 URL 或大小。
3. 修正：定位具体文件、集、场、时间窗口或资产。修复已授权范围的问题，记录新版本并返回它。改变来源或上游资产时沿已有状态工具标记受影响下游，不重用旧检查结果。
4. 复检：重新读实际修订产物，对照问题与范围核对遗漏、重复、衔接和一致性；同一阶段有未解决问题时不推进依赖工作，不把“修改成功”当作复检通过。
5. 交付：只声明已核实范围及实际检查类型，注明 self-check。需要独立审核的既有项目仍保留其规则，任何未知、待处理或部分产物如实标记。

不同任务使用不同标准：转写核对实际 ASR/文字依据与覆盖、保留不确定说话人，没有试听渠道时不称对照原声；剧本核对原文、人物知情、叙述层和连续性；短剧核对正式资产、远端任务、镜头及原文覆盖；剪辑核对入出点、音画、字幕、时长、格式与实际导出结果。完整标准来自当前阶段技能和用户要求，不能把短剧固定规格套到普通剪辑。

所有剧本起草、续写、改编与修改均采用 `screenplay-format` 导航的共享写作品质；先完整返回该技能正文及 `resourceBase`，下一模型轮按实际基址读共享规范。精修和改写还检查因果链、对白接话、伴随动作真实同步且不重复、补充演绎与来源分开，以及《修改说明》是否对应最终实际成稿。说明中的采用决定、改动位置和检查范围不能由计划或文件 contains 检查替代；按 [精修与修改说明](refinement.md) 保留输入输出版本、实际对照、授权与待核实项，不机械要求每句补动作或所有背景转 OS。

记录包含任务/阶段、输入与产物版本、实际读取范围、来源和可复核路径、检查标准、问题、修订、复检结果及未完成项。工具已给出修订、摘要或真实模型步证据时直接使用，不虚构它；没有自动验证的普通任务如实写模型自检记录。该协议对所有创作任务提供行为指导，只有已有工具声明的条件才是自动执行门槛，不能声称任意工具已机械强制模型判断。
