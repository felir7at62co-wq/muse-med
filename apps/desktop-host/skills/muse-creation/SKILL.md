# Muse 精修与 QA 指南

创作模式自动提供的 `muse:creation-guidance` 系统指导负责共用任务分流、阶段自检与来源、授权、费用底线。本技能保留 `muse-creation` 名称，供需要精修或详细 QA 标准的阶段按需读取；普通转写、素材查询或剪辑不必先加载它。当前阶段的专业步骤按自动提供的技能目录选择，再读取适用技能正文，不在这里重列职责目录或启动无关阶段。

## 按需读取详细指南

- 正文精修、改写或准备《修改说明》：处理前完整读取 [精修与修改说明](references/refinement.md)。按其来源事实、表达调整与获授权补充分层执行；共通写作品质与固定《修改说明》通过 `screenplay-format` 导航读取，说明必须对应最终实际成稿。
- 需要制定检查范围、记录问题、修订复检或交付 QA：检查前完整读取 [共同自检协议](references/self-check.md)。使用当前阶段的专业技能标准，按实际产物和证据填写自检记录；精修检查同时读取上面的精修指南。

## 正文与引用资源的读取

通过 PTC 加载本技能时，使用 `return await tools.skill({name: "muse-creation"})` 或输出完整返回值，使 `content`、`provider`、`resourceBase` 进入对话；在下一模型轮实际读到正文后，再按本页导航读取所需指南。只有名称、摘要或目录时先补读正文，不能据此宣称已采用详细标准。

引用资料以技能返回的真实 `resourceBase` 为基址，用现有读取工具取得上述 `references/` 文件并将正文返回模型；不假设安装目录，也不只保留路径。正文过长时分段返回并记录实际读取范围，在相关详情完整读到后才执行对应处理或检查。
