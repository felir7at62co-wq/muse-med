# 音视频语音转写

对用户提供或授权读取的本地媒体，使用当前 Muse 账号的云端语音服务取得可核对的原始转写。只记录实际识别的语音，不根据画面或剧情补写对白。用户要求改编时，原始转写与创作稿分别保存。

## 项目位置

转写属于小说或剧本项目时，使用获授权的项目根目录。`source/links.md` 记录原件路径或链接、来源与实际可读状态；`source/media/` 仅存用户授权取回或复制的本项目媒体。已有媒体可原位只读，不移动或覆盖。云端任务收据保存在 `transcript/jobs/`；完成后的原始 TXT、JSON 和 SRT 按同一素材名与版本写入 `transcript/raw/`；人工听辨校订另存 `transcript/reviewed/`。只有链接、没有可读本地媒体时说明缺口，不声称已转写。

## 云端运行

先确认本地媒体和项目目录。Muse 账号必须已登录，服务器必须配置云端转写。`audio_transcribe` 的 `start` 会先检查时长，使用随包 FFmpeg 从音频或视频中提取 16 kHz 单声道 PCM WAV，保存包含任务 ID 的本地收据，再通过当前账号提交。只上传提取的音轨，不上传整段视频。云端转写会使用计费语音服务；仅在用户要求转写、项目已有相应授权时提交。

按实际用途设置 `purpose`：字幕生成或校时用 `subtitles`（极速识别）；音视频转剧本用 `screenplay`（标准识别）。一般转写未指定用途时默认 `subtitles`。具体服务版本与资源由 Muse 服务器分配，不向用户索要提供方密钥或让用户选择资源。用途写入收据和所有音轨分段，查询与重试保持原用途；已有未完成任务不能改用途，先用原收据查清结果。

```json
{"method":"start","project":"<项目根目录>","input":"<获授权的本地音频或视频>","language":"zh","purpose":"screenplay"}
```

`language` 可为 `zh` 或 `auto`，省略时为 `zh`。保存 `start` 返回的 `receipt`，然后对同一收据调用：

```json
{"method":"status","project":"<同一项目根目录>","receipt":"<start 返回的收据路径>"}
```

限流的 `error_code` 区分 `queue_full`（队列满）、`upload_busy`（上传繁忙）、`request_rate`（账号请求频率）和 `provider_rate`（服务额度或提交频率）。有 `retry_after_seconds` 时按该秒数等待，再使用返回的 `resume_status`。`status` 先回读，确认原任务尚未受理后可能补传同 ID 音轨并计费；不更换 ID、用途或收据。`daily_quota` 先处理账号日额度，`sign-in-required` 先登录，`idempotency_conflict` 先核对原任务，不能直接重投。一次调用没有自动等待或无限重试。

`processing` 或 `uncertain` 表示任务仍需查询；继续用同一收据调用 `status`。网络超时不能说明提交未被受理，不要换素材版本或任务 ID 直接再提交。服务器确认原任务不存在且本地音轨仍在时，工具才用原 ID 重试。留存到期仍未解决时，网关删除临时音频；下一次 `status` 删除本地暂存音轨，但保留收据和原任务 ID 供只读对账，不重新提交。`complete` 才有 `output_txt`、`output_json` 和 `output_srt`；`silent` 表示未识别到语音，只保留收据，不生成空转写。未登录、服务器未部署或未配置、限额或音轨提取失败时，报告具体障碍，不假称云服务成功，也不自动切换到离线识别。

TXT 每段格式为 `[00:00:01.250 --> 00:00:03.500] 台词`；JSON 为包含秒数 `start`、`end`、`text` 和字词 `words` 的逐段数组；SRT 使用相同时间轴。长媒体自动切分后合并为原视频时间轴。正式字幕须按 draft-build 技能将字词时间对齐到剧本原文，不能直接把识别文本当成经过审校的台词。完成后读取输出，核对时间顺序、明显错词和漏识别；人工修订另存新文件，保留原始版本。

JSON 中可选的 `speaker_id` 只是本次识别的声学分组，不是角色名。多个角色可能合并到同一编号，同一角色也可能被拆成多个编号；全稿只有一个编号不表示只有一个人物。逐段核对实际画面、字幕与发声时段，保留归属依据和未知声音；一段含多轮对白时另记分轮对照，不能把整段全部指给当前镜头中的人。姓名、公司名、专业词与画面文字冲突时补看相应时间码；有充分校订依据才另存修正版，原 ASR 保留。

用户要求视频转剧本时，继续加载 `transcript-to-script` 整理正文；带时间戳的原始转写用于内部核对，不直接作为剧本交付。剧本的时间码处理与场次格式遵循该技能。

## 获得离线转写授权时

用户明确要求本地离线转写，或云服务不可用后同意改用离线转写时，才使用另行准备的 faster-whisper 依赖与本地模型；默认安装包不含这套识别依赖和模型：

```text
python -B "<skill-dir>/scripts/transcribe.py" --input "<音频或视频文件>" --output-txt "<新的时间轴.txt>" --output-json "<新的片段.json>" --language zh
```

脚本要求已有 `MUSE_WHISPER_MODEL_DIR`，并使用 `DSH_FFMPEG_PATH` 或 PATH 中的 FFmpeg；不会下载模型。两个输出路径必须是新文件，不覆盖云端或人工校订结果。此技能只做语音转写；画面 OCR 和场景截图需分别核对。
