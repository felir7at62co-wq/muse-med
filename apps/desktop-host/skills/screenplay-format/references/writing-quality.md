# 共享剧本写作品质

适用于视频转剧本、小说转剧本、换梗、续写、新写与已有稿修改。以实际素材、用户简报、已选大纲及保留要求确定本轮范围；这些是写作与审校标准，不替代项目实际声明的来源、授权和验收机制。验收时让没看过原片或原稿的制作老师仅凭剧本基本复原事件、冲突、人物选择与情绪变化；读者能理解，不表示来源已经核实。

## 先区分任务与来源账

| 当前任务 | 作品层处理 |
| --- | --- |
| 新创作模式中的视频转剧本 | 默认走工具提供的 `story-faithful-v2`，忠实的是故事，不要求逐字或逐镜复刻。在本作品获授权的范围内可强化合理情绪张力、口语化对白、反应动作与视听表达，保住事件及行动结果、情绪冲突、关系立场、因果和关键揭晓。 |
| 明确要求逐字稿、字幕或严格来源整理 | 保留实际发声轮次与可核对画面，不新增台词、动作或心理；疑点留待核实。 |
| 历史项目及其他 preset | 沿现有严格策略和验收记录，不因读取本指南切换为新故事策略。旧 `source-preserving-v1` 的渠道、顺序与结构限制仍生效。 |
| 小说改编与换梗 | 小说转剧本以保留原作为基础，润色表达并转换成戏；换梗按用户已选方向、大纲、必保留事件或情绪机制与授权范围重组。不套用视频逐源动作、逐镜或渠道硬锁，不能漏掉必要铺垫和结局兑现。 |
| 续写 | 依已确认前文、大纲、人物状态、知情范围与未兑现伏笔继续，不静默重置人物、场景或世界规则。 |
| 新写 | 依简报、已定人物和大纲组织戏；没有原稿时不捏造原句、来源观察或 before/after。 |

原始 ASR、来源文本与实际观察账保持可追溯，不用润色稿覆盖。来源事实、作品表达调整和获授权补充分开记录：新写台词不称视频原声，新增反应或心理不称已观察画面。合理强化不自动授权重大因果、关系立场、事件反转、关键揭晓或重大动机变化；超出当前范围先列具体改法与影响，等待用户决定。真实项目级授权只在绑定的作品、版本、集数与类别内复用，不由自由理由、批注或参考资料扩展。

小说或视频转剧本默认尊重并保留原作的人物性格与关系、主要情节、因果、情绪走向及有效的原台词，在此基础上润色。自然化书面表达、压缩重复说明、把叙述转换为原作支持的动作与互动，都以保留原意和故事走向为准；有感染力的原句不为显得新颖而改写。只有用户明确选择重构、换梗或扩写时，才在其范围内改变故事，不能把“转成短剧”理解为另编一套剧情的许可。

视频取材与全时段采样按 `transcript-to-script` 的核对材料步骤执行。采样计划覆盖与实际看过的帧分别记录，离散图片不等于连续看完。当前没有独立音频观察通道；ASR 是文字识别，不是试听，不声称核实环境声、语气、声线或音画同步。

换梗复检分别核对保留的事件、冲突与因果，以及当前正文真正重写的对白、行动、道具与场景组合。对应表写了“保留”不证明新稿已重构；原句沿用须如实记录，不能登记为全部新写。新行业的技术或流程因果须通过可理解的剧内行动、信息和责任关系成立，方案里的解释不能代替成稿呈现。源片未知项留在源分析；获授权新作可明确补写相应事件，但不能将补写倒记为原片已观察事实。

## 情绪通过事件与人物选择推进

每场明确人物想得到什么、遇到什么阻力、采取什么办法、对方怎样回应及场末发生什么变化。情绪从事件、冲突、选择和代价产生，保留积累、释放与必要余波；不能只堆神态、争吵和口号。关键关系或揭晓需要前置条件，强化压力不能改掉原有立场或提前解决冲突。

对白通顺、口语化且符合人物此刻的身份、关系、目标和知情范围。逐轮连读提问、应答、回避、打断和反应：本句应回应对方实际说出或做出的事，并对下一句或下一行动产生作用。不同人物不统一成同一种声口；必要的直白情感、文雅措辞与有力量的原句可以保留，不机械剁短或全部变潜台词。人物此刻自然说得出，比句子单独看着漂亮更重要；小说中的事后总结、作者评语和比喻不逐句转成对白或 OS，画面与对话已经传达的信息不再靠心声复述。

## 精练不损伤条件与因果

删无效修饰、空泛评价、重复解释和无功能过程，保留会改变时序、力度、选择或结果的词。条件、否定、金额、数量、时间、承诺、身份、证据与揭晓次序逐项核对，不能靠“意思差不多”放行。例如原创句“等手续办好，我再交钥匙”不能压成“我现在交钥匙”。

动作具体可拍，写明谁做什么及必要结果；身体感受和文学比喻不能只加 ▲ 就算画面。核对原因→行动→结果、话前→话中→话后，以及地点、道具与人物进出。不能删掉推搡却留下无因摔倒，不能把说完后的反应提前到对白之前；跨过别人的提问的两次回答也不合并。

## 人物知情与展示一致

OS 只属于角色自己的心理，别人不能听见并接话；作者背景、事后评价和审稿意见不自动成为当前人物的心声。VO 明确声音来源和真正听者，观众可闻不等于场中人物可闻。场次、人物名、别名与 OS/VO 标记在全稿一致，隐瞒的身份和未揭晓信息不提前暴露。时间线与叙述归属按本技能同包的[时间线规范](narrative-layers.md)核对。

审校知情时分开记录来源或正文明确呈现、未经证实的推断、未交代的信息。未交代不等于不知道，掌握一项信息不自动表示掌握另一项；单个反应不能证明此前知情状态、物品归属或未呈现事件。推断写成可能解读或待核实，不据此认定矛盾或声称新增事实已经成立；获授权的新写或演绎可选择一种表达，但须标明实际新增，不能倒写成原有事实。

确实同步的短动作可放说话人括注，只展示一次，不重复 ▲ 行；独立原因、话前话后反应、跨人物回应或跨场动作保留独立顺序。受管项目仍保留动作来源、typed 分类、覆盖及知情记录，展示合并不能混淆事实渠道。每句神态、所有背景转 OS、只准特写或蒙太奇等仅适用于用户明确指定的项目风格，不推广为通用规则。

## 逐集覆盖与整体连续

按剧情单元和情绪落点分集，再调整篇幅；沿用户已定集数、字数、时长与制作要求执行，不改专业技能中的数值约定。集尾钩子从本集实际后果、已有信息差或已定伏笔产生，不凭空编造反转。严格视频整理只标来源已有悬念；获授权新作的钩子也须有已选大纲或正文铺垫，下一集接住并兑现。

篇幅分别核对目标总集数、每集或全稿正文的字数、预计表演时长，以及素材中足以支撑这些目标的事件、冲突与情绪过程。反馈时说清是哪项不足，引用实际集场与来源范围，并说明字数统计是否含标题、标点和空白。没有时长要求时不另设固定秒数，也不以字数或小说章数直接推定能拍多少集。

发现已读素材与目标明显不匹配时，尽早向用户说明缺口，不等到写完全剧后反复补差。先核对是否漏读来源、漏掉必要过程或把原有场面压得过短；小说或视频改编可在已有授权内将叙述转为可拍动作、自然对白、互动和反应，不要求逐句、逐镜照搬。补充应深化原有冲突、选择或情绪，不靠重复解释、抽象总结、长段 OS 或反复重演同一事件填满篇幅。

若仍需调整约定的集数、字数或时长，或新增超出当前授权的事件、人物关系、支线、动机或结局才能满足目标，给出有依据的容量估计与取舍：减少集数、调整单集长度，或列出具体扩写内容及其影响，请用户决定后再处理依赖该选择的部分。用户已明确授权的扩写范围直接沿用，不重复确认；不受该选择影响的整理与改编继续完成，不静默放弃目标，也不把未获同意的新增剧情当作原作内容。这是创作沟通要求，不新增工具审批或固定审校轮次。

逐集读取实际保存的完整正文，核对本轮计划与来源故事或已选大纲的事件覆盖、遗漏、重复、有效冲突与情绪回报。合稿连读相邻集尾与开头，追踪人物位置、状态、关系、知情、道具、场景和时间层；必要时沿改变追到受影响后续集。只检查首批或局部时列出未读集数，不能称全稿完成。

## 修改任务固定交付独立《修改说明》

已有稿或批注且本轮修改正文时，成稿与独立《修改说明》固定并列交付，不把说明、QA、hash 或内部批注拼进剧本、Word 或知识库正文。只要求审稿意见时交付诊断。新写没有旧稿时可记录简报、来源→作品映射和未核实项，不虚构修改前文本；初次视频成稿可用实际来源位置与作品映射说明改编取舍。

说明依据已保存的最终实际成稿，至少包含：

1. 范围与版本：实际处理的集、场、片段，输入原件与基线、来源版本、输出路径及真实版本/hash；范围外部分另列，受管工具提供的候选和检查记录直接引用。
2. 实际对照与来源位置：按集场、beat、正文行或来源片段定位原文与新文、类别、理由和影响。已有稿列真实前后，不把 ASR 当试听；无旧稿用来源→作品位置，不造 before。条件、金额、立场、因果、知情及揭晓变化逐项说明。
3. 批注逐条对账：保留实际批注的稳定编号与原意，标采纳、部分采纳、未采用或待核实，附理由和最终成稿位置。批注实体不完整时说明范围；没有锚点不等于没有批注，未处理的下一批不能列为本批完成。
4. 新增与授权：区分来源事实、表达调整与补充演绎，列新增内容、依据、角色/时间层、类别及真实授权范围；OS、新对白和反应动作不归入原声或已观察事实，必要依据或授权不足的项保持待核实。
5. 未处理与待核实：列范围外集数、材料缺口、未知声源/人物、未解决问题及需要用户决定的变化。部分交付明确部分。
6. 实际验证范围：分列已采用的格式、引用、覆盖、内容审校、实际看图/音频观察和页面检查的位置及未覆盖部分。是否采用独立审校、后续模型轮自检或其他检查方式由 Agent 按任务决定，不虚构未执行的检查。文件存在、关键词命中、括号计数、抽查两页均不能证明对白逻辑、所有批注采纳、全片忠实或全稿分页。

先比较保存的实际输入与输出版本，再写修改说明。建议不等于已落实：分清问题或建议首次提出的位置、正文真正落实的位置，以及本轮未改变或沿用的内容。声称删除、前移、合并或新增须有对应版本的真实前后位置与文字；两版位置和文字相同就不能登记为已修改。审读引用有误时撤回原结论并记录更正，不把错误建议包装为完成的改动；批注仍有疑点或只部分落实就保留相应状态。

## 按任务复核实际成稿

由 Agent 根据稿件长度、修改范围、用户要求和当前工具声明选择审校方法、时机与是否独立审校，不固定要求 A/B/C 轮次或批准收据。选用模型审校时先实际读取完整内容或明确分段及相关图片，再定位问题、修订并复核受影响部分。说明中的采用决定、对照、授权与验证声明须能在最终版本查对，不把执行计划或模板全部 pass 当结论。advisory 检查结果提供建议，不阻断继续写作、导出或交付；明确启用的严格部署沿其声明检查。自检不称独立审核，未执行或无法执行的检查如实列出。

只记录实际改动和已执行的检查；修改后尚未复核的范围如实列出，不冒称当前版本已验收通过。采用复检时核对当前正文、说明、实际差异和知情依据，不把旧版本结论直接用于新稿。
