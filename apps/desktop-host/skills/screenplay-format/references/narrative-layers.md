# 时间线与叙述归属

本规范用于分场剧本的起草、续写、修改与审校。以实际读到的来源和已定大纲为依据；用户明确规定的标记优先，沿用已确认约定，不自行补造前世经历、闪回画面或人物认知。

## 先确定时间与说话归属

逐段判断故事发生时间、叙述者或说话人、表达方式与人物知情范围。对会影响改编的段落，在项目 `qa/` 的既有来源对照或新的版本化记录中保留来源位置、现实／前世／闪回／梦境等时间层、视角人物、对白／心理／旁述／作者评述，以及谁在此刻知道相关事实。没有项目写入授权时在本次工作记录中保留，不另写文件。

| 来源内容 | 剧本处理 |
| --- | --- |
| 人物当面说出的话 | 保留为该人物的对白，其他人物是否听见按场景核对。 |
| 人物未说出的心理 | 优先用原文支持的可拍动作呈现；必要时写 `人物名 OS：内心话`，只归属于该人物。 |
| 可核对的画外声音 | 写 `人物名 VO：话语`，标清声音来源；是否被场中人物听见取决于原声与场景，不能由 VO 标记推定。 |
| 叙述者补充事实或事后评价 | 保留其叙述者与时间立场；按改编需要转为有依据的画面或明确归属的旁白，不能默认写成角色 OS。 |
| 作者分析或审稿意见 | 留在 `qa/` 或改编说明，不作为人物台词、心理或故事中已发生的动作。 |

Muse 默认用 OS 表示角色内心独白，VO 表示画外声音。来源或用户采用其他约定时先根据其说明辨认并统一，不按字母批量替换。角色 OS 不让其他人物听见；只有明确的对白、行动或其他有来源依据的事件，才可能使其他人物获得该信息。

“她害怕”不自动变成“她 OS：我害怕”；不能为使画面可拍而发明来源没有的动作。先判断这是谁的心理、能否由现有动作传达、是否必须保留具体想法。叙述者的“他此刻还不知道……”不能变成该人物提前知道事实的 OS；“多年以后她才明白……”不能改成此刻已经明白。评价语气、心理动词或第一人称本身都不足以判断归属。

## 明确进入与离开回忆

区分故事发生顺序与读者看到的顺序。前世不是当前人物刚刚经历的现实事件，闪回不改变现实中人物的位置、道具或在场人员；只有来源支持的回忆与认知，才能影响人物返回现实后的行动。

同一意识不等于同一个肉身的全部往事。穿越题材分别记录当前意识、当前肉身原主的经历和前世身份；原主过去的状态不直接成为当前意识的状态。原主记忆被当前人物接收时，在现实层另提并独立审校有来源依据的认知事实，正文引用它；其他人物不会因此获知这段记忆。跨层知情校验失败时核对缺少的认知过程，不直接清空 `requires_knowledge` 消除报错。

来源确实呈现回忆画面时，在开始处写 `【闪回开始｜前世】` 或标明本次回忆的时间与归属，另起场次，并在闪回场次行括注同一时间层；结束处写 `【闪回结束｜回到现实】`，另起现实场次，恢复此前现实的地点、人物与状态。用户已有等效格式时沿用。梦境和转述画面同样标明进入、退出及返回的时间层；嵌套时按进入的逆序退出，不一律返回现实。

角色只说起往事或在 OS 中想到过去，来源没有回忆画面时，保留在当前场次，不为了关键词“前世”“想起”自动插入闪回。无法判断时记录待核实，保留原文表达，不把不确定的时序写成已确认事实。

以下是排法示例，人物与情节不属于用户作品：

```text
第1集
1-1 老屋客厅 夜 内
人物：林遥、周宁
▲林遥握住信封，望向门口。
林遥 OS：这封信，前世也曾落到我手里。
【闪回开始｜前世｜林遥的回忆】
1-2 城门 夜 外（前世闪回）
人物：林遥、守卫
▲守卫将同样的信封递给林遥。
守卫：天亮以前，别回城。
【闪回结束｜回到现实】
1-3 老屋客厅 夜 内（现实）
人物：林遥、周宁
周宁：你在看什么？
林遥：没什么。
```

周宁没有听见林遥的 OS，也没有参与这段回忆，不能因此接出“你前世收到过这封信”的对白。原文中的作者评述另存审校记录，不插进上述正文。

## 分段写作与合稿

拆分章节、场次或集数前，把来源范围、已定标记、当前时间层、视角与人物知情范围、上一场结束状态和下一场承接位置交给实际写作的任务。分段不能静默重置为现实，也不能把一个时间段的同名角色状态带入另一个时间段。跨段尚未结束的闪回必须明确告知下一段；写作结果同时说明开始与结束的时间层，原文缺口标待核实。

合稿与交付前读取实际保存的正文，逐一核对：每次进入回忆是否有正确的退出或明确的跨段延续；现实恢复后的位置、人物、道具是否相符；OS 的说话人是否明确且未被其他角色当作已听到的对白；角色有没有提前知道叙述者或作者才知道的事实；作者分析和审校批注是否留在正文外。每个问题定位到来源段落及集场，修订后连读相邻场次，不以格式齐全或一次自检代替内容核对。未核实的范围如实说明，不能宣称全稿通过。
