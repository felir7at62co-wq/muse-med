# 小说转分场剧本

在原作基础上把故事写成可演的戏。沿用用户确定的主线、人物关系、关键事件、情绪和结局；普通改编不默认换梗，不为降低文字相似度替换有效台词，也不借润色改变关键承诺、数量或时间。用户明确授权重构或扩写时，记录其范围和实际新增。

保留原故事不等于照搬原句里的错误。核对说话人、说话对象、指代、人物已知信息和动作先后；原文有明确的指代失误、接话矛盾或前后冲突时，结合上下文作最小修正。有效的原对白继续保留，需要润色的部分写成当场人物会说的话，不用叙述者的解释替代交锋。

## 读懂来源

读取本轮涉及的原文及必要前后文，记录题名、作者或来源、版本、章节和实际阅读范围。人物名称与别名、时间地点、行动结果、关系和知情变化以实际原文为准。缺章或版本冲突标明缺口，不从简介推定未读内容。来源大纲可保存在 `outline/source-v1.md`，作品大纲及修订另存新版本。

第一人称小说区分每章叙述者与角色的正式身份，不把不同人的“我”合并。回忆、梦境、转述和现实分别交代起止，保留误解、隐瞒与揭晓时机；读者知道的背景不自动成为场中人物已知的事实。

全局规划覆盖本轮来源、事件归属和集间状态，正文按完整场景或集连续落稿：用现有文件工具先保存可用的开场或首集，再在同一当前稿中续写、局部修订，不等待全剧每句对白都预演完才写入。上一段的实际结果和人物、道具、知情状态带入下一段；最后核对本轮完整范围与受影响边界。分段保存是写作过程，不把开场或首集当作全部交付。

## 从叙述变成戏

来源与关键衔接读清、分集起止可用后，就将正文写成实际稿件；规划保留必要的事件归属与因果，不逐集预写全套对白再重写一遍。对白和动作在场景稿上打磨，只有具体问题才改相关段落或集界，不为可选写法反复重排全剧。

区分原文当面对白、心理活动、叙述者评价和实际动作。对白保留说话人、原意和人物声口，书面说明转成符合当下目标的自然交流；作者评语与比喻不逐句塞进人物台词。心理优先通过原作支持的互动、选择与动作呈现，无法传达的必要信息才使用明确归属的 OS/VO，不让其他人物听见内心话并接话。

每场保留必要铺垫、冲突、行动与结果。长对白按接话、策略和情绪转折分开，短动作与同拍台词合写，独立前后动作仍按实际次序展示。不能删去起因却留下结果，不能补造已外出、已知情或昨日约定来修衔接。分场、人物行、▲动作、对白及 OS/VO 的中文排法见 `screenplay-format`；对白专项见 `muse-dialogue-polish`。

## 分集与修订

分集方法见 `muse-episode-design`。小说章节和字数不直接决定集界；每集围绕原故事的一次推进组织，保留情绪积累与回报。上集实际结尾是下集的起点，已演出的同一事件不重新完整演一次；若钩子已经揭晓消息，下集处理消息的后果，而不是再宣读一遍。复现或回忆须有新的叙事用途，普通承接不写成长篇前情。

篇幅沿用户约定，没有数值要求时按情节节奏安排，不自行追逐字数。素材不足先查遗漏与必要过程，不用无功能 OS、重复场面或新支线补差；仍不能兼顾时反馈具体容量与取舍。修订与交付沿共享写作品质复用已读来源，集中核对受改内容及必要依赖，不重复整套检查。

## 交付

原件、来源索引与正文分开保留。草稿和正式稿在 `draft/`、`final/` 版本化保存，实际来源覆盖、改编选择、已读范围和未核实项放在 `qa/`。按本轮约定交付完整范围；修订已有稿附独立《修改说明》，格式与 Word 操作分别见 `screenplay-format` 和 `office-docx`。来源引用保留可查对照，新写对白不冒称原文逐字。检查结果是写作依据，不设受管登记、独立审核或批准后才能继续的前提。
