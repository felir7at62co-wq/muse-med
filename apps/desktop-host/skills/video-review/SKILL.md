# 视频核对

使用 `video_inspect` 查看本地媒体。文件尚未取得时，先按来源使用可用的导入或下载工具。需要画面事实时选用明确支持图片的模型；只有元数据不代表看到了视频。

用户提供的视频位于工作区之外时，用已有文件工具复制到当前项目的 `source/media/`，保留原件与来源记录，并避免覆盖已有文件。网页和手机预览只服务当前会话工作区内的视频；无法复制时，说明原件不能在该预览中播放，继续核对已授权可读取的内容。

先检查视频时长及用户关心的范围，再按区间采样。结果中的源帧时间码与图片才是视觉依据；清单保存在项目中。关键动作、转场、角色或资产疑点用具体时间码补看相邻画面。需要全片核对时遍历后续区间，并记录已采样区间、已确认的事实与未核实部分；不要把离散抽帧描述为连续看完视频。

对白和字幕需要使用已授权的 `audio_transcribe`，字幕校时传 `purpose: "subtitles"`，转剧本提取对白传 `purpose: "screenplay"`，然后按原始时间码与画面核对。工具或模型无法听辨时，声线、音色、声音归属及口型同步保留待核实；不能只凭画面或台词稿宣称音频一致。生成新声线与参考音频沿用项目的声音约定。

向用户展示成片时返回可打开的项目文件链接，使用视频预览核对。播放失败先报告真实连接或编码问题；未经核实不重生成视频或重复付费提交。
