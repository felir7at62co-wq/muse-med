# 直链媒体导入

微信小程序或视频号资源先加载共享技能 `wechat-shortdrama-harvest`，通过用户已登录的 Windows 微信取得当前可访问的原件；本技能仍只处理下面的公开直链。

仅处理无需登录、直接返回音视频字节的公开 HTTPS 链接。抖音分享页、微信视频号或小程序页面、需 Cookie 的链接、临时签名链接、加密流和播放列表不是直链；本技能不解析页面、不绕过登录或平台限制。若用户只给这些页面，保留来源并说明缺少可读原件，不声称已下载或可转写。

先选用户授权的单个项目根目录，确认原件可保存且有相应使用许可。在 `source/links.md` 记录来源页面或资源 ID、平台与标题、访问时间、用户授权的使用范围、目标文件名和当前下载状态；不要记 Cookie、签名 URL 或账号凭据。本地已有原件保持只读引用，避免重复下载或覆盖。只从用户授权的直链导入，输出固定在项目的 `source/media/`，文件名须与真实媒体格式一致：MP4、M4A、MOV、MP3、WAV、FLAC、OGG 或 WebM。项目路径必须是用户控制的现有绝对目录；路径中已有的符号链接或 Windows junction 会被拒绝。

```text
python -B "<skill-dir>/scripts/import_media.py" --url "<公开 HTTPS 音视频直链>" --project "<已存在的项目根目录>" --filename "episode-001.mp4" --rights-note "<用户对此原件的授权或许可证依据>" --max-mib 2048 --max-seconds 900
```

`<skill-dir>` 为本文件所在目录。Muse Windows 随包 Python 可运行此脚本；其他平台须先取得可用的 Python 3.12+ 可执行文件，macOS 尚未做本技能的安装包实测。脚本只使用 Python 标准库；拒绝 HTTP、本机和内网地址及重定向、URL 查询参数、网页等非媒体响应。每次 HTTPS 连接固定到验证过的公网 IP，并以原主机名验证 TLS 证书；总下载上限为 2048 MiB 和 1800 秒，参数只能缩小。下载到临时文件并验证媒体文件头后，先写含公开来源 URL、授权依据、大小和 SHA-256 的 `.source.json` 记录，再发布媒体文件；只有记录状态为 `ready`、文件校验值一致时才用于正式转写。中断后记录可能为 `pending`，须先核对来源与文件并恢复，不能把孤立文件当成已授权原件。成功结果不回显来源 URL；将实际访问时间和完成状态补入 `source/links.md`。脚本拒绝静态目录重解析点并在发布前后复核路径；用户控制的项目目录若被其他进程主动并发替换，标准库无法保证完全隔离，应停止导入并检查项目文件。
