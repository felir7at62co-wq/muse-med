# 抖音视频获取

收到 `v.douyin.com`、`douyin.com/video/…` 或 `douyin.com/jingxuan?modal_id=…` 时先用本技能，不把直链导入器的限制当作 Muse 无法处理抖音的理由。用户要求对所给视频做转写或改编时，先尝试获取该视频，不要求用户再手动下载一遍。单条链接只代表该视频；剧名或全集需求先搜索并核对目标作品、版本和集数，不把单条成功报告为全集下载完成。

## 查找视频（按需）

用户已有具体视频链接时，直接进入下载步骤。只给剧名或关键词、要求“搜抖音”时，先用当前模式提供的网页搜索工具检索公开作品页，例如 `site:douyin.com/video 剧名 关键词`；也可以在用户授权的本机浏览器中打开抖音搜索页面，核对作品标题、发布者、版本和集数，取得具体作品链接后再下载。搜索页本身不是视频，不把 `/search` 页面交给下载器；打开目标作品，提取 `/video/<作品ID>`、分享短链或带 `modal_id` 的链接。

网页搜索只能发现可索引的公开结果，本机浏览器搜索取决于当前账号与平台页面；本技能不提供完整的抖音站内搜索 API。工具不可用、结果为空或作品不可读取时，如实记录检索范围和缺失素材，不把搜到的剪辑当作全剧、也不保证任意视频都能下载。搜索得到可用链接后，沿用下方下载与转写流程，不要求用户再次手动保存视频。

## 下载与核对

使用 Muse 随包 Python 和本目录的 `scripts/download.py`；所需 yt-dlp 已随技能内置并锁定版本与 SHA-256，不运行 pip，不写安装目录。先取得随包 ffprobe 的可执行路径；可从媒体运行环境或 `load_workspace_dependencies` 发现，不能臆造路径。

```text
python -B "<skill-dir>/scripts/download.py" --url "<用户提供的抖音链接>" --project "<已存在的项目绝对目录>" --ffprobe "<随包 ffprobe 路径>"
```

脚本会把 `modal_id` 规范化为作品页、解析抖音分享短链，再让平台提取器取得当前媒体地址。平台返回的带参数、临时签名媒体地址可以交给该提取器下载，不应以“带参数”一律拒绝。没有保存的浏览器选择时，公开视频先无凭据尝试；实际遇到登录、Cookie 或验证要求，才请用户在自己的浏览器打开目标并完成必要操作。访问受限或受保护的视频如实报告，不购买或解密。

## 复用本机登录

首次需要登录时，用 `ask_user` 让用户明确选择已登录抖音的浏览器与配置，例如 Chrome / Default、Edge / Default 或指定 Firefox 配置目录；多账号时必须选具体配置，不能自动扫描并挑最新账号。用户选定后，给下载命令追加：

```text
--browser edge --browser-profile "Default" --remember-browser
```

支持 `chrome`、`edge`、`firefox`；`--browser-profile` 必填，接受具体配置名（如 `Default`、`Profile 1`）或已有的绝对配置目录。脚本只保存 `$DSH_HOME/douyin/browser.json` 中的浏览器和配置选择，不保存 Cookie 或“已登录”的判断。后续普通下载自动复用选择，每次重新读取该配置中的本机 Cookie，不再反复询问；用户切换账号时更新选择。`--public-only` 忽略已保存选择；单独运行 `--forget-browser` 清除选择，保留原浏览器账号与 Cookie。

登录过期或平台要求验证时，请用户在已选浏览器配置中重新打开目标页面，刷新并完成登录或验证，再沿用该选择重试。Cookie 可以在未登录时存在，也可能因页面变化、账号限制或网络条件而无法取得视频；有 Cookie 不代表已登录或一定能下载，不把重启 Muse 当作已验证的修法。

维护方的浏览器读取器会在本机临时读取所选配置，再将其中 `douyin.com` 及子域的 Cookie 过滤到内存下载会话；不导出、上传或打印 Cookie，不把它写到项目或知识库。不要让用户粘贴 Cookie 到会话，不读取其他浏览器配置，也不复制开发者个人凭据到安装包。Chrome/Edge 的 AppBound/DPAPI 加密、锁库或新版平台验证仍可能阻止读取，不能承诺绕过或把已保存选择说成登录成功。根据实际错误提示用户关闭锁库浏览器后重试，或明确提供本地 Netscape Cookie 文件路径并追加 `--cookie-file "<本地文件路径>"`；文件模式会忽略保存的浏览器选择，且不能同时指定 `--browser`。

视频保存到 `<项目>/source/media/douyin/<作品ID>.<格式>`，旁边的 `.source.json` 记录公开作品页、大小、SHA-256、媒体时长与取得时间，不包含 Cookie 或临时媒体地址。已有同名文件不覆盖；先检查原件和来源记录，缺失、失败或验证未通过不能声称已下载。脚本仅在 ffprobe 确认有可读视频流后报告成功，默认单条上限 2 GiB。网络失败、页面变化或平台验证仍可能导致下载失败；按实际返回说明缺项，不能把失败泛化为所有抖音页面不支持。

## 衔接编辑

把公开作品页、作品ID、原件路径、任务范围和下载状态写入 `source/links.md`。取得视频后加载 `audio-transcribe`，再按任务加载 `transcript-to-script` 或 `transcript-to-novel`，不要求用户重复上传已下载文件。原始转写放 `transcript/raw/`，核对剧本放 `transcript/reviewed/`，大纲放 `outline/`，最终 Markdown/Word 放 `final/`；剧本正文不带时间轴。云转写鉴权失败时先核对 Muse 账号状态并报告真实错误，不把随意重启说成已验证的修法。
