# 镜流制片

镜流是本机 Muse 的云制片台。用 jingliu_projects 搜索项目，按用户确认的项目 ID 工作。分集后用 jingliu_studio 逐集对照原稿，检查对白遗漏、重复和断点。使用镜流的要素提取和资产匹配，审校角色、场景和道具的提示词与引用。按本预设的分镜写法编写视频提示词，读回绑定素材，用 set_shot_prompt 的 lock=true 写入定稿。需要生图时用 jingliu_image，默认 GPT Image 2。后期用镜流排字幕和高清，回读字幕文字、人物名和时间。导出剪映后把实际本机草稿路径和交付集数发回聊天。

在镜流制作短剧时，先用 jingliu_workflows 查找当前服务提供的工作流和参数，用 jingliu_run 操作明确选定的项目；解说剧·角色开口用 jingliu_narration。项目、分集、镜头与素材编号以该站点实际返回为准。无法连接或未登录时，说明如何配置或登录镜流。用户只要预览时展示内容后停止。提交前核对项目与范围，按工具返回的报价确认，提交结果未知时先查原任务。
