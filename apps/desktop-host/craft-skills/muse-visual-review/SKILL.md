# 审片与一致性核对

依据实际成图和成片判断吸引力、情绪与叙事效果，关注它能否帮助故事成立。发现偏差时抓住主要原因调整，保留已经得到用户认可的设计，不凭提示词、参数或任务成功就宣称艺术效果达标。

审片先实际读取同一项目已确认的角色与场景参考图，再与生成图或带时间码的视频帧并列比对，记录参考资产、时间码和脸型、服装、材质、渲染等可见差异。仅看成片不能确认风格或角色身份符合项目；缺少已确认参考、看不清或风格难以区分时标为待确认，不通过、不绑定，也不擅自收费重做。

正式参考的资产编号、所选版本与采用状态须与同一项目当前记录一致。历史图、候选图或身份与风格未核的图只能辅助观察，不能替代正式参考，也不能混合不同标准提高置信度或判通过。

写实CG和照片感画面可能相近；只描述可见画面及与参考的符合程度，不凭提示中的3D、任务状态或加载的技能推断实际风格，也不把渲染或真人实拍的制作来源当作看图已证实的事实。

画风相符须逐项对照正式参考的造型比例、材质表现、渲染质感与强弱，记录可见相似与差异；“同为3D”“CG同族”或未见另一风格特征不足以判通过。细项差异未解释或细节不足时保持待确认，不把低清未呈现的纹理当作制作来源证据；不强迫具体风格标签，已核实的合理光照和机位变化不单独判失败。

每镜绑定实际入画角色及必要场景、道具；多视角设定只表示同一个人，不复制演员。对照正式资产逐镜检查脸型、发型、服装和年龄特征；服装相似或资产ID正确都不足以确认角色一致。

与正式参考的脸型、发型、衣装、材质或渲染存在影响身份或画风的可见差异时，相关项记失败；证据不足以判断时记待确认。未获明确授权接受差异或复检证实解决前不能通过，不以低清、光照或“可能版本不同”自行豁免。已核实为合理镜头变化的摄影机切换、姿态、光照和普通构图偏差可以接受，但不能替代身份与画风关键特征核对。

关键正式参考缺失或未核、关键质量项失败或待确认时，包整体不得通过，不绑定、不推进依赖该验收的收费操作；不能用局部通过、高置信度或“未发现失败”覆盖未核项。

人物难以辨认、重复、错绑定、瞬移或镜头节奏超限时记录具体时段，修正受影响片段后再实看复检；不把任务成功当作质量通过。
