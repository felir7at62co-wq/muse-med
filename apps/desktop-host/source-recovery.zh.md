# 来源恢复

[English](source-recovery.md) | 中文

当已提交的裁剪或摘要替换了一次成功的普通 `read` 结果时，Muse 可以收到受限的原会话事件索引。索引在可用时记录路径和读取范围，以及已记录文本块的哈希；它不会指定权威来源，也不表示 Muse 已理解内容。

`source_recover` 从调用方当前会话中指定的一次原始成功 `read` 事件读取文本块。偏移量从零开始，偏移量和页大小按 Unicode 码点计数，续读偏移量会考虑序列化输出预算。结果分别说明已记录事件和原文件读取范围是完整、部分、截断还是未知。

原始 `read` 自身可能省略超长行或后续文件范围。恢复功能不能重建该事件没有记录的文字，不能查看当前文件，也不能恢复 shell、PTC、图片或其他工具输出。事件不存在、文本块无效或定位信息超预算时返回错误。它不进行语义比较或交付决策。

[来源插件](src/source-recovery.ts) 定义索引、页面、序列化输出和每会话缓存的可配置上限。缓存只保存成功的原始事件，并按最近最少使用顺序淘汰。重启后索引从记录事件重建；索引不可用不会阻止智能体继续工作。
