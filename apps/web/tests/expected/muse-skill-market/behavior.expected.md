# Skill market browser behavior

- ZIP import and cloud installation retain exact archives and remain disabled.
- An explicit default loads the real Skill body, text references and binary resources in a new agent scope.
- Importing V2 preserves the V1 default; an explicit confirmation selects V2 through compare-and-swap.
- An executed Session retains V1 after the switch and disable; a blank Session and a fresh agent read V2.
- Disabling removes the default from new agents, while installation does not change defaults.
- A real filesystem Skill is prepared through the creator form, exported with its original text and binary resources, and explicitly uploaded as a private draft.
- A creator draft disappears when a different reader account refreshes the page.
- UI disable restores the original composer draft and preserves stored releases; re-enable restores one page and navigation entry.
- Both languages and both themes fit at 1280px and 420px.
- One scripted local model completion binds V1; no external model calls or cloud tenant starts occur.
