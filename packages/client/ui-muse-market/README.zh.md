# Skill 市场界面

[English](README.md) | 中文

## 概述

浏览发行包、管理完整的本地 Skill 包、制作单个来源 Skill，并显式选择新聊天的默认版本。云端草稿与审核使用配置的账号网关。本插件独立于账号设置，卸载后仍保留登录、反馈和首次使用引导。

## 使用本包

在具名 `dsh` profile 中将本包与本地发行包及激活服务一起挂载。Desktop 已提供这些行及可选云端客户端。侧栏导航打开全局面板；设置入口链接到同一面板。所有操作均使用生成的本地、激活与云端 Remote。界面提供中文、英语、日语、西班牙语、法语、德语、俄语和葡萄牙语文案。

选择 ZIP 后立即将其导入为停用状态的本地版本。制作单个来源时保留完整资源与元数据。安装云端版本先核验所选摘要，再导入。通过单独确认，使用此前观察到的归档 SHA 选择默认值；冲突时重新读取当前默认值，并要求重新选择。默认值用于新聊天及首次任务前的空聊天。已执行聊天保留已记录版本；旧有已执行聊天不会补入市场绑定。移除被引用版本时会明确拒绝，并保留其列表项。

没有云端连接或未登录时，仍可本地导入、导出、制作和管理默认值。云端搜索有数量上限，不代表完整目录。刷新会验证当前账号能力；断线或账号变化会撤销私有操作权限。旧搜索及私有响应无法覆盖较新的视图或账号代次。请求失败时，已有可用的本地内容仍保持可见。

上传尝试的原账号 id、请求 key、归档与发布团队会跨面板重挂保留。上传只创建私有草稿。重新登录原账号后可用原 key 重试；其他账号不能复用该尝试。切换选择或制作另一包不会悄悄丢弃未确认尝试。单独的放弃确认会说明服务端可能已存在草稿。提交与审核使用所展示的原发行修订号。审核未确认时读取原 id，不会重新提交更新的修订。

卸载会移除面板、导航、字典、反馈叠层与 Remote 注册。Toast 结果可跨面板导航显示；插件卸载后会抑制晚到结果。[发行包组件](../../host/muse-market/README.zh.md)负责归档校验、存储、激活和云端权限。

发现页将审核发行与原有公开 Skill 目录合并展示；按发行 id 和原资源 id 分别保留内容；名称与版本相同也不会隐藏另一制作组的发行。每个来源独立保留结果和重试状态，一个目录不可用不会清空另一个。下滑可继续显示卡片。原包由 Host 转换后导入，不会自动修改新聊天默认值；Host 在重启后仍提供已校验的原资源与本地归档对应关系。

公开目录独立于本地库存和默认版本读取。某项本地读取失败时，保留已有结果并显示重试提示，不阻断公开搜索。匿名原资源安装在账号权限撤销后仍保留结果；面板卸载仍会抑制迟到回调。

发现页、本地版本、发行详情和制作预览共用用途匹配及角色尺寸对齐规则。已发布的 `presetPortrait` 为已知角色时优先使用；否则由 Skill 名称、标题、分类和简介选择内置角色。鼠标悬停或键盘聚焦可查看 Skill 介绍。图片随应用打包，不依赖生图模型或远程图片服务。

市场使用独立页头、三列角色卡片，以及分为来源 Skill 和 ZIP 两种模式的制作页。修改来源或元数据会取消此前准备的选择，避免上传旧预览对应的包。首次使用指引介绍查找、导入和显式启用；关闭时仅保存原有 `dsh.muse-market.guide.v1` 标记，也可从页头重新打开。

制作入口打开独立主面板，可直接进入来源 Skill 或 ZIP 模式；创作者中心独立列出发行，不依赖本地来源是否可用。ZIP 准备会保留原包，将未绑定的形象写入另一个上传包。预览、导出与上传使用同一份已准备元数据和形象。上传成功后回到发行管理。角色卡支持鼠标、键盘和触摸介绍，图片加载失败时显示内置备用形象。

[独立浏览器入口](src/client/browser.tsx)与 Desktop 共用资源卡片、详情、角色和发布状态筛选。它通过明确的浏览器操作读取公开目录、预览 ZIP、确认上传、审核及下载已校验文件。浏览器不会声称资源已在本地安装，也不会启用默认版本。上传预览使用实际准备的归档，重试保留原字节、账号、团队及请求 key。私有下载保留所选账号和权限代次，任一变化都会丢弃其结果。公开下载不受内部导航和账号切换影响。导入和启用仍由 Desktop 执行。

浏览器上传面板在市场内部导航时保持挂载，保留进行中或结果未确认的上传归档与请求 key。后台完成不会切换当前页面。确认账号变化后，会隐藏前一账号的预览并抑制其完成回调；回到原账号后可用原 key 重试。

浏览器身份读取失败时保留实际原因：网络失败提供局部重试，登录失效提供登录入口。未登录时仍可预览本地 ZIP。在发现页中，非活动上传控件和提示不会进入无障碍树。

## 理解实现

[Remote 适配器](src/client/market-remote.ts)保留生成接口的操作结果及结构化错误。[控制器](src/client/market-controller.ts)负责私有请求代次。renderer 拥有所注册的创作者草稿 store；其中仅保存用户选择和原重试身份，不代替安装或云端账本。组件使用框架 hook、派生 slot props，以及现有 Button、Modal 与 Toast 原语。

## 模型体验

### 显式发行选择

#### 模型看到的内容

面板导航和云端浏览不添加模型消息。`museMarketActivation` 服务与现有 Skill 消费者通过已记录的 Session 绑定及普通 Skill 加载暴露所选版本。

#### Token 影响

UI 状态不消耗模型 token。加载所选 Skill 保持已有目录与指令的 token 行为。

#### KV 缓存影响

导航不改变请求前缀。默认值变化影响符合条件的未绑定聊天；已执行聊天保持原有绑定。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

- 云端操作需要匹配且已配置的服务端。本界面不会部署服务端、自动发布，或更改已执行聊天的版本绑定。全局面板不声称展示某个所选 Session 的绑定。
