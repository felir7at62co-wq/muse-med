# @deepseek-ai/dsh-client-ui-jingliu

[English](README.md) | 中文

## 概述

镜流与 Muse 同站挂载在 `/jingliu/` 时，制片项目、共享资产、余额和项目设置在 Muse 中打开。从右栏「＋」打开「工作间」，可查看当前文件夹或选择新的工作间。独立镜流站点使用原版标签页，剧本工坊单独打开。

「共享素材 → 角色」显示镜流共享目录中人物的原图和特征。

Bot 团队面板有自己的「剧本」、「镜流」、「资产库」和「数据」标签，见[使用此包](#use-this-package)。

内嵌标签保留所打开的文档。切换账号时重新登录。

## 使用此包

Bot 团队面板里，Bot 的对话和群聊都有「镜流」标签，它列出制片项目，新建的排在前面并以标签显示其设置；列表上方是「新建项目」和搜索卡片。从列表或搜索卡片选中的项目在面板里各开一个标签，可以同时打开多个。打开查看不会改变这段对话关联的项目：对话还没有关联项目时，第一个打开的项目成为它的项目；在别的项目标签里发起要求时，那个项目先成为对话的项目，要求再进入输入框。每个项目标签是一个工作台，显示项目的资产（角色、场景、站位图、道具、音频、海报），以及每一集每个镜头的卡片：提示词（标出其中提到的资产）、视频和各个版本、生成参数和素材。视频只在播放时经 Host 读取。新建项目的表单按镜流提供的选项创建项目；「项目配置」只改名称和分辨率，即镜流允许客户端修改的两项。删除镜头在原处确认一次，由镜流立即执行。「引用」「再出一版」「复制」、选择素材、「批量导出」和「生成海报」把引用或准备好的要求放进这段对话的输入框；用户发送后由 Muse 执行。「资产库」标签按类别列出共享素材，用得多的排在前面；点选或拖动一项即可交给输入框。海报、视频、特效、音频、音效和 BGM 尚无共享库，列表为空。

镜流无法读取对话关联的项目时，点击「刷新」重新读取该对话的项目关联。

「数据」标签列出数据站的平台：红果、抖音、绿泡泡、番茄和七猫，每个平台带榜单数或采集端状态。选中一个平台后，它像镜流项目一样在面板里单独开一个标签，默认显示「全收录」：数据站在该平台收录的全部作品，最近采到的在前，搜索框按剧名、作者、编号、简介和标签查找。旁边是榜单：按层级选榜单（例如 男频 · 阅读榜 · 分类），可看日榜、周榜或月榜，每行显示平台自己的两项指标和一个把作品引用到对话的按钮。红果的榜单行另有「转写」，并多一页「储备」，提供转写储备的筛选、搜索、集数进度和「立即转写」。读取和立即转写都经 `museAccount` 的数据站方法以当前登录成员身份进行，所以数据站记录的请求人就是该成员。

「剧本」位于「镜流」之前，默认显示登录账号可以访问的「草稿」。可以新建带集数的空白草稿，导入最多 4 MB 的 Word、TXT 或 Markdown 文件，也可以按剧名找到已有草稿。选择一集后可以引用到会话。Muse 可以为单集提交候选稿。草稿已经打开时，用「刷新」查看最新候选。编辑器对比候选和保存稿，由用户采纳或丢弃，也支持直接手改后保存。若云端稿已更新，需要刷新并重新核对。切换「正文」和「分场剧本」，即可查看和编辑对应稿件。「本集历史」可以预览存档，并把选中的版本恢复为当前稿件的新版本。「导出剧本」支持 Word、TXT 和 Markdown 格式。正文和分场可以导出单集或整部剧，混合内容和大纲按整部剧导出。「定稿入库」先确认版权、剧本形式和画面风格，再将整份草稿保存为定稿库版本。

所有成员都能查看「定稿剧本」，可按剧名、阶段和归属筛选。剧本在自己的面板标签中打开，显示版本、版权、来源与分集正文。有选用权限的成员可以选用当前版本，再关联已有的镜流项目，或把「新建镜流项目」请求放进输入框。来源卡片展示数据站记录。

<a id="model-experience"></a>
## 模型体验

### 打开工作台

#### 模型看到什么

打开编剧页面 `/v2` 或制片页面 `/sfp/` 均不会添加提示词、工具或会话事件。确认制片项目后，Host 将项目名和编号作为通知记入当前会话。

#### Token 影响

打开面板不消耗模型 token。

#### KV 缓存影响

浏览工作台不改变模型请求前缀。

<a id="known-limitations-and-deferred-work"></a>
## 已知限制和后续工作

- 独立部署的嵌入页需要允许 Muse 显示页面。部署[工作台登录适配器](../../../services/muse-workbenches/README.zh.md)后，两套工作台通过 Muse 账号网关登录。
- 打开草稿或切换集数不会改变会话要处理的对象。使用「引用到对话框」可在消息里带上草稿编号和选中的集数。
