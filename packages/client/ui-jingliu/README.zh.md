# @deepseek-ai/dsh-client-ui-jingliu

[English](README.md) | 中文

## 概述

镜流与 Muse 同站挂载在 `/jingliu/` 时，制片项目、共享资产、余额和项目设置在 Muse 中打开。右侧「环境」显示本机工作间，「添加工作间」可选择或新建本地文件夹。独立镜流站点使用原版标签页，剧本工坊保留单独的写作入口。

「共享素材 → 角色」显示镜流共享目录中人物的原图和特征。

Bot 团队面板有自己的「剧本」、「镜流」、「资产库」和「数据」标签，见[使用此包](#use-this-package)。

内嵌标签保留所打开的文档。切换账号时重新登录。

## 使用此包

Bot 团队面板的「镜流」标签列出制片项目，新建的排在前面并以标签显示其设置；列表上方是「新建项目」和搜索卡片。从列表或搜索卡片选中的项目在面板里各开一个标签，可以同时打开多个。打开查看不会改变这段对话关联的项目：对话还没有关联项目时，第一个打开的项目成为它的项目；在别的项目标签里发起要求时，那个项目先成为对话的项目，要求再进入输入框。每个项目标签是一个工作台，显示项目的资产（角色、场景、道具、音频、海报），以及每一集每个镜头的卡片：提示词（标出其中提到的资产）、视频和各个版本、生成参数和素材。视频只在播放时经 Host 读取。新建项目的表单按镜流提供的选项创建项目；「项目配置」只改名称和分辨率，即镜流允许客户端修改的两项。删除镜头在原处确认一次，由镜流立即执行。「引用」「再出一版」「复制」、选择素材、「批量导出」和「生成海报」把引用或准备好的要求放进这段对话的输入框；用户发送后由 Muse 执行。「资产库」标签按类别列出共享素材，用得多的排在前面；点选或拖动一项即可交给输入框。海报、视频、特效、音频、音效和 BGM 尚无共享库，列表为空。

「数据」标签列出数据站的平台：红果、抖音、绿泡泡、番茄和七猫，每个平台带榜单数或采集端状态。选中一个平台后，它像镜流项目一样在面板里单独开一个标签：按层级选榜单（例如 男频 · 阅读榜 · 分类），可看日榜、周榜或月榜，每行显示平台自己的两项指标和一个把作品引用到对话的按钮。红果的榜单行另有「转写」，并多一页「储备」，提供转写储备的筛选、搜索、集数进度和「立即转写」。读取和立即转写都经 `museAccount` 的数据站方法以当前登录成员身份进行，所以数据站记录的请求人就是该成员。

「剧本」标签在「镜流」之前，列出剧本工坊的定稿剧本，所有成员都能看：可按剧名搜索、按阶段（待挑选、已选用、已投产）或只看自己的筛选，每张卡片显示创建人、集数、字数和剧本形式。剧本在自己的面板标签中打开：左侧是参数（剧本名称、创建人、版权、原小说/剧、剧本形式、集数、字数、版本、状态），右侧逐集显示正文，场景、动作和对白分开排版。点原小说/剧会展开它在数据站的记录：平台、榜单与名次、指标、标签和采集日期。有选用权限的成员选用当前显示的版本，再关联已有的镜流项目，或把准备好的「新建镜流项目」请求放进输入框，由 Muse 用 `script_library` 完成。「引用到对话框」把剧本或当前这一集的引用放进输入框。

## 模型体验

### 打开工作台

#### 模型看到什么

打开编剧页面 `/v2` 或制片页面 `/sfp/` 均不会添加提示词、工具或会话事件。确认制片项目后，Host 将项目名和编号作为通知记入当前会话。

#### Token 影响

打开面板不消耗模型 token。

#### KV 缓存影响

浏览工作台不改变模型请求前缀。

<a id="known-limitations-and-deferred-work"></a>
## 已知限制和后续工作

- 独立部署的嵌入页需要允许 Muse 显示页面。部署[工作台登录适配器](../../../services/muse-workbenches/README.zh.md)后，两套工作台通过 Muse 账号网关登录。
- 两套应用各自管理账号会话、草稿和项目。选择页面或切换标签不会将草稿导入镜流，也不会替会话工具选择项目。
