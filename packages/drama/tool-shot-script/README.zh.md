# @deepseek-ai/dsh-tool-shot-script

[English](README.md) | 中文

## 概述

使用 `drama_shot` 校验导演格式脚本、预演打包时长或编译 matched JSON 与单集文件。长镜头、慢台词、旁白与心声可以通过，并附建议性警告。字段格式错误、已绑定资产未确认或信息不完整、角色状态与资产自己登记的值不一致、超过项目自己声明的每镜上限，以及超出调用方明确时长预算的包仍阻止编译。工具保留台词原文与说话人身份，不调用提供方。

## 使用本包

在短剧预设中把插件挂载到工具注册表旁。`actionShotSeconds` 默认 2，接受 1–4 整数秒；它用于估算没有明确时长或复杂度的无声镜，不是镜头时长上限。

| 方法 | 必填输入 | 结果 |
|---|---|---|
| `validate` | `script`；可选 `assets`、`project`、`episode` | 只读镜头事实、失败与警告 |
| `preview` | `script`、`assets`、`max_submit_seconds`；可选 `project`、`episode` | 只读打包方案 |
| `compile` | preview 输入加 `project`、`episode` | matched JSON 与单集文件；校验失败不写入 |

任何方法给了 `episode` 都会保留，因此单独的 `validate` 也能拒绝登记集数不覆盖本集的资产。

`max_submit_seconds` 是依据项目所选模型能力确定的单包提交总时长上限，包含至少一秒自然收束。已核实的模型修订中，Seedance 2.0 为 4–15 秒，Seedance 2.5 为 4–30 秒。每个分镜的实际时长按对应包返回的 `submit_seconds` 填写，不把这个上限套给全部分镜。编译器不读取提供方能力。

### 角色状态与资产自己的登记值

`主体状态追踪` 里每个入画人类主体用一条普通字段声明身体状态：`身体状态：【孕早期（孕八周）；孕期职场装；长发】；`，写在该主体所在段落里（不带名字），或写成带主体名的一行。其中两项各占一个维度——孕期阶段与年龄段，这两个决定身形——其余都是妆造版本登记值必须包含的状态文字，服装、发型与伤病一视同仁。没有体型变化的角色写 `非孕期`。`孕八周`、`怀孕8周`、`怀孕十三周` 都读成 `孕早期`；`十四周` 起是 `孕中期`，`二十八周` 起是 `孕晚期`；只写 `孕期` 而没写周数或阶段读成 `孕期待定`；一处写了两个不同阶段读成矛盾。

该角色绑定的资产必须在 `state_or_costume` 里连同资产名登记相同的孕期与年龄维度。妆造版本还必须登记镜头写出的其他状态条目。只有一侧写了某个维度就是 `未标阶段`，因为版本尚未确定而判定绑定失败。登记必须写 `episodes`：具体集号数组，或全剧标记 `all`/`全剧`；调用给了集号时，登记不覆盖该集就拒绝绑定。

某个被点名的角色在清单里没有任何一版登记了所需维度时，产出的是补料需求而不是绑定：点名角色、阶段、服装、新资产用于哪几集、已登记的版本，以及可执行的补料路径（从资产库复用，或生成后登记，再跑 `drama_assets reconcile`，然后重新校验）。

清单的资产数组读 `assets` 或 `items`：项目自己的清单用 `items`，旧的分镜脚本副本用 `assets`。

明确的 `出镜人物` 名单按完整正式名或登记别名决定绑定哪些人类角色；人名仅仅包含在另一个人的名字里不构成匹配。没有名单时，绑定器读取画面说明，排除台词、说话人信息、`核心场景` 与 `关键道具` 字段。运镜与位置描述中已登记的场景、道具名或别名不构成人物入画证据：`李军家`、`李军的碗` 不会绑定李军。真实的独立人物动作和主体追踪仍参与推断，较短道具名也不会抹掉包含它的人名，例如老算盘。正式名与登记的 aliases（分隔字符串或名称数组）解析到正式资产；具体长名覆盖其内部命中的短名。未限定版本的角色名，只有在适用集数与已声明身体状态共同确定唯一版本时才选用。多个可用版本返回 `asset_binding_ambiguous`，列出候选身份与修法；写明目标完整资产名或更正登记。明确出镜名单中的未知名字返回 `unregistered_character`。身体局部和姿态描述仍可与同一主体已登记状态配合使用。`关键道具：无` 阻止道具推断。

`character_name` 可登记供应商标签不同的多个版本共同所属的剧情人物名，不同人物不能共用它。

明确登记 `reference_scope: "identity"` 的人物身份图只提供身份参考，服装、妆造、姿态和表情保留本镜正文要求；年龄和身体阶段仍须一致。匹配的专用妆造版本优先于身份图回退。不写此字段或填写 `"appearance"` 保留严格的登记妆造匹配。不能把专用服装图标为身份图来绕过冲突。

反复出镜的动物主体登记为 `type: "动物"` / `"animal"`，或保留 `type: "角色"` / `"character"` 并加 `subject_kind: "animal"`。即使有人的出镜名单，画面说明中的动物正式名与 aliases 仍会绑定；仅台词提及不会绑定。动物进入包的素材名与 key，仍检查官方确认、ID、URL 和适用集数；绑定的动物分类贯穿反复打包，即使声明身体状态也不计入人物人数，无需声明人的孕期、年龄或服装。角色行未写 `subject_kind` 时保留人的状态门禁；绑定器不根据名字猜物种。多个动物版本需用完整名或互不重叠的适用集数区分。

每个 preview 或 compile 包返回完整 `prompt`，保留镜头正文，补充明确的人物、场景和道具参考及自然收束要求。已有引用将登记别名归一为正式名，同一资产复用一个 key；缺少引用时使用 `asset_<jubian_asset_id>`。引用其他人物、错误父资产 key，或多个角色共用同一 key，会返回 `material_reference_mismatch`。`material_bindings` 按 key 首次出现顺序明确列出正式名、父资产 ID、material ID、URL 和参考范围；选源直接使用这些行，不拼接 `material_keys` 与 `material_names` 的下标。重复提及共用一个素材。重复完成提示词时，即使打包器不再持有原清单，每个镜头内每项资产的身份说明仍只保留一份。matched 输出第 5 版包含这些映射。单独 validate 可选；preview 和 compile 执行相同检查。

完成提示词时逐镜声明选中的人物身份和人数上限，允许近景、局部入画和遮挡，不强迫所有人同框。重新编译时按当前选择重建已有的派生人数范围。无人镜保持无人，画外发声、来源场次人物表和其他镜头不增加人物。同一资产的脸部、服装和多视角属于同一人，跨镜复用也不新增人物。身份说明保留区分人物的面部特征和年龄感，同时尊重正文明确变化及选中的正式版本；道具说明沿用正式图的外形、结构、材质和颜色，不按泛名替换。这些是生成提示，编译器不查看像素，不发明胡须或材质，也不保证生成结果必然符合。

### 项目自己的要求

每个方法都会读取所属项目自己的要求：调用给了 `project` 就用它，否则从脚本所在目录向上找最近的 `project_config.json`（最多四层）——与流水线自己的脚本定位项目根的方式一致。目前读取的唯一要求是 `delivery.max_effective_chars_per_shot`，即项目自己声明的每镜有效字上限。它的效力高于本工具的内建数值：超过它判失败而不是警告，因为项目写明的要求不是建议；拒绝文案同时给出两条正当出路——按原文语义拆句，或改掉该项目的这条要求。项目配置没有这个键、或根本解析不了时，内建数值仍然只作建议。键存在但不是正整数时会直接让本次调用失败，而不是被忽略。

### 脚本与时长

镜头使用连续编号的 `【镜头N】` 块。可选 `时长：N秒` 声明安全正整数时长，优先于估算。省略时，有发声镜按 `max(1, ceil(有效字 / 8))`；无声镜按 `动作复杂度：简单/一般/较复杂/复杂`（1/2/3/4 秒），再回退到配置默认值。有效字数汉字、拉丁字母与数字，不数标点与空格。明确时长行不进入 matched 镜头的画面提示词。

独占一行的 `场次54-1：地点 时段 内/外` 标题归属于随后的镜头，直到下一条同格式标题；不会进入前一镜。每个所属提示词以 `来源场次（原文段落）` 保留标题在 `｜` 或 `|` 注释之前的原文，首镜前的标题也保留。出场人物注释、场次对照汇总及动作或台词中的提及不提供此上下文。它保留原文段落的时段与地点，不参与资产选择，也不覆盖本镜的内外插镜：具体视野和登记场景仍以本镜画面与 `核心场景` 为准。源文件偏移和问题行号不变。

结果区分 `failures` 与 `warnings`；只有失败阻止打包方案与写入。

风格声明保留项目的媒介选择：真人项目用 `真人短剧写实风格`，3D CG 项目用 `写实3D CG渲染风格`。编译器保留已声明的行，不会把一种媒介替换为另一种。matched 的 `production_mode: "live_action"` 是历史编译流水线标签，不是媒介选择开关。实际风格以每镜明确声明和项目确认的画面参考为准；提供方尚未映射的代码（例如 `0`）不能证明是真人风格。


| 检查 | 结果 |
|---|---|
| 超过 15 或 36 有效字；声明时长偏离估算 | 警告：核对节奏与实际发声，不强制拆镜 |
| 超过项目 `project_config.json` 里声明的 `delivery.max_effective_chars_per_shot` | 失败（`speech_exceeds_project_limit`）：按原文语义拆句，或改掉该项目的这条要求 |
| 旁白/心声声明 | 警告；以 `vo` 保留包括冒号在内的完整正文，用 `说话人` 指定发声角色 |
| 缺少建议的写实风格或固定负面词 | 警告；不自动补入任何一句 |
| 画面正文或台词里的秒数表达 | 警告；保留文字，不从正文推导时长 |
| 缺少镜头块、编号不连续、明确时长格式错误 | 失败 |
| 空/占位台词、多条台词、action 同时带台词 | 失败；不静默丢弃含糊的发声内容 |
| 导演格式对白没有说话人；显式说话人与台词角色前缀冲突 | 失败（`missing_speaker` / `speaker_mismatch`）；保留声明身份，编译前按原文解决冲突 |
| 无声镜复杂度未知或人物占位 | 失败 |
| 台词与动作复杂度并存 | 警告：明确时长优先；否则复核发声估算时长 |
| 明确场景未登记、绑定资产未确认或不完整 | 失败 |
| 清单某行的 `type` 不是绑定规则认的拼法 | 失败（`asset_type_unusable`）：这一行谁也绑不上、别的规则也不会发现，所以说明里点出第几条、资产名、读到的值、允许的拼法与修法；读得出来的行仍在同一次运行里照常参与 |
| 已挂角色没有 `身体状态`，或声明里没有维度 | 失败（`shot_body_state_missing`、`shot_body_state_unusable`）：在该主体的 `主体状态追踪` 段落里补声明 |
| 登记维度不一致、登记值没有阶段，或缺少镜头要求的服装/发型 | 失败（`asset_state_mismatch`、`asset_state_unregistered`）：改登记，或改挂写了这一版状态的资产 |
| 登记没有 episodes、读不出集号，或未覆盖本次编译的集号 | 失败（`asset_episodes_unregistered`、`asset_episode_mismatch`） |
| 被点名的角色在清单里没有登记所需维度的版本 | 失败（`asset_state_missing`），并带完整补料需求 |
| 多个可用角色版本，或明确出镜名单里的未知角色 | 失败（`asset_binding_ambiguous`、`unregistered_character`）；编译前确定版本或登记角色 |
| 未绑定场景 | 警告 |
| 单个不可拆镜头超过 `max_submit_seconds - 1` | 失败（`shot_exceeds_package_budget`），绝不截断镜头 |

打包保留完整连续镜头，在场景变化或 `子任务边界：是` 时切包，并确保内容加至少一秒收束不超过明确预算。短包增加自然停留至四秒请求下限，不新增台词。提交前用实际分镜核对 `submit_seconds`；编译不会修改分镜已存时长。

### 文件

编译写入 `prompts/<episode>.txt`、`matches/<episode>.matched.json`，以及含 `package.json`、`shot_script.txt`、`matched.json`、`episode.txt` 和本地绑定资产的 `episode_packages/<episode>/`。集号补成两位。提示词文件是不变的源文件副本；matched 镜头画面去掉时长字段，并包含补齐的素材引用。每个 `video_tasks` 行保存完整包 `prompt`、有序 `material_keys` 与对应的 `material_bindings`。分集正文或本地资产文件缺失会在写入前失败。结果列出全部写入路径、逐镜时长、包时长与有序素材键。

## 模型体验

### `drama_shot` 工具

#### 模型看到什么

[工具目录](../../../docs/tool-catalog.zh.md#deepseek-aidsh-tool-shot-script)记录方法 schema。结果暴露 `shots`、`packages`、`failures`、`warnings`、`written` 与汇总计数。警告带可执行建议，从不要求删改台词原文。`duration_source: declared` 表示明确声明的时长。 同名角色、场景和道具登记保留实际选中的远端 ID；场景和道具版本必须有唯一的集数覆盖，多条登记同时符合时报告 `asset_binding_ambiguous`。

#### Token 影响

schema 固定；结果随镜头、完整包提示词与问题数增长。失败时不打包、不写入，但保留诊断行。

#### KV Cache 影响

工具结果追加，不改写已有消息。工具描述或 schema 改动会改变可复用请求前缀。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

- 编译只在本地进行。调用方提供已确认的分镜预算；计费提交必须独立校验实际模型设置与主体身份。
- 估算不是实测音频时间。最终剪辑交付前核对录制的发声。
- 资产匹配使用本地清单名、aliases、适用集数和声明状态；不核验远端项目归属，也不从自由画面正文推断尚未登记的角色。
- 状态门禁比对的是声明的维度与镜头写出的服装文字，不比对资产设定板图片本身：登记值对而图不对的情况仍由模型复核负责，短剧技能要求在提交前完成该复核。
- 场景是连续性键；时间/服装变化需要明确切包标记。
- 写入前会预检，但不是跨并发进程的事务。

镜头边界使包数超过理论最少值时，打包会增加包数。每个输出包均复核内容时长上限；单个不可拆镜头超限时失败并指出镜号。
