# @deepseek-ai/dsh-session-video

[English](README.md) | 中文

## 概述

浏览会话中记录的视频，并检测已有视频中按时间排列的镜头区间。本地工作区引用、已呈现文件、上传的视频附件、受支持的生成结果，以及成功的剧变媒体结果，均保留其原始会话坐标。切镜检测在必要时下载已核验的剧变媒体，并在本地运行 FFmpeg；它不发起模型或生成请求。结果引用原视频的时间区间，并保留原始字节。

<a id="use-this-package"></a>
## 使用此包

Host 组合将此插件与 Session 查询和投影、工具注册表、文件系统和附件提供者、子进程执行、沙箱策略，以及经过认证的 Client 连接一起挂载。Client 使用生成的 `sessionVideo` Remote 服务。

### 已记录来源与检测

`list` 返回已记录视频的标识、事件坐标、文件或提供者版本、播放地址和可用性诊断。清单接纳用户显式文件引用和上传的视频附件、已呈现视频、受支持的本地生成输出，以及成功的剧变工具结果。助手正文和任意 Client URL 不会引入视频来源。清单达到数量上限时会报告覆盖不完整，不会将省略后续内容的结果表示为完整清单。

来源可以包含从已记录的成功剧变与 `muse_production` 结果重建的 `production` 定位：远端项目、分集、分镜卡、任务与子任务 ID、显示集号、视频包序号，以及创作镜号。直接调用与已提交的 PTC 分派使用相同提取规则。未知或冲突的关联保持缺失，文件名不决定所属集数。创作镜号不标识 FFmpeg 检测的视觉切镜。元数据达到上限时报告覆盖不完整并省略制作分组，保留可播放来源。这些新增字段保留来源标识，并重建不兼容的私有投影检查点；它们不查询提供者，也不授予生成权限。

`detect` 接收 Session 标识，以及 `list` 返回的来源标识和版本。检测会拒绝过期版本，探测时长和尺寸，然后通过 FFmpeg 检测视觉变化。首次下载提供者视频后，就绪结果携带所下载内容的版本；将结果与播放关联前须刷新 `list`。就绪结果以按时间排序、非空的区间覆盖整个原视频；连续视频包含一个区间。失败结果不包含镜头区间，并提供诊断。调用者取消后，会在所属子进程结束后拒绝请求。

本地播放使用与 Session 绑定且经过认证的字节范围路由。已核验的公开剧变 URL 可以直接播放；检测通过现有的受限剧变下载器获取字节，并保存到附件存储。下载不携带凭据，拒绝重定向，并遵守配置的字节和超时上限。任何方法都不接受 Client 提供的任意来源路径或 URL。

`muse_video list` 向 Agent 提供清单。`bind` 在核对 SHA-256、视频时长和已有证据文件标识后，为已记录的来源版本保存明确的制作定位及可选的实测 `shotRanges`。证据的语义由调用者负责：计划时长和切镜顺序不能确定创作镜头的时间。绑定可从 Session 重放恢复，包括保留的工具元数据；视频版本变化后，清单不再使用旧绑定。修改预览应单独呈现和绑定，以在同一集保留两个版本。

`muse_video review` 返回最近一次用户所选版本和区间的带时标画面以及实测视频信息。运行时上下文不会替换该选区。只读意图允许读取视频清单、限定审阅、工具发现和回读所选视频已绑定的分镜卡，并禁止整片扫描与媒体修改。不含只读意图的新消息恢复普通工具访问，并定义下次视频范围。若指定时间之后、区间结束之前没有画面，结果在 `unavailable_seconds` 中报告。整个区间没有可解码画面时明确失败。提取的图片保存在附件存储。

审阅按已对应的创作镜头核对剧本、已有的人物绑定和适用的交付要求。结果区分制作方案中的绑定与成片实际表现，也区分成片交付规格与原始镜头验收。已完成的本地转写可提供所选区间内的对白。审阅会解析回执的来源路径并校验视频摘要，确认回执对应同一视频。审阅使用已保存的转写结果，不会提交转写任务。依据不足的项目标为待核验。抽帧无法确认连续动作、说话人身份或口型同步。建议列出剧本要求、带时间点的差异与具体改法。原始文件保持不变。

选区提供 `review_link` 时，结果要求助手为每个有依据的问题提供一条建议链接。`at` 指向采样时刻，`problem`、`basis` 和 `suggestion` 分别携带画面发现、对应的剧本或交付要求和可编辑改法。链接保留原来源、版本和所选区间。[Client](../../client/ui-session-video/README.zh.md) 校验目标后定位问题画面，也可按原选区准备未发送的修改请求。

<a id="tool-failures"></a>
### 工具失败

`muse_video` 的预期失败是错误工具结果（`isError: true`），身份位于 `error.info.name` 和 `error.info.code`。缺少 Agent 上下文使用 `ToolContextUnavailableError`（`TOOL_CONTEXT_UNAVAILABLE`）；绑定元数据和区间约束等无效参数使用 `ToolArgsError`（`INVALID_ARGS`）。视频领域失败使用内部的 `SessionVideoError`，其错误码由 [`src/errors.ts`](src/errors.ts) 拥有。已有 `HarnessError` 身份和调用方取消沿工具路径传递。

消费者用这些身份处理失败，用消息展示诊断。来源或版本变化后刷新清单并重新选择；重试前修正无效参数，或选择符合处理上限的媒体。遇到忙碌结果时等待活跃任务结束，绑定校验失败后核对来源字节与证据。被包装的外部失败在 Host 错误对象中保留原始原因。重新绑定或审阅前先解决所报告的条件。Remote 检测的 `failed` 状态和播放 HTTP 失败保留各自的响应语义。

### 配置

插件没有必填配置字段。所属 Host 组合提供注入服务；可执行文件路径和处理上限由部署配置决定。

| 字段 | 默认值 | 含义 |
|---|---|---|
| `ffmpegPath`, `ffprobePath` | `ffmpeg`, `ffprobe` | 在配置的执行环境中解析的可执行文件 |
| `sceneThreshold`, `analysisWidth`, `minShotSeconds` | `0.3`, `320`, `0.08` | 视觉变化阈值、分析宽度和保留区间边界的最小间隔 |
| `maxSources`, `maxResultBytes` | `500`, `4194304` | 清单数量和结构化工具结果解析上限 |
| `maxSourceBytes`, `maxDurationSeconds`, `maxSourcePixels` | `536870912`, `3600`, `33177600` | 输入字节、时长和视频轨像素数量上限 |
| `maxShots`, `maxConcurrent`, `maxCachedAnalyses` | `500`, `2`, `128` | 完整区间数量、并发检测和进程内缓存结果上限 |
| `commandTimeoutMs`, `downloadTimeoutMs`, `graceMs` | `180000`, `60000`, `1000` | 子进程期限、下载期限和进程终止宽限期 |
| `maxOutputBytes`, `playbackChunkBytes`, `maxPlaybackStreams` | `8388608`, `262144`, `8` | 命令输出大小、播放读取块大小和活跃播放数量上限 |
| `reviewFrames`, `maxReviewSeconds`, `reviewFrameDimension` | `6`, `60`, `960` | 采样数、区间时长上限和审阅图片的最长边 |
| `maxReviewEvidenceBytes` | `16384` | 单份参考资料或转写回传给审阅的字节上限 |

[`src/index.ts`](src/index.ts) 中经过验证的 schema 定义可接受范围。提高来源处理上限不会扩大固定的剧变下载来源允许列表。

## 理解实现

<details>
<summary>实现内部细节——点击展开</summary>

私有 Session 投影保留受限的来源坐标和尚未结束的受支持工具调用。显示名称取自已记录的本地路径、附件名称，或去掉查询参数的提供者 URL。文件系统补充当前可用性和版本，不改动 Session 历史。来源标识将 Session 与精确的已记录坐标绑定；镜头标识还绑定来源版本和区间端点。只有当前文件版本与缓存版本一致时，成功的分析结果才会复用。分析和下载缓存超过配置上限时，会淘汰最早插入的条目。

服务通过文件系统提供者获取执行路径。探测和画面分析子进程读取视频字节，仅向标准输出或空设备写入；受限 Session 的策略收窄为只读，`danger-full-access` 保持不变。分析不获取工作区写入授权，也不创建素材。它在检测后，以及每次播放读取前后重新检查文件版本。插件卸载时取消操作和流，等待子进程及未完成读取结束，并移除播放路由。处理辅助函数返回完整结果或显式错误，不会截断成功的镜头列表。

| 文件 | 职责 |
|---|---|
| [`src/index.ts`](src/index.ts) | Remote 方法、来源解析、受限下载、播放和生命周期 |
| [`src/sources.ts`](src/sources.ts) | 私有来源投影和已记录结果解析 |
| [`src/production.ts`](src/production.ts) | 已记录制作关联与无歧义的来源分组 |
| [`src/media.ts`](src/media.ts) | 子进程归属、已验证的视频信息和完整切镜区间 |
| [`src/errors.ts`](src/errors.ts) | 视频工具错误类与稳定错误码 |
| [`src/types.ts`](src/types.ts) | Client 可见的清单、来源和区间类型 |

<a id="model-experience"></a>
## 模型体验

### Client 中的视频检查

#### 模型看到的内容

`muse_video` 工具提供清单、绑定和限定审阅操作。结果在普通工具历史中保留来源版本、明确的制作定位和采样图片。清单、播放和切镜检测仍为 Client 检查数据，不请求模型轮次。

#### Token 影响

工具定义和结果消耗请求 token；审阅图片消耗图片输入 token。Client 清单、播放、下载和 FFmpeg 检测不构建模型输入。

#### KV Cache 影响

工具调用追加普通历史，审阅图片可能增加请求后缀。仅 Client 侧的检查保留请求前缀。缓存可用性仍由提供者负责。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

以下限制适用于视频发现和切镜解释。

- **仅检测视觉切镜**——检测区间不识别剧情场景、角色、台词或戏剧情节连贯性；淡入淡出和渐变过渡可能仍在同一区间内。
- **原视频区间**——检测不创建独立片段文件、缩略图、剪辑或替换生成。Client 可以从播放来源截取预览帧。
- **仅支持已记录的特定来源**——省略任意助手链接和未识别工具结果。丢失或不可访问的已记录文件保留可见诊断；不支持的剧变来源不能下载。
- **进程内分析缓存**——Host 重启会丢弃分析和已下载来源的查询记录。已保存的按内容寻址的附件字节遵循附件存储的生命周期。
- **可执行文件与编解码器可用性**——配置的执行环境必须具有 FFmpeg、FFprobe、文件系统访问能力和兼容解码器。达到上限、不支持的输入和隔离失败返回诊断，不编造镜头。
