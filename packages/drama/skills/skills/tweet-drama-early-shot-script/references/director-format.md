# 导演镜头文本示例

适用于项目已确认的真人或3D风格，不规定写作顺序或审校轮次。下面的人物和剧情均为虚构离线示例，不能代替用户原文或正式素材。写卡使用 `jubian_storyboard` 的预览、保存和真实回读，具体参数以当前工具说明为准。

## 字段

| 字段 | 写法与用途 |
|---|---|
| 镜头编号 | 独占一行 `【镜头1】`，逐镜连续编号。每镜声明项目已确认的风格；真人用 `真人短剧写实风格`，写实3D用 `写实3D CG渲染风格`，不得因此更改项目风格或画幅。 |
| 出镜人物 | `出镜人物：温雨、温雪` 只列实际可见的人物。使用完整剧情名、正式资产名或明确登记的别名；没有可见人物时省略整行。台词提及、同场画外说话人和记忆音不加入名单，也不写入其身体追踪。 |
| 核心场景 | `核心场景：后厨` 使用本项目已确认的正式场景名。该字段不是场次标题；没有正式场景资产时保留画面位置描述并报告缺项，不编造场景 ID。 |
| 关键道具 | `关键道具：钥匙` 指向正式道具；确实没有道具时可写 `关键道具：无`。 |
| 主体状态追踪 | 每个入画人物各写自己的 `【姓名】-位置：【…】；`，下一行写 `身体状态：【非孕期；青年；服装；发型】；`，再写动作、朝向、手部与情绪。姓名使用该人物的正式名或登记别名，不把别人的状态写入本段；年龄/孕期等信息来自原文或已确认资产，不猜。 |
| 台词与发声 | 有声镜写 `台词：温雨：原文`，可声明 `发声类型：dialogue`。无声镜写 `发声类型：action`，省略台词行，不写假台词“无”。画外续说用 `台词：温雨（画外音）：原文`；原文明确的 OS/心声可分别写 `说话人：温雨`、`发声类型：vo`、`台词：温雨：原文`，不把发声方式当新人物。 |
| 镜头预算 | 时长与画面正文分开记录，实际生成时长通过当前工具参数设置，不把秒数写进运镜、动作或提交的视频提示词。有声按8个有效字/秒估算，无声按动作复杂度和表演需要安排。 |

同一人的不同服装版本仍属同一角色，不把不同人混成一个身份。身份母版只参考本人面孔和身份，镜头保留原文服装、发型、动作与表情，年龄/孕期仍须一致；专用妆造参考核对已确认的服装与发型。不为匹配参考删掉正文妆造或改写资产事实。

场景按本镜实际内外与动作选择，结合正式图片里可见的门窗、炕床和布局，不靠资产同名认定适配。人物在炕上起身仍是室内镜，不能使用房屋院外图；走出门后的院外镜再使用外景。一个动作跨过室内与室外时拆成各自的镜头，分别填写核心场景。原文没有的空间关系不当作参考已证实的事实。

`vo` 只归类发声，不替代原文的 OS、心声、记忆音或当前画外对白语义。保留原句，用说话人、台词与镜头正文表达：OS/心声写明内心独白，画面人物不对这句发声、不按该句对口型，表情动作仍按原文，不强制闭嘴；记忆音写明回忆中的声音，不改成当前场景正在说话。视频提示词也保留这些说明，不强迫声源入画；原文没有可见回忆画面时，不为记忆音新增人物镜头或人物图引用。

## 配速与单集时长

配速作用于视频包内部：对白速度、动作展开、停顿和切镜共同决定这个包的观看节奏。8个有效字/秒、常见镜头1–4秒等是包内设计的参考，不能把整集字数除以8后当作集长，也不能拿单集时长目标反推每包或每镜应占多少秒。首次制作按完整内容、表演需要与当前模型能力估算各包，独立记录预算，不按模型上限填满。

已有视频包或任务卡的时长、对白速度、动作停留与切镜节奏，只有在用户明确要求调整这些包或卡时才修改；用户只要求统计、查看或调整单集总时长，均不构成改包配速的授权。目标包、修改范围或含义不清楚时，保留当前内容、时长与节奏描述，先澄清；已明确授权的范围直接执行，不逐包重复索要批准。用户已经修改的内容继续按当前稿保留。

原始包总长是本集实际采用的视频包时长之和；成片时长按实际取用片段汇总，并扣除裁切和转场重叠。增加或移除包、调整取用片段会改变集长，仍须符合对应的制作或剪辑授权；重复卡、历史版本和未采用包不重复计入。计划预算与实测媒体时长分别报告。单集目标、最低时长或汇总差额只用于核对结果，不改变各包时长分配。

例如三个已有包各12秒，原始总长为36秒；用户说“一集最好不低于40秒”时，报告目前36秒、距目标差4秒，并澄清是否及如何处理相关包或剪辑。不要直接把三包都改为15秒，不为补差额新增空镜、延长反应或追加“不急着切”等慢节奏指令。用户明确要求“这三个视频包都改成15秒”后，才按该范围调整并回读，汇总为45秒。这是Agent的操作指导，不增加工具审批或执行拦截。

## 完整镜头文本

示例换装前后分别描述人物状态，第三镜只拍温雪，周明在画外说话，因此不引用周明图。示例正文是虚构剧情，不能代替用户原文；实际人物状态与服装必须有来源。
