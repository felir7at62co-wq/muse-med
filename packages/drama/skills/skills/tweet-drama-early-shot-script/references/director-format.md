# drama_shot 导演文本与调用格式

这是当前工具的格式参考，适用于项目已确认的真人或3D风格；它不规定写作顺序或审校轮次。使用已打包技能资源和当前工具 schema 即可，不需要读取仓库源码。下面的人员、ID、URL和剧情均为虚构离线示例，不能当作用户项目的正式素材。

## 字段

| 字段 | 当前写法与用途 |
|---|---|
| 镜头编号 | 独占一行 `【镜头1】`，逐镜连续编号。风格声明只读取紧贴本镜编号的前一行，不跨镜继承；缺失返回 missing_style_line 警告。真人用 `真人短剧写实风格`，写实3D用 `写实3D CG渲染风格`；不得因此更改项目风格或画幅。 |
| 出镜人物 | `出镜人物：温雨、温雪` 只列实际可见的人物。使用完整剧情名、正式资产名或明确登记的别名；没有可见人物时省略整行。台词提及、同场画外说话人和记忆音不加入名单，也不写入其身体追踪。 |
| 核心场景 | `核心场景：后厨` 使用本项目清单的正式场景名。该字段不是场次标题；没有正式场景资产时保留画面位置描述并报告缺项，不编造场景 ID。未绑定场景会返回 `no_scene_bound` 警告。 |
| 关键道具 | `关键道具：钥匙` 指向正式道具；确实没有道具时可写 `关键道具：无`。 |
| 主体状态追踪 | 每个入画人物各写自己的 `【姓名】-位置：【…】；`，下一行写 `身体状态：【非孕期；青年；服装；发型】；`，再写动作、朝向、手部与情绪。姓名使用该人物的正式名或登记别名，不把别人的状态写入本段；年龄/孕期等信息来自原文或已确认资产，不猜。 |
| 台词与发声 | 有声镜写 `台词：温雨：原文`，可声明 `发声类型：dialogue`。无声镜写 `发声类型：action`，省略台词行，不写假台词“无”。画外续说用 `台词：温雨（画外音）：原文`；原文明确的 OS/心声可分别写 `说话人：温雨`、`发声类型：vo`、`台词：温雨：原文`，不把发声方式当新人物。 |
| 镜头预算 | 可独立写 `时长：2秒`，只接受正整数秒。该行优先于估算，编译返回的包 `prompt` 会去掉它；不要把秒数写进运镜、动作或视频提示正文。省略时，有声按8个有效字/秒向上取整，无声按 `动作复杂度：简单/一般/较复杂/复杂` 记1/2/3/4秒，未写复杂度默认2秒。 |
| 子任务边界 | `子任务边界：是` 表示本镜之后结束包。时空、服装或连续性发生变化而沿用相同场景资产时，仍在变化前的末镜写此字段；不指望“回忆/次日”等文字自动产生切包。 |

身份与外观分别登记：`character_name` 是稳定的剧情人物名，同一人的多个版本共用它；不同人不得共用。`reference_scope: "identity"` 只参考本人面孔和身份，镜头保留原文服装、发型、动作与表情；年龄/孕期仍须一致。未写 scope 的默认 appearance 专用妆造还核对服装/发型，适用时优先于身份母版。`episodes` 声明实际适用集数或 `["all"]`。不要为了通过校验删掉正文妆造或改写资产事实。

场景按本镜实际内外与动作选择，结合正式图片里可见的门窗、炕床和布局，不靠资产同名认定适配。人物在炕上起身仍是室内镜，不能绑定房屋院外图；走出门后的院外镜再绑定外景。一个动作跨过室内与室外时拆成各自的镜头，分别填写核心场景；跨内外却沿用同一资产时，仍在变化前的末镜写子任务边界。原文没有的空间关系不当作参考已证实的事实。

机器的 `vo` 只归类发声，不替代原文的 OS、心声、记忆音或当前画外对白语义。保留原句，用现有说话人、台词与镜头正文表达：OS/心声写明内心独白，画面人物不对这句发声、不按该句对口型，表情动作仍按原文，不强制闭嘴；记忆音写明回忆中的声音，不改成当前场景正在说话。最终包 `prompt` 也保留这些说明，不强迫声源入画；原文没有可见回忆画面时，不为记忆音新增人物镜头或人物图绑定。

## 完整镜头文本

将这段保存为 `shot-script.txt`；同一项目已有 `episodes/01.txt` 保存本集原文。示例换装前后用显式边界分包，第三镜只拍温雪，周明在画外说话，因此不绑定周明图。示例正文是虚构剧情，不能代替用户原文；实际人物状态与服装必须有来源。

## 工具参数与返回

下面的路径相对项目工作目录；`max_submit_seconds: 30` 只演示已确认允许30秒的项目预算，实际值来自当前项目、分镜和模型支持范围。`preview` 不写文件：

```json
{
  "method": "preview", "script": "shot-script.txt", "assets": "assets_manifest.json",
  "project": ".", "episode": 1, "max_submit_seconds": 30
}
```

同样的输入可编译本地包；项目必须已有 `episodes/01.txt`，工具创建 `prompts/01.txt`、`matches/01.matched.json` 和 `episode_packages/01/`。远端 URL 只记录为引用，本地图片路径存在时才复制图片，不下载示例 URL：

```json
{
  "method": "compile", "script": "shot-script.txt", "assets": "assets_manifest.json",
  "project": ".", "episode": 1, "max_submit_seconds": 30
}
```

调用没有 `duration` 参数。返回的包 `submit_seconds` 是独立生成参数；完整包 `prompt` 不含原脚本的控时行。每包 `material_bindings` 明确提供 `material_key`、`asset_id`、`material_id`、`name`、`url` 和 `reference_scope`，按这些记录绑定，不用 `material_names` 与 `material_keys` 下标拼接。示例第一镜对应温雨身份71001，第二镜对应雨衣71002，第三镜只对应温雪71003；画外周明71005不进入本镜图像绑定。
