# 仿真人镜头编译

保留源文本、顺序、说话人、发声方式、资产 ID 与材质身份。只绑定当前项目实时主体设定中通过门禁的 official=true 资产；本地匹配不是远端身份的替代。

## 创作建议与真实约束

通常每镜 1–4秒、按 9 个有效字/秒估算；15 字以上可考虑语义拆镜，36 字以上复核可读性与节奏。它们是警告/人工或模型复核，不是普遍硬禁。旁白与心声优先考虑画面表现，但原文要求的发声不删、不强制变成角色当场对白。真实供应商的时长、比例、分辨率和资产限制必须满足。

从剧变对应项目读取并沿用视频模型、平台通道、比例、分辨率和风格，核对当前分镜及用户确认要求，再以实时模型目录验证；配置完整时不重复询问。每包请求时长按内容计算：有台词镜头按有效字数÷9向上取整、至少1秒；无台词按动作复杂度1/2/3/4秒，未声明时采用工具配置值（默认2秒）；镜头独立的「时长：N秒」声明优先。复核停顿、慢节奏和动作后，包内镜头时长相加再加1秒自然收束；超过模型支持范围时在完整镜头之间拆包，不让用户逐包填秒数，不把项目或旧分镜的时长套给所有新包。对同场景、同时间、同服装、动作连续的完整镜头打包，场景或服装变化切包，不截断原文凑时长。用户确认的交付规格不能被本地默认值覆盖。

## 编译入口

新制作必须使用当前 `drama_shot` 工具，并先读取其 schema：preview/compile 所需 `max_submit_seconds` 是 Agent 根据内容确定、且模型目录支持的本次总时长预算，包含收束；不可盲填 30。编译结果各包 `submit_seconds` 写入对应分镜的 `modelConfig.duration`，提交前回读核对。镜头中的「时长：N秒」表达慢节奏或长镜，`report.warnings` 供节奏复核。VO 使用已支持的 vo 表达并保留说话人及原文；未支持格式报告缺口，不静默降成 dialogue。

本轮授权生成范围的镜头包可分集并行编译；先汇总并检查全部包的原文、镜头顺序、时长、正式资产与模型约束，再为每个分镜完成免费 `select_assets` 与 `prepare_video`。把全部 preview 与本次授权分镜 ID 逐一对应并排除遗漏、重复，整批费用核对通过后，用 `jubian_storyboard submit_video_batch` 一次提交独立分镜；一包失败先修正整批，不提前生成已就绪包。每项结果按自身 preview fingerprint、分镜 ID 和任务 ID 对账。

分镜正文直接采用 `drama_shot preview/compile` 返回的包 `prompt`，其中保留全部镜头正文并补齐已确认的人物、动物、场景、道具引用与收束要求。沿用已有素材 key，缺失时用 `asset_<jubian_asset_id>`；把完整提示词保存到 `modelConfig.prompt`，按返回 `material_keys` 的首次出现顺序去重选择对应父资产。原文未手写动物 key 不代表本包没有动物；检查绑定结果与提示词，不能从人的出镜名单或旧卡片复制素材。

绑定前的角色状态是**硬门**：每个入画主体的 `主体状态追踪` 段落必须写 `身体状态：【阶段；服装；发型】；`，所挂资产的 `state_or_costume` 必须登记同一组维度、`episodes` 必须覆盖本集。`validate` 给了 `episode` 就能在提交前判到这一层；不一致会点名角色、期望值、资产实际值与资产 id。清单里没有所需阶段的版本时，`failures` 里是一条完整的补料需求（角色/阶段/服装/用于哪几集）与补料路径——先复用或补料登记，不要改状态文字绕过，也不要直接拿名字带阶段的旧版本顶上。

`project` 给了就按它解析项目根，没给就向上找最近的 `project_config.json`；本项目声明的每镜有效字上限等要求见[字段表](references/project-config.md)，不要靠试错反推键名。

当前环境缺少 `drama_shot` 或不能无损表达输入时，保留输入并报告依赖或格式缺口，不修改原文绕过，也不退回把创作建议当硬失败的旧编译器。

## 导演脚本

景别、视角、运镜、空间、动作、情绪、连续性须自洽。无声镜省略台词行，可写 `发声类型：action`；不写假台词 `无`。零人物镜省略出镜人物，不用 `出镜人物：无` 占位。动作复杂度仅按入口支持的标签使用。节奏预算与自然语言提示词分开；提示词一般不堆时间戳，但不把任何秒数视作内容违规。

原文完整性按 [总流程的原文覆盖核对](../tweet-drama-pipeline/SKILL.md#原文覆盖核对) 逐项检查；台词之外的动作、视线、表情与剧情顺序也需要镜头对应。

格式自检只看脚本**每个镜头块的字段**：一条一条读镜头行，而不是在文件或输出全文里搜字样——技能正文、检查清单和自述里写着「台词：无」是规则说明，不是违规。判据是「无声镜整行省略台词行与出镜人物」，`drama_shot preview/compile` 会同时执行字段和资产检查，修改后读同次结果的 `failures` 与 `warnings`；单独 `validate` 按需使用。

编译时长仅是计划值，实际视频和字幕时长以生成结果、真实音频及 ffprobe 为准。预计集长可作审片参考，不能凭原剧本标注或字数比例认定最终时长。
