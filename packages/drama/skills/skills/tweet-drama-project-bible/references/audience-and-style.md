# 短剧的受众与影视风格

结合实际读过的剧本和用户要求，理解人物处境、关系、冲突与情绪回报，思考作品能吸引怎样的观看兴趣、希望带来什么感受。3D 动漫和仿真人都以故事、情绪与视觉吸引力为创作目标。明确的人物魅力、关系张力、冲突推进和情绪兑现可以引导设计，具体节奏由本剧决定。

这些判断自然融入当前方案，不要求固定分析维度、独立报告或每个资产重复分析。用户已给的方向直接沿用；只有片段时结论限于已读范围。受众判断是有依据的创作推断，不等于市场验证，不虚构人口画像、热度或转化率；用户明确要求市场调研时再检索真实资料。

影视风格可先用适配作品的整体语言表达，例如浪漫年代爱情片、温暖祥瑞的东方玄幻或紧张克制的悬疑短剧，再按当前画面需要补充。3D 动漫默认保留次世代高精度建模 CG、物理可信 PBR 材质的风格前缀；仿真人采用其影视媒介语言，可以融合电影级玄幻生物与特效。具体程度由创作需要决定，无需把风格词逐项展开为材质、光线或五官参数。

人物形象、妆造、场景、道具、表演与声音共同服务于题材情绪和故事。年代与生活条件提供依据，非关键细节允许影视化处理；剧情关键设定、人物身份、道具功能和原台词保持一致。用户明确认可的参考用于相应的形象、妆造或整体观感，已采用角色保持身份连贯。

沿用现有项目工具保存完整 `project_bible.style`，用户自填原文与补充设计区分；`visual_medium` 仍独立表示交付媒介，不新增工具未定义的字段。常规美术选择自主推进，重大方向冲突集中沟通；受众推断不自动授权切换模型或重新付费生成。

依据实际成图与成片判断情绪和吸引力，保留用户认可的设计，针对影响故事与观感的主要问题调整。生成参数和任务成功只能说明执行情况，艺术效果仍以实际画面为依据。
