# 受众定位与影视风格

用于创作、改编与视频制作的项目定位。已有用户要求、剧本内容和项目约定优先；以下方法帮助形成方案，不是额外审批或市场调研流程。

## 从已读剧本提出定位

先核对实际读过的版本、集数或场次，再找主角处境、持续冲突、关键关系、反转和情绪兑现的具体依据。用户已指定受众、渠道或风格时直接沿用；只有开篇或片段时，结论只覆盖已读范围，后续正文出现新证据再调整。

- 观看兴趣：哪些观众可能被当前人物处境、关系或题材吸引，用“偏好亲情团圆与善意回报的观众”等兴趣描述，不直接把题材等同某个性别、年龄、地域或收入群体。
- 情绪回报：作品主要兑现守护、团圆、成长、扬眉吐气、恋爱满足、奇遇或悬念中的哪些体验，引用具体剧情依据，允许多个体验并存。
- 接受边界：当前方向希望保留多强的紧张、惊吓、悲伤、冲突和复杂度，区分剧情有危险与画面需要恐怖化；用户要求“不吓人”时，危险事件仍按原文表达，造型、用光与细节不额外强化惊悚。
- 创作取舍：上述定位怎样影响角色与灵兽的亲和程度、场景氛围、节奏和镜头距离。推断注明依据与不确定项，不能将“会喜欢”写成已验证的观看或购买行为。

无实际数据时不编造精确年龄段、男女比例、热度、点击率或付费转化预测。用户要求市场调研时再检索真实资料并标明样本、日期和适用范围；剧本分析本身不证明市场表现。

## 转化为可执行的影视风格

把媒介、题材、情绪观感与美术表现分开描述，再检查它们是否能共同兑现上述体验。媒介决定真人摄影、动画等基础质感，不能独自决定题材氛围。美术要求要写成可观察的轮廓、材质、配色、光线、构图与表演，不只堆“高级”“爆款”“仙气”等抽象词。

| 项目方向示例 | 可以落实的画面与资产要求 |
|---|---|
| 仿真人、温暖祥瑞玄幻 | 真人摄影与电影级灵兽特效融合，轮廓温和、材质温润、光线柔和通透；保留剧本物种、尺度和关键外形，不主动添加捕食凝视、黏液与惊悚特写。 |
| 仿真人、温馨家庭 | 可信的生活环境与服装，人物身份清楚，表演亲近克制；按实际剧情处理冲突，不把温馨等同没有矛盾。 |
| 仿真人、悬疑 | 围绕线索、遮挡、空间关系与紧张表演设计明暗和镜头距离；不因使用仿真人媒介就自动添加血腥或怪物元素。 |

同样的题材可以有不同的观感。沿用当前用户方向和项目风格，不把表中的示例设为所有项目的默认模板。参考图片只提取本次明确采用的形态或材质信息，参考照片的凶性、配色、姿态和背景不自动成为创作要求。

## 保存与后续检查

用简短结论说明受众假设、原文依据与视觉方向，随当前方案或既有创作说明保存，不要求另建报告或为每个视频包重复分析。用户原话与模型补充区分，未确认的人口画像不写成项目事实。

采用现有项目工具保存完整的 `project_bible.style`，保留用户自填原文；`visual_medium` 继续独立表示交付媒介，不新增工具未定义的字段。只有影响作品观感的真实冲突或无法确定的重大取舍才集中询问；有依据的常规设计按当前授权推进。

资产和视频提示词沿用同一方向。审核既看物种、身份、尺度和制作质感，也看图像是否符合项目已定的亲和、祥瑞、紧张等观感；具体差异须有实际画面依据。受众推断不覆盖原台词、剧情与用户约定，不自动授权更换媒介或重新付费生成。
