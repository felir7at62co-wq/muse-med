# 仿真人项目检查

只读核对 pipeline_state、磁盘、当前项目/分镜、模型目录及远端任务，不凭目录存在推断完成。报告真实缺失依赖与受影响分支；修复交给对应阶段。

先读 Core 的[通用质量复核](../tweet-drama-core/references/production-quality.md#审片证据与返工)，对照当前文件与时间码区分观察事实、疑点及审美偏好。关键动作是否缺失须查看连续片段；少量静帧没拍到不能当作缺失证据。用户已确认采用现状时不自行重做，旧结论被新证据推翻后更正当前报告，不重复旧误判。

对照[首轮制作时确定的要求](../tweet-drama-core/references/first-pass-production.md)审片，不临时把目标物数量变成全场数量限制。硬判动作缺失或穿模前回看支撑和躯干角度，核对反证；动作存在仍须检查同一道具的形态变化。需要证据时运行`python -B scripts/video_review_evidence.py <项目目录> <视频相对路径> --start <起秒> --end <止秒> --output <新证据目录>`；提供PATH中的ffmpeg/ffprobe或显式`--ffmpeg`、`--ffprobe`路径。输出连续音画片段、每页最多六帧和文件哈希，保持`review_status=pending`，不签发验收；新目录要求防止覆盖旧证据。

Muse已有原生工具时优先用`video_inspect method=metadata`核对当前源，再对动作区间用`sample`或精确时间点查看原帧；概览用`video_contact_sheet columns=3 rows=2`，遵循分页和未查看时间点继续核对。拼图和图像输入收据不证明理解或连续看完。上述便携脚本只用于需要离线导出连续片段或缺少原生工具的环境，不替代原生证据及实际听校。

先从本次加载的技能目录运行`python -B scripts/inspect_evidence.py <项目目录>`，核对已有云端转写收据的源文件哈希、raw输出和字级时间戳候选，以及最新审核段落中明确的交付结论矛盾。它只输出JSON，不写项目、不查远端、不签发验收。`review_for_active_sources`只是复用候选，须再核对它是否属于当前选用片段并实际听校；旧同名文件、被替换包和仅有时间戳不能证明当前整集的声音通过。已有完整且匹配的结果先复用，不把旧“ASR不可用”批注当作当前健康状态；待处理收据沿原ID用`audio_transcribe inspect`查明，不为巡检另行收费重提。脚本边界见[检查字段](references/io-contract.md)。

重做包出片后，先复查原缺陷与新增问题，再核对整集、字幕和草稿实际采用的版本。抽帧干净只能说明已检查帧；视频生成成功、音轨非空或局部画面通过，不能抵消未听校的旁白/心声、未校时字幕或未达到的导出规格。分开报告“局部审核通过”“整集待验”和“最终交付”，不写“整集可交付（VO仍未听校）”。

按Core的[场景时段规则](../tweet-drama-core/references/first-pass-production.md#场景时段进入每个独立包)对照原文场次、场内时间推进、实际提交提示词、选用场景图和相邻包原片。核对天空、主光方向、环境光与人物受光；近景曝光变暗不直接证明入夜，不能仅凭平均亮度判定时段。区分原文允许的次日或蒙太奇推进、分包遗漏时段和生成偏差；不通过改原文或统一整集光照来消除穿帮。

按Core的[动作依据与用途规则](../tweet-drama-core/references/first-pass-production.md#动作依据用途与手部状态)核对实际执行者、发生条件、道具取用路径和落点，以及双手释放与承接顺序。动作出现在视频里仍可能是无依据的提前操作、错误用途或错误容器；区分原文故意失误和生成偏差，不能因画面无穿模就判为合理。返工先核对动作本身，再改路径、落点和手部状态，不保留无依据动作只补负向词。

挑起/卸下长杆、抓握、抱扶、交接或人物跨越道具时，按动作起点、接触与支撑变化、最接近身体处、放置落点检查连续视频；需要时在该动作区间加密抽帧，不用固定间隔的少量静帧证明全程无穿模。核对手掌、杆体、躯干及邻近人物的遮挡和相对位置，尤其检查切镜后的持物、姿态和落点；重做一个缺陷后也检查这些动作，不能只复查旧字幕位置。问题优先通过合理机位、清晰动作阶段与空间关系修正，不为镜头新增夸张表演，不默认把后续镜头全部固定。

核对当前正式资产身份与归属、必要的确认出演或本地主体门禁证据；核对源文本、说话人、发声方式（对白、旁白、OS）与素材顺序。时长联合考虑实际台词、动作、反应、运镜和收束，沿用当前发声预检的估算，再用实际声音核对；估算语速、字幕阅读提示和镜头节奏建议不能冒充模型硬限制，也不能据此删改原文。旧剧本格式无法解析时单列待核对，不把解析失败直接写成内容缺失。请求按当前分镜及实时目录允许时长、比例和分辨率检查，保留已确认交付规格。

pending/unknown 任务继续查询原 ID，模型安排后续回读，不建议盲目付费重提。草稿可继续但明确非最终；最终仅选用 clean/not_required 且有实际文件对应内容、字幕、规格和音画 QA 的视频。核对最终字幕覆盖实际发声而非动作说明，每集 BGM 至少 2 首，按剧情情绪选择并记录选曲理由、时间段和试听记录，最终输出与被审核源文件一致。confirmed failed 的恢复需核对根因、费用及剩余授权，不能无限重试。
