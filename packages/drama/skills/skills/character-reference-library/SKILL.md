# 公共人物参考库

公共人物库只供检索和看图。它不会创建项目资产、登记出演、上传镜流或添加公共库记录。角色 `character_id`、图库 `catalog_asset_id` 和镜流的项目及资产 ID 各属自己的来源，不得互换。

## 检索与看图

先用 `drama_character_reference_project` 确认当前本地项目和角色。已有一个经 Host 验证的有效项目时可以直接使用；有多个项目时按用户明确指出的项目选择，不凭角色名、目录顺序或最近一次读取推定。不要把一次读取当作嵌套项目选择，也不要把镜流项目编号填入本地人物库的项目字段。此会话没有可用的本地项目或库工具时，说明限制，继续用当前剧本和用户可提供的素材设计，不编造匹配结果。

依据剧本用 `drama_character_references` 初选相关人物。使用已登记的 `role_class`；尚未登记时可依据原文暂定检索类型并标明不确定性，不因缺少分类就要求用户先登记。检索请求只包含已知角色、年代、风格与可观察特征，剧情依据可解释检索目标，不构成素材使用授权。文字评分只用于初排。

从同一结果取得 `catalog_asset_id` 与 `image_sha256`，原样传给 `drama_character_reference_view` 的 `catalog_asset_id` 与 `expected_sha256`。只有拿到并查看实际图片才能评价；不把文字推荐、图片名或未打开的预览当作看图。若 `candidate_limit_reached` 且已看的前三张都不合适，可按已知特征收窄条件，至多再检索一次。不要只凭前三张就宣称全库没有合适素材。报 `UNCONFIGURED` 或认证失败时报告库不可用，不把它解释成没有候选。

若角色已有项目现行主图，先把其现行主图作为同一人物的身份锚点。镜流资产和造型可用 `jingliu_workflows` 查询 `list_assets`，再用 `jingliu_run` 在已选项目读取。比较实际看见的脸型、五官结构和年龄观感，不因职业、服装和风格相符就认作同一人。若无法实际看到主图，说明身份一致性尚未核实；不把候选自动绑定给该角色。

## 使用边界与交付

图库推荐和看图不代表审核或项目级批准。`pending_review` 只能作为只读比较，不能上传、发送给供应商、正式绑定、发布或跨项目复用。即使是用户本人上传的图，当前工作流也不提供图库到镜流的授权、传输或采用。只记录选中图的目录身份、原图 SHA-256 和选择理由；这些记录不改变原图审核状态，也不是生成输入。不得导出签名 URL、复制或写入图库对象来绕开限制。

用户只要选型时，交付匹配依据或不匹配原因。需要继续生成而没有可用参考时，按当前剧本与项目自有的合格素材准备独立候选；必需图库原图无法合法传入时，说明限制并停在提示词。先区分人物设定板与成片镜头，设定板按明确的角色资产规格，不能把成片竖屏自动套给设定板。按[主角专用资产图](../protagonist-asset-sheet/SKILL.md)或当前美术要求设计，沿用[视觉审核](../tweet-drama-asset-vision-check/SKILL.md)逐图判断。

生成前核对当前用户的授权、报价、目标资产与已有任务。生成结果未知时只查原任务，不换键、改名或换目标重投。主肖像缺脸、错脸、多余肢体或未要求的拼版属于不合格候选；若已明确采用主肖像加三视图的设定板，正反面身形或服装视图中的空白脸只是占位，不能作为已完成的面容参考。明显换脸即判为不合格候选。实际查看结果后分别报告画质、项目现行版本和镜头引用状态；不为补救画质自动追加收费。
