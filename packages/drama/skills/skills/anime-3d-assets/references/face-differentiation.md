# 人物五官差异与身份保持

## 先确定是否应该换脸

新角色、跨项目新主角、尚未定角的独立候选：设计不同的面部结构。同一已确认角色的换装、表情、视角和后续视频：沿用该角色的身份母版，不为了去重换脸。亲属、双胞胎、明确指定同演员或用户锁定面貌时保留必要相似，并记录理由；不擅改剧本年龄、身份或审美要求。

## 生成前：用结构对照，不用形容词去重

先在角色卡写当前方案与最接近的已有人物/候选的简短对照表。每行一个角色，按以下四组记录可观察的结构：

| 结构组 | 需要描述的关系 |
|---|---|
| 额颧颌与脸部比例 | 宽长关系、中庭比例、颧部宽度与下颌收放、下巴；这些属于一组，不能拆开凑数量 |
| 眉眼结构 | 眼裂形状与开合、眼睑、眼距、眉眼距离和眉形组合 |
| 鼻部结构 | 鼻梁长短及起伏、鼻翼宽度、鼻头形态 |
| 口唇结构 | 嘴宽、上下唇厚度关系、唇峰与人中关系 |

对没有相似性要求的不同身份，默认以至少三组有清楚可见差异为设计目标，包含脸部比例、眉眼及鼻部或口唇。这是创作检查方法，不是人脸识别阈值或质量保证。空间受用户设定限制时说明约束，不丑化或畸变角色来凑数。

“圆方/方圆”“略宽/稍宽”不构成可靠差异；改变发型、服饰、肤色、表情、妆容、光照或加痣疤也不计入结构差异。若两份方案仍共享内双、较宽眼距、微垂眼角、宽鼻翼、饱满下唇，仅改下颌不能宣称独立选角完成。应在允许范围内重新组合眉眼和鼻唇，而不是追加“独特、不撞脸”口号。不要把示例组合固化成每个项目反复使用的几张脸。

实际提交文本采用：短风格前缀 → 本角色的具体面部结构与年龄身份 → 服装材质、光照版式 → 必要保留和排除项 → 风格锁定。面部设计靠前且只写当前目标；旧角色的长篇五官描述留在本地对照表，避免以大段否定句反复注入旧脸。已有统一风格首尾要求继续遵守。

## 参考图与剧变提交核对

新身份不把其他角色的整张人脸当默认风格图、编辑底图或共用身份素材。优先使用已有无脸材质/光照参考及文字造型标准；完整风格图留在本地审核。确有平台已核实的风格隔离能力时才使用该能力，并仍检查结果有无身份污染。仅在提示词中标注“style only”不证明工具隔离了身份。

检查实际发送的提示词、附件、素材绑定、默认模板与可见的历史上下文，而不只看本地草稿。不同角色不能绑定同一身份母版；无法读取实际请求时明确“提交链路未核实”，不假称已排除平台污染。工具不支持的参考权重、随机种子、去重开关和图像角色字段不得编造。旧脸作为比较证据，不作为所谓负面参考图传入。换种子不能替代结构重设计。

## 比较范围与生成后验收

当前项目比较可访问的相关角色及本轮候选；跨项目从已知资产清单或用户提供的路径中选最近三至五张可比人像，记录实际覆盖范围。历史检索最多两次，每次最多三十秒、总计六十秒；已有更严格限制时沿用。无入口、超时或不可访问则记录未比较范围并继续已授权新建，不全盘扫描、不声称完成全库去重。

实际查看输出，在相近角度、面部显示尺度和清晰度下比较，尽量忽略头发、服装和表情。按四组写出可见证据；文字方案不同不等于画面不同。单一共同特征不能判同脸，多组结构仍高度重复则差异审核失败；角度、遮挡或清晰度不足则未验收，不编造相似度百分比。

有独立母版制作授权时先验收正面脸部/半身母版，通过后再派生换装和身体视图。仅授权一张设定板时就在该板中先验脸，不擅自增加收费人像或成组候选；既定交付版式保持不变。最终设定板及修复后版本仍复核面部，避免美化阶段重新收敛为模板脸。

重复脸失败时先定位是结构方案相近、参考绑定错误还是输出未执行差异，再定向修正。不自动重做已经通过的其他角色。沿用原任务预算、尝试计数和重试上限，不以新增“面部阶段”重新计数；没有既定上限时本问题最多三次新生成且不得超过已授权数量/预算。未知任务先查原任务，禁止重复付费提交。

## 留存证据

沿用项目现有角色卡、身份描述、提示词片段和审核记录，不另建全局身份库。记录当前目标、实际比较图片/修订、四组结构的差异或重复、实际提交参考及未覆盖范围。使用已有 pass/fail/not_checked 状态；只有实际看图才能通过视觉审核。旧母版及采用状态不因规则更新而自动改变；已确认角色的身份连续性与新角色的差异性分别判断。
