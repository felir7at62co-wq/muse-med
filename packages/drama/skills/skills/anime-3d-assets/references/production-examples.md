# 固定块、变化块与证据交接示例

以下为虚构的 1980 年农村住家制作示例，用户已确认局部布局、时代适用性和色卡；不是任何实际剧目资产。没有图片、母版、远端任务或采用结论。实际使用时替换为本次已确认依据；不能把示例的门窗、物件或姓名当作通用模板。

## 厨房白天基础版

家族为住家 HOME，区域为厨房 KITCHEN。已确认厨房在堂屋右侧，但“右侧”的观察基准和通堂屋的门朝向未给，空间说明保留未知。以下只采用单独确认的厨房局部布局，不把左门目的空间编成堂屋。固定陈设为后墙灶台、右窗、左门、左前木案、左后收纳架；厨房未配置灯具。

```text
3D动漫／风格化三维动画，次世代高精度建模 CG，物理可信 PBR 材质，纯环境场景，清晰三维空间，精细构件厚度、表面微结构和接触阴影统一。
交付内容：住家厨房白天基础场景单图，画面无人，只展示建筑、固定陈设和环境道具。
时代与场所：1980 年农村普通住家，局部布局和材料已按本示例设定确认。正常维护，结构完整，使用磨痕局部可读，不表现废弃或灾后破败。
固定色卡：暖灰抹灰墙、灰蓝木门、土黄压实地面，木案保留自然木色；色名表示材质固有色，照明不把各物件统一染成同一种色。
区域结构：以相机面向灶台后墙为观察基准，后墙中右部一座完整砌筑灶台，带铁锅和锅盖；右墙中部一扇木框窗；左墙近前部一扇关闭的灰蓝木门，门后空间不入画。左前方厚木操作案与左后方木收纳架保持固定位置，中央及门前通道无遮挡。
固定陈设：木案上一个无文字粗陶盆和一块木砧板，收纳架上两只素陶碗；干柴整齐收于灶台侧下方。维持上述种类、数量和位置，无额外灯具、现代厨电、包装或装饰。
材质与光照：墙体有细密抹灰起伏，木门有榫接厚度和轻微边缘磨痕，夯土地面压实平整，木纹顺构件方向，灶台灰缝有深度，锅盖的金属反射与粗陶、木材明确区分。右窗柔和白天天光照入，墙面反射提供弱补光，案脚与灶台接触阴影清楚，暗处结构可读。
机位与输出：16:9 横向单图，相机在厨房前部中间偏左，约高1.5米，中等广角朝向灶台后墙；左门、右窗、灶台和中央通道同时可见。垂直构件稳定，保留前中后景，不拼接多机位。
保留全部固定布局、物件数量、色卡与正常使用痕迹。排除人物、路人、人影、剪影、身体局部、玻璃或金属中的人物倒影、意外文字、水印、无依据的人形装饰、实拍背景及不符合本时代的设备。
最终保持3D动漫／风格化三维动画媒介、次世代高精度建模 CG 与物理可信 PBR 质感，建筑、陈设、道具、材质和光照使用一致的造型精度与渲染体系，画面保持纯环境。
```

生产记录为 [白天候选](../assets/scene-day.example.json)。示例记录的参考、文件和任务为空，审核未完成；它展示结构化计划，不宣称上面的文字已经通过时代或视觉验收。

## 同机位雨夜派生版

用户另要求厨房雨夜设计；原文只在院落写了雨夜时，不把厨房雨夜擅自绑定同集。此示例 `episodes=[]`，真实用途待确定。白天图未生成，先交付文字草案；以下参考指令只在父图实际过审且可访问后才能提交。同一张白天图在 `generation.references` 中只登记一次，主用途 `purpose=style`，本地 `roles=["style","layout","edit_base"]` 记录兼用职责；实际工具只传一个已上传 URL，不重复提交同一图。

```text
3D动漫／风格化三维动画，次世代高精度建模 CG，物理可信 PBR 材质，纯环境场景，清晰三维空间，精细构件厚度、表面微结构和接触阴影统一。
交付内容：同一住家厨房的雨夜环境状态单图，画面无人，只改变已登记的时间光照、窗外天气和外侧湿润。
实际参考用途：审核通过的本厨房白天图同时作为3D风格、布局与编辑底图；保持其相机、构图、完整空间和固定物。没有该真实底图时本稿保持待生成，不使用人物设定板补位。
时代与场所：1980 年农村普通住家，正常维护，结构完整，使用磨痕局部可读，不表现废弃或灾后破败。
固定色卡：暖灰抹灰墙、灰蓝木门、土黄压实地面，木案保留自然木色；沿用白天版的材质固有色。

固定陈设：木案上一个无文字粗陶盆和一块木砧板，收纳架上两只素陶碗；干柴整齐收于灶台侧下方。维持上述种类、数量和位置，无额外灯具、现代厨电、包装或装饰。
本次变化：右窗外为雨夜，低照度冷灰环境光从同一窗口进入，窗玻璃外侧可见稀疏雨迹，露天窗框外侧局部湿润；室内地面和陈设仍干燥。环境反射提供克制补光，门、灶台与通道暗部可辨，不靠新增煤油灯、电灯或火光补亮。保持原材质微结构、木纹、灰缝与接触阴影，只改变明暗、环境反射和符合遮蔽关系的湿润。
机位与输出：16:9 横向单图，相机在厨房前部中间偏左，约高1.5米，中等广角朝向灶台后墙，与白天版完全同机位同构图；左门、右窗、灶台和中央通道相对位置不变，垂直线稳定，不拼接多机位。
保留布局、门窗、家具、数量、尺度、材料和固有色。排除人物、路人、人影、剪影、身体局部、玻璃或金属中的人物倒影、意外文字、水印、新增灯具、室内凭空漏雨、家具移动、场景重建和实拍背景。
最终保持3D动漫／风格化三维动画媒介、次世代高精度建模 CG 与物理可信 PBR 质感，建筑、陈设、道具、材质和光照使用一致的造型精度与渲染体系，画面保持纯环境。
```

[雨夜候选](../assets/scene-night.example.json) 通过 `scene_parent` 依赖白天修订。结构检查可在当前技能目录执行：

```sh
python -B scripts/validate_asset_records.py --project-root assets assets/scene-day.example.json assets/scene-night.example.json
```

该命令只读记录、输出 JSON，`structure_valid=true` 仅表示已实现的结构检查通过，`visual_review=not_performed` 明确未看图。实际项目传其项目根和本批记录及全部本地依赖。无效 JSON、缺依赖、未钉住修订、环、变体改布局、受污染场景参考声明及文件摘要不符返回非零；不修改记录、不更新采用、不联网。

## 同一道具的完好与掉瓷

本例为原创搪瓷杯设定，杯口约9厘米、高约10厘米是已确认的美术尺寸，不据此推定实际容积。完好版通过后才派生掉瓷版。固定块在两次请求中完整复写，变化块各选一项；真实尺寸、时代与使用依据仍需项目核对。

```text
3D动漫／风格化三维动画，次世代高精度建模 CG，物理可信 PBR 材质，独立道具单图，构件厚度、连接、局部粗糙度和接触阴影清晰。
稳定形制：1980年农村住家使用的素白搪瓷杯，灰蓝卷边口沿，近圆柱形杯身，杯口约9厘米、高约10厘米，右侧一个完整环形把手，开放内腔、平稳杯底，无杯盖。以杯自身把手在右的正面为定位基准。
尺度与展示：单手持握尺度，把手开口能够容纳手指；仅展示一只完整杯，不绘制手部。中性浅灰背景，三分之四略俯视机位，杯口、内壁、把手和杯底均入画；各状态相机、尺度与柔和侧前主光相同。
材质：釉面不透明，柔和高光随曲面转折，卷边与把手接合有厚度。白色釉面、灰蓝口沿与裸露底材分别表现，不统一为镜面金属或透明玻璃。
保留稳定形制、数量、功能、尺寸、把手方向和固有色。排除文字、商标、水印、额外把手、无依据杯盖、穿孔、自发光与实拍产品摄影。
最终保持3D动漫／风格化三维动画媒介、次世代高精度建模 CG 与物理可信 PBR 质感，道具和项目采用的场景、角色具有同档造型、细节密度与光照语言。
```

完好状态变化块：`当前状态：旧而完整，口沿、内腔与把手无缺口，杯底仅有正常擦痕，整体清洁。` 掉瓷状态变化块：`当前状态：仅杯身正面下部偏左有一处约1厘米宽的表层掉瓷，露出更粗糙的暗灰底材，薄釉层边缘高度差可读；口沿、内腔与把手完整，不穿孔、不增加裂缝，其余旧擦痕保持。`

将选中的变化块放在固定形制之后，编译完整 `final_prompt`；不是只提交一句“掉漆”。项目人物或场景母版不可访问时，跨资产匹配保持未核验，不能凭末句声明已匹配。

## 角色身份与不可访问资产

虚构角色“柳川”的独立身份卡可以写为：长椭圆脸，额部比下颌略宽、颧骨适中；平直眉与略窄眼裂、自然眼距；窄鼻梁、圆钝鼻尖；中等嘴宽、下唇略厚。衣服和职业单独放在 `state`，不要以工装区别替代与另一角色的四组五官对照。以上是新候选的美术设计，不是现有李成身份。

已采用李成 r003 需要侧面换装但身份图不可访问时：保留旧版；新变体的 `dependencies` 钉住 r003，固定脸部信息只填写实际已有证据，缺侧面依据明确待核。女配质量板只能在实际查看后供质量对照，不能提供李成的鼻梁、侧脸或发际线。服装材料、颜色及时代条件齐全时可以起草服装段，身份生成和采用等待真实母版。

## 单张图的空间交接

room.jpg 不可访问，文件名为厨房，用户提出“经左门进入另一房间”：仅登记用户镜头意图与未知原图。不得确认门位置、给另一个房间命名或推定门后可达机位。原图可访问后标记参考视角、门洞、稳定地标、遮挡和光源；只有进一步资料证实门后空间时才能锁定穿门路线。需要新增空间设计时作为新候选说明，不冒充从原图还原。
