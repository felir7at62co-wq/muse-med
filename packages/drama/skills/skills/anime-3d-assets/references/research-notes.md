# 外部能力的适用范围

本技能依据公开资料中的方法组织原创规则、示例与校验代码。外部文字、代码、图像及许可证仍由原仓库负责；以下链接不表示已安装外部技能、已连接服务或已取得任意媒体的使用权。维护时核对源文件和许可，再决定是否逐段引用或移植；不整体复制外部教程。

| 来源 | 吸收的方法 | 本技能采用的范围 |
| --- | --- | --- |
| [漫剧场景资产导演](https://github.com/djyy1031/ai-comic-drama-director-skills/blob/main/skills/ai-comic-scene-assets/SKILL.md) | 场景家族、区域与机位层级、色卡、父图继承、白天与环境变体 | 对接现有修订与依赖，纯环境参考继续隔离人物 |
| [分镜资产接入](https://github.com/djyy1031/ai-comic-drama-director-skills/blob/main/skills/ai-storyboard-asset-grounding/SKILL.md) | 实看成品、可见空间锚点、未知与冲突记录 | 提供资产事实，保留 Muse 镜头绑定与导演职责 |
| [Scenario 身份库](https://github.com/scenario-labs/skills/blob/main/skills/scenario-identity-library/SKILL.md) | 认可母版、多视图逐张审核、合格图归档与后续检索 | 使用本项目既有身份、版式和版本，不增加 Scenario 服务依赖 |
| [Scenario 一致性](https://github.com/scenario-labs/skills/blob/main/skills/scenario-consistency/SKILL.md) | 固定块加变化块、参考用途、姿态与构图控制的影响 | 最终字段按实际工具 schema；拼板和旧姿态控制不直接套用 |
| [Scenario 质量检查](https://github.com/scenario-labs/skills/blob/main/skills/scenario-quality-gate/SKILL.md) | 按可拒收单元审核、依据问题返修、总分不能证明结构正确 | 继续逐图视觉审查，不新增收费评分服务 |
| [3D CGI 提示词](https://github.com/an7ing/higgsfield-seedance2/blob/main/skills/02-3d-cgi/SKILL.md) | 材质分区、具体光源、阴影与空间层次 | 保留自然比例高精度 CG；不继承摄影写实、片名捷径、任意穿墙运镜或示例分辨率承诺 |
| [fal-regenerate-3d](https://github.com/fal-ai-community/skills/blob/main/skills/fal-regenerate-3d/SKILL.md) | 图像到模型、绑定／动画、PBR 通道、GLB 导出与预览 | 仅用于明确要求模型的任务；不默认建网页、伴生兽或背景视频 |
| [Scenario Meshy](https://github.com/scenario-labs/skills/blob/main/skills/scenario-meshy/SKILL.md) | 多视图、拓扑、重贴图、绑定与动画的工具差异 | 按实时工具说明选择阶段，避免已自动绑定的任务再次购买绑定 |

可运行的本地校验器为本包原创代码，只检查声明、依赖和文件摘要，不调用以上平台。示例都为虚构制作说明，不代表用户当前剧目或实际产物。外部示例的模型 ID、价格、并发、图数、时长和动作 ID 均不作为 Muse 默认配置；先读取当前工具与项目配置，费用仍按本次授权处理。
