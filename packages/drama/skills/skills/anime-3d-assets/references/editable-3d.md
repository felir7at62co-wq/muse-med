# 可编辑三维工程

仅在用户需要实际三维模型或工程时使用。先确认目标软件或引擎、版本、单位、坐标轴、角色绑定与表情需求，以及交付格式。未给性能预算时可提建议并标为待确认，不宣称模型达到特定平台标准。

## 可编辑性要求

- 保留源工程，角色身体、服装、头发、配饰及道具按后续修改需要组织对象；不用一张渲染图冒充可编辑模型。
- 记录材质槽、贴图路径、UV、尺度、轴向、对象命名和依赖。交付时打包必要贴图，避免只有本机可用的绝对路径。
- 角色需要动画时检查骨骼命名、蒙皮权重、关节变形与用户需要的表情或口型。静态模型无需凭空增加复杂绑定要求。
- 场景固定模块尺寸、原点与连接关系；道具标注持握点、旋转轴或开合部件。可动部件避免合并成不可独立操作的网格。
- 工程源文件与导出模型分别归档。FBX、GLB 等格式是否保留目标材质、约束及动画，以实际导出后回导检查为准。

## 验证

在目标软件或兼容环境实际打开工程，核对贴图、尺度、材质和缺失依赖；有绑定则做用户需要的代表动作与表情测试；导出物单独回导验证。根据真实需求记录面数、贴图尺寸、骨骼及材质数量，不编造“游戏级”“生产级”结论。

缺少建模或验证工具时，交付建模规格、参考图和明确的待制作清单，记录 `not_checked`；不能宣称已交付可编辑工程。修改已有模型先复制为新修订，再修改用户指定部分，并测试关联服装或骨骼是否受影响。

## 从身份图到可编辑模型

需要模型时，在现有角色身份与质量母版之外单独准备符合目标工具的完整角色单图或已审核多视图；绑定任务需要 A/T 姿时按实际工具要求制作。右侧脸部覆盖纯白的设定板主要展示发型、体态与服装，不能作为完整面部几何依据；建模所需脸部细节使用左侧特写或另有明确用途的完整角色单图。

按需求组织“合格参考 → 原始网格 → 必要拓扑／UV／贴图修订 → 需要的绑定或动画 → 导出 → 回导验证”，只执行目标软件和用途需要的阶段。先检查工具当前说明：某些动画操作已经自动绑定，不再次提交独立绑定；重贴图不得被误当作修复几何，单视图模式和多视图模式不能互套参数。保留原网格、材质、UV 与源工程，阶段输入引用前一阶段真实通过的文件或资产 ID。

PBR 贴图分别核对 base color、normal、roughness、metallic，按实际导出检查通道和色彩空间。不能把角色服装图直接推断为地面材质，也不能用颜色贴图冒充实测高度／位移图。只拿到生成 GLB 时交付为导出模型；未获得源工程、可编辑对象组织或回导证据时，不称为完整可编辑工程。

用于分发的 GLB 压缩、贴图降采样和网格简化另存派生版，保留源版。先确认目标加载器支持压缩格式，再实际回导，核对贴图、骨骼、动画和视觉差异，记录原始／派生实测文件大小，不承诺外部示例的固定压缩率。预览转台用于检查各面，用户没有要求时不制作角色选择网页、伴生兽或循环背景视频。

Muse 当前任务仍优先使用现有工具；没有模型服务或建模工具时交建模规格与待制作项，不安装外部 CLI、不改图片通道、不发起额外付费任务。用户明确要求接入外部平台时，再核对可用工具、凭据配置、真实报价与授权范围，不能仅凭参考文档中的端点或动作 ID 直接调用。
