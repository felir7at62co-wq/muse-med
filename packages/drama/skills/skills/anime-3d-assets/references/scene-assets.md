# 无人场景资产与人物参考隔离

场景资产用于反复绑定空间布局，默认交付纯环境单图，画面无人。人物由角色资产与镜头脚本决定何时入画；场景图预先画入人物会把身份、服装、动作和位置一起固化在背景中。本页适用于场景基础版、反打、日夜与季节状态、修改和复用，CG/PBR 质量、时代与已确认画幅仍按原规则执行。

## 先区分交付内容

场景家族、色卡、父子依赖和日夜变体同时按 [场景继承规则](scene-continuity.md) 执行；该规则限制结构变化，本页限制人物与实际输入污染，二者均通过才可采用。

- 场景资产：只呈现建筑、地形、陈设、环境道具和光照，预留可用空间。剧本中的出镜人物、台词与动作不写进场景生图正文；站位和行走路线保留在本地布局说明，转成通道宽度、无遮挡区域和前中后景。
- 用户明确要求带人物画面：另记为带人物构图参考或剧情画面，按指定角色、状态与人数制作和审核；不把这张图替换为默认无人场景基础版，不因原文有人物就在场景资产中自动加人。
- 剧本明确需要画像、雕像或人形装饰道具：单列道具及依据，检查它是静态陈设而非误入演员。没有该依据时不增加此类装饰。

“正常维护、有生活痕迹”描述环境状态，不能写成需要在画面中展示居民。灶台、整齐的工具、使用中的家具布局、适度磨损可以表达生活条件；空出人物不等于荒废、废墟、破屋或移除剧情需要的陈设。集市、学校、医院等公共空间同样默认无人，保留各自设施和时代依据。

## 最终提示词

场景提示词依次写：3D动漫媒介与 CG/PBR 画风 → `交付内容：纯环境场景资产，画面无人` → 时代与场所 → 固定布局与预留空间 → 陈设 → 材质、色板与环境光源 → 维护状态 → 画幅与机位 → 人物排除项 → 场景专用质量结尾。填写 [场景模板](design-and-prompts.md#场景设定模板) 并检查实际发送文本，不能只改本地草案。

正文描述建筑、陈设及环境光照，与项目已确认的 CG 材质、色板和光照体系一致。人物母版用于本地风格比对，不转写成“人物清晰”“人物站位”“与人物受同一光源”等入画描述，也不附人物姓名、衣着、姿势或角色四联板。排除人物、路人、人影、剪影、身体局部及镜面或玻璃中的人物倒影；建筑和物件的正常阴影、反射仍需保留。

## 实际参考输入

生成前逐张打开拟提交的参考，核对实际上传文件或服务端引用，而非只在记录中写 `purpose=style`。

1. 图二及本项目人物母版仍供本地质量对照。场景生成优先用已通过的无人场景或无人物风格参考；不得把完整人物设定板、角色母版和带人剧情帧直接作为场景参考输入。
2. 只有人物参考可用时，从中选择不含可辨识人物、完整人形、脸、头发、肢体及角色版式的材质或光照局部，实际制作并打开检查该派生文件。记录原图、派生路径、实际文件哈希与用途。“无脸”但仍有躯干、手脚或人形轮廓不符合此要求。裁剪本身不能保证质量；局部不足以表达材质和光照时记缺项。
3. 工具把多个用途的参考混为同一图像输入时，检查其中所有文件，不凭 style 标签或文字“不要复制人物”放行。没有可用的隔离参考时，交付待生成提示词与具体缺项，生成阶段保持未完成，不声称严格匹配。

任务明确为移除旧场景误入人物时，旧场景可作为待修编辑底图，单独记录为本次要清除内容的源文件；不能把它当作已合格的无人物风格参考。提示词明确移除人物及其人影、倒影，保留布局、门窗与陈设，实际打开修正结果复审。新增风格或布局参考仍须满足上述隔离要求。未经审核的清除结果不能当成已通过的参考，也不能通过只增强质感把误入人物保留下来。参考处理和图像编辑使用当前可用工具与既有授权，不自动增加付费尝试。

## 逐图验收

场景沿用 `review.quality_checks` 的 pass/fail/not_checked 与 evidence 结构，增加两个检查维度：

| 维度 | pass 依据 | fail 条件 | not_checked 条件 |
| --- | --- | --- | --- |
| `scene_clean_plate` | 打开实际结果，逐区域核对前中后景、门窗、镜面、玻璃、暗角与远处，无误入人物、路人、身体局部、人影、剪影或人物倒影；陈设和维护状态仍符合原文 | 出现上述误入内容，即使人物很小、模糊或在远处也失败 | 无实际结果、看不清必要区域或只读提示词未看图 |
| `scene_reference_isolation` | 实际核对全部新增风格/布局参考及引用，均满足无人物要求，来源、派生和用途有记录；明确清人的待修编辑底图另记来源、问题与清除范围 | 把完整人物设定板、角色母版、带人剧情帧或仅去脸仍留人形的图作为场景风格/布局参考，或把待修图冒充已合格参考 | 缺实际提交记录、参考不可访问或无法确认工具所用文件与用途 |

“带人物构图参考”按其明确的人物要求独立验收，不能记作无人场景通过；原文必需画像等静态道具须在检查证据中列明依据与可见区别。上述维度任一 fail 或 not_checked 时，场景候选不正式采用。检查通过也不替代时代、空间、画幅、CG/PBR 和跨资产一致性审核。

修正须针对实际误入内容，保留旧修订、布局依据和受影响镜头，遵守已有预算和重试上限。旧场景不自动删除、覆盖或批量重生；本次复用时按当前规则重新审核。这是技能执行与视觉审核要求，未在生成工具中实现自动拦截，也不能用文字检查证明生成画面无人。

## 回归场景

从 drama-skills 包根运行 `python -B -m unittest tests.creation.test_scene_assets`，检查发布模板明确无人、未混入人物表演描述、场景使用独立结尾且主技能可找到本页。技能加载快照检查模型实际收到场景规则；这些离线检查不验证真实图片质量。

独立写作实验覆盖正常住家、院落和集市，要求先完整复用模板并匹配人物基准画风；检查最终正文是否仍写居民、人物照明或站位，实际参考方案是否传完整人物板。变体包括只有无脸躯干裁剪可用、工具混合所有参考、修改已有带人场景，以及用户明确要求带两名角色的构图参考。没有生成工具时记录待生成，不编造图片验收。
