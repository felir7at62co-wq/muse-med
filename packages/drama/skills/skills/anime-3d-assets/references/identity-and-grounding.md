# 身份库、参考分工与真实资产交接

适用于角色、道具的多视图／状态生产，以及成品资产向分镜的交接。稳定身份与允许变化沿用既有 `identity/state`，审核和采用沿用现有记录，不建立第二套身份 ID 或完成标记。

## 可复用身份与多视图

先从剧本、用户设定和实际可见母版列出不能改变的脸部结构、轮廓、体型、主色及识别点。新身份独立设计，已采用身份的换装保持同脸；无法访问必需身份图时只交付条件性文字稿，不能用另一角色的质量板补位。不同状态沿用同一逻辑资产，变体绑定明确母版修订。

生成每一视角使用同一审核通过的身份母版，固定块完整复写，只在变化块写新视角或本次状态。不要从第一个新候选不断串接到下一个候选，累积脸型、比例或色彩漂移。服装整体改变时先审核该服装状态，再从它制作适用身体视图，保留原身份依赖。随机种子不证明同脸，同名不证明同一个物件。

独立图分别审核，参考库只收录适用视角、当前状态和通过的具体修订；历史版保留，但新任务不混入过时服装。近景需要真实可用的面部参考，侧面结构无法由正面确认时标待核。多视图按角色自身左右检查识别点，不能按画面左右镜像判断。

人物设定板采用左侧面部特写、右侧正／严格侧／背全身三视图，按 [人物交付版式](reference-standard.md#人物正式交付版式) 保留完整头部、发型和从头到脚的身体；右侧仅可见脸部覆盖纯白，背面保留后脑与头发。额外侧脸或 A/T 姿图按目标建模／参考任务需要单独记录。参考输入优先选择真实合格单图；视频工具若会把拼板当作首帧，不直接提交整板。

## 参考输入按真实用途登记

`generation.references` 沿用数组，每项保留路径或实际远端引用、明确用途和实测摘要；可补 `content_kind`、`submitted`、观察依据和来源修订。`content_kind` 记录实际看见的 `environment_only/material_only/character/headless_body/composition/unknown`。未知不能通过本地字段改名变成合格内容。

| 用途 | 可以锁定什么 | 当前技能的使用规则 |
| --- | --- | --- |
| `identity` | 本项目角色或道具的稳定外形 | 使用已通过的同身份修订；不能替代风格审核 |
| `style` | CG 质量、材质、色板、着色 | 不提供另一角色身份；无人场景仍执行无人物隔离 |
| `layout/structure/costume` | 空间、构件或服装结构 | 记录可见范围，信息来源不自动成为可直接上传的风格参考 |
| `edit_base/edit_source` | 当前要改的真实底图 | 写清保留与清除范围；带人场景只有明确清人编辑可以作为底图 |
| `local_review` | 本地质量对照 | `submitted=false`，不得混入实际生成引用 |

工具 schema 决定实际参考字段、数组或单值、槽位数量和互斥关系，不将此表的用途名当作 API 支持。确认工具收到的文件或素材 ID；只写 style 标签不保证身份隔离。img2img 底图可能同时锁定构图；姿态图、深度图和边缘图也会锁定相应结构，目标需要改变该因素时不继续喂旧控制图。无相应控制能力时报告限制，不伪造字段。角色身份输入不进入无人场景；具体隔离沿用 [场景规则](scene-assets.md)。

## 道具状态保持可操作

稳定记录形制、部件数量、大小、接触面、持握点、开合轴和功能，状态单独写完好、开启、局部掉瓷或破损。完好版先过审，再从同一版派生；每个变体列出准确位置与允许变化，不能为美观改变容积、把手数量或可用功能。持握示例属于带角色交互参考，独立道具图不必画一只手来表示尺寸。

在相同视角和光照下先比较形制与固有色，再检查新状态。需要不同视角时标明变化来自相机，而非误判为变形。身份固定块变化须创建新修订并复核引用；同角色普通表情不额外拆成新身份。

## 实际资产到分镜的交接

实际打开本次调用的成品文件，对每项写“确认可见、无法核实、文件缺失或证据冲突”，观察存入 `review.checks` 的 `asset_grounding`，身份和质量仍分别验收。状态是证据结论，不复制为第二份采用状态。文件名、生成提示词、成功 URL 和旧审核均不能代替本次看图。

场景交接包括参考视角、门窗及固定地标、可见连接、遮挡、光源、尺度依据、可用通道、候选摄影机区域和未知区域。没有测绘依据时用“本参考图左侧门洞”，不推定门外房间、绝对朝向或完整户型。相机与人物路径只能经过已确认可达空间；反打保持同一物体的空间位置，画面投影左右可以改变。多个视角矛盾时保留冲突，不把家具位置静默拼成虚构户型。

角色交接身份、服装、当前姿态的可见范围和修订；道具交接形制、尺度、状态、持有关系；声音沿用项目已认可绑定与实际试听记录，本技能不新增配音流程。下游使用标准名称和明确修订，既有 `shot-bindings.json` 保留镜头引用，不绑定 `latest`。本技能提供资产事实与限制，不擅自改剧本、决定镜头时长或替换导演技能。

用户只要一两镜文字时返回有关资产的简短观察与缺项即可，不强制搭建完整工程。没有可访问原图时交文字草案并标未核验；其余有证据的独立资产继续处理。
