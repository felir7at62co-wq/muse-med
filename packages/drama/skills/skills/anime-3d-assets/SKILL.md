# 3D 短剧资产与风格

用于已明确采用 3D 动漫、三维动画或 3D 漫剧的项目。结合实际剧本、用户方向和已认可的参考，发挥编导与美术判断，优先追求故事表达、情绪感染力和视觉吸引力；具体设计因题材和人物而异。

人物、场景、道具及相关视频提示词默认以“3D动漫／风格化三维动画，次世代高精度建模 CG，物理可信 PBR 材质”开头，再加入适合本剧的风格修饰。保留明确的三维动画媒介，人物与环境共享一致的风格质感；仿真人项目使用其自身影视风格。风格语言可参考[设计与提示词](references/design-and-prompts.md)，按需要阅读，自主组合。

短剧的角色需要有魅力、关系需要有张力，妆造、场景与道具共同营造情绪。结合用户认可的形象、妆造和整体观感自主设计，允许年代与生活细节做影视化处理；保留剧情关键设定、人物身份、重要道具功能与原台词。后续换装和镜头继续保持已采用角色身份。

提示词用自然语言表达本次画面，善用整体影视风格，自主决定详略。把具体描述用于故事、身份、情绪、构图与连续性的关键处，其余细节留给模型发挥；无需固定五官拆解、提示词顺序、结尾锁定句或逐项材质清单。资产画幅与版式遵循当前系统提示词和用户明确要求，本技能不另设人物版式。

已有合适资产与参考优先复用，按实际用途提交。没有必需参考也可独立设计；用户指定必须使用的参考无法传入时说明实际情况。随包图片仅是可选参考，不是每个项目必读、必传或统一模仿的审美标准。无需为每个角色另建面部资产或为每个场次重做一套素材。

实际查看生成图，结合本剧风格、用户偏好与目标镜头判断人物魅力、情绪和使用效果；抓住主要偏差调整，不为轻微版式偏差机械重生。费用、任务状态、真实素材绑定与采用记录沿用现有工具流程。技能内的记录模板、校验脚本与细节资料仅供需要维护对应本地项目数据时使用，不是普通资产生成的前置流程，也不覆盖当前系统提示词。
