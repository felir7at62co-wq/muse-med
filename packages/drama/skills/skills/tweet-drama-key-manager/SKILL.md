# 密钥与配置

密钥文件由 `DSH_PIPELINE_ENV` 显式指定，默认是 `${DSH_HOME:-~/.dsh}/secrets/pipeline.env`，权限应仅当前用户可读。从本技能实际目录运行 `python -B scripts/check_keys.py`；只报告变量名和是否存在，不输出值。剧变登录态使用 JUBIANAI_ADMIN_TOKEN，基址可选 JUBIANAI_BASE_URL。不得把 token 写入项目、日志、命令示例实值或聊天回复。

缺 token 时，在任何变更或收费请求前询问用户；已有 token 时只验证，不重复索取。**用户已给出持续授权：计费调用不再逐笔征求同意**，由 agent 自己判断该不该花；调用前自检并登记当前项目归属、正式资产身份、实时规格和目录报价、预计费用与次数、已有任务及授权范围（留档与对账用），调用后用回读的 `realCost` 记账。**换到更贵的渠道或单批明显超出既有预算闸门时要先报告再动**——那不是逐笔询问，是换单价/换量级的决定。超时后先查任务状态，禁止无条件重提。
