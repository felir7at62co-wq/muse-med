# 首轮生成与同一标准验收

本流程适用于各题材剧本，目标是首次生成即满足同一组审查要求。写分镜和卡片前建立有原文依据的验收项，在首次收费前消除已知冲突，出片按同一标准核验。不以减少动作、降低标准或增加付费试生追求通过率；准备检查不能保证随机生成的实际结果。

## 首次提交前的共同要求

先运行Core的`episode_coverage.py <项目目录> source-scan`扫描声明范围内的全部原文，再逐集完成来源映射、台词预检和覆盖验收。结构、角色归属或发声歧义在写卡前解决，不能等轮到该集收费时再临时删改原文。没有出现的角色不添加；没有离开依据的在场角色继续保持原位置和原动作。

把审查依据写进现有制作记录并落实到实际提示词：原文行与台词/OS/VO；关键动作的起点、接触、支撑与落点；人物和道具的固定空间锚点及变化依据；目标物相对尺寸、结构、数量与消耗状态；参考素材身份和适用时段；自然试读、动作排演及模型可用时长。没有原文依据的条件不能成为硬验收项。适用项存在明确冲突或仍缺关键证据时先完成免费核对与修正，不以先付费试一版代替准备。

相邻镜头或分包沿用同场落点。摄影机取景覆盖角色所在位置时应呈现该角色，特写裁切不能被写成人物离开；位置、动作、表情与情绪只按原文发展。运镜可改善呈现，不能靠人物额外走位和夸张表演凑效果。按同一组事实逐项审片，不能出片后临时加标准，也不能为让首次结果通过而降低标准。

## 从原文确定结果

利用已有来源映射，为起身、交接、踩踏、切割、挂回等关键动作保留原文行及起点、接触或支撑变化、结束状态。关键道具记录具体对象、相对人物的尺度、位置、数量范围、初始形态、变化动作及最终形态。生成要求和审查依据共用这些事实，出片后不能临时加条件；不要求逐镜另写报告，可补充现有制作记录。

“一整条”“一个碗”通常指参与动作的对象，不能直接推出全场只能有一个。区分目标物、背景同类物及取景可见数量；只有取景覆盖同一空间位置时才能据此检查真实消失。正式场景图有多件时，不擅加“只准一件”与母版冲突。

收费前实看实际绑定的角色、场景和道具图：站立或垫高能否够到、器物能否承重、门窗和光源位置是否成立，完整/消耗/破损状态如何变化。日景母版不因加了“深夜”就自动适配，须区分沿用的布局与需要改变的光照。已有适用素材优先复用；实质冲突先解决受影响包，不在错误母版上盲目试生。

## 动作依据、用途与手部状态

逐镜先从原文确定实际执行者、操作对象、发生时机和结果，再写动作。动作行和对白中的表演括注都可提供依据；台词中的教学、命令、计划、假设、回忆或条件步骤只说明人物在说什么，不能自动变成说话人当场执行的动作。只在原文明确执行或前后文支持发生时才安排实施；“先完成条件，再执行”的顺序须有依据，不能从后续场次借来条件。原文明确边讲边示范时保留示范，不能一律改成静态说话。

对拿取、倒入、放置、抽出、交接、踩踏等关键交互，用已有动作起点、接触支撑与落点写清“谁，用哪只手或工具，从哪个固定位置，经过哪里，到哪个位置，松手后由谁或什么承托”。核对物件原本用途、容器内容和取用位置，不能只写“放到一边”“拿过来”让模型选择最近的容器；食品容器、燃料入口、废料盒等在布局上可能相邻，用途仍各自明确。必要的辅助描述只使原文动作可执行，不新增表演、道具用途或剧情结果。

把动作状态、手部状态、支撑关系及落点按同一时间顺序写。某手放稳原物、释放后才能接新物；交接双方握取与松开须衔接。只有原文支持且物理可行时才同时操作，不把前后阶段写成同一时刻，也不把最终静止手势写成全程姿态。动作、手部末尾的道具说明、关键道具与实际选源须相容；普通器物已由场景提供时说明来源，不因检查自动收费补图。条件不成立或原文确有矛盾时保留待核对，不悄改执行者或删动作过关。

原文未指定左右手、操作所需的小幅转身或器物在既有台面的具体落点时，结合已确认布局、当前持物和前镜状态，自主选择使原动作成立的最小执行细节并前后一致，不逐项向用户索取。原文已指定的手、位置和表演仍按原文；选择执行细节不能增加操作、跨越未发生的条件、改变结果或掩盖真实素材冲突。

必要执行细节优先复用本场已确认的器物和已释放的手，保持完成原动作所需的最少资源。未明示的器具先查实际场景与资产，不能仅凭常识假定它存在；先后操作通常可复用一只手，不为分工给左右手各新增一套器具。

准备动作止于原文终点。原文仅写拿起、查看或瞄准时，落点用可见的握持位置、工具朝向、身体与目标关系说明准备就绪，再留自然收束；后续真正操作由相应原文支持。不能为填满时长或展示道具，把拿起钥匙查看门锁自动接成开门，把持工具观察自动接成使用工具；只写“还没开始”不足以定义可生成的结束姿态。

原文明确误用、失手、喜剧笑点或非写实机制时，保持既定行为和后果，再按该设定核对身份、接触及因果。生活常理复核区分剧本故意设计与模型无依据的错误操作，不替作者纠正剧情。已出现错误结果时先回查动作本身是否有依据，再检查路径和落点；只补“不要放进某处”而保留无依据的动作，不能解决根因。

免费准备后逐镜回读实际动作、手部与道具引用，再对照原文和上述条件；本地分镜正确不证明提交内容正确。工具能提示显式先后动作缺少阶段或仍用估算时长，不能理解所有动作、验证依据真伪或自动判定两只手是否冲突。完成语义核对后再按同一套要求审片，不把`text_checks_passed`当作动作合理性批准。

## 动作与预算进入实际制作

按[表演预算](production-quality.md#表演与时间预算)排演身体重心、抓握、支撑、原台词、反应和收束。还没起身不能同时宣称“已坐直”，还没上凳不能站地上够肉。超出当前模型时长时沿因果拆镜，保留过程，不替换成“开场即盘坐”等原文没有的姿态。

复杂接触或多步先后动作可写三个独立字段；它们是画面指令，编译后仍进入实际提示词。使用时三项各写一次且有实际内容，普通表情或仅运镜无需添加。`动作状态`明确写“先…再/然后/随后/接着/最后…”时，即使没有复杂度标签，工具也会提示缺阶段或仍用估算时长；此检测不从台词或运镜文字推出人物动作，不覆盖所有自由表达。

```text
动作起点：人物双脚在地面，小板凳放在横梁下
接触与支撑：扶稳横梁，一脚踏实凳面，重心移稳后另一脚踏上
动作落点：双脚站稳在凳面，再伸手取物
```

机位要清楚呈现距离、支撑和完成状态，合理推近、拉远、横移或摇镜；不靠新增夸张表演迎合摄影机。OS/心声不按该句对口型，原文的吞咽、呼吸和表情仍可保留。

## 同场状态跨镜、跨包延续

同场关键人物和目标物使用稳定对象标识，以固定环境锚点记位置，不以“画面内/画面外”命名位置。无原文依据则延续；特写未列出对象不表示离开、消失或恢复完整。新包带入前包落点。

工具可比较下列独立行。`连续性状态`是本镜完成后的状态，数量针对这个具体对象，不是场景同类物总数。同镜可写多个不同对象，位置及状态沿用同一用词；未声明的对象保留同场最近状态。

```text
核心场景：旧灶房
连续性场次：15-3
连续性状态：人物甲｜横梁下板凳凳面｜双脚站稳｜1
连续性变化：人物甲｜原文“搬来小板凳踩上去”
连续性状态：目标物A｜横梁左一挂点｜完整厚实｜1
```

行内用全角`｜`或半角`|`分隔，值内不含分隔符；对象标识用稳定简称，不写素材链接。位置、形态/姿态或数量变化时，同镜写`连续性变化：对象标识｜原文动作或时空变化依据`，不填“无”“同上”“待补”。`连续性场次`仅区分原文场次，不能逐镜换标识隐藏变化；已有`场次 N-N：...`标题时可省略。昼夜或时间跳转须按原文分段，切镜不重置状态。

### 场景时段进入每个独立包

写卡前核对原文场次时段及场内时间推进，在该场首镜独立写`场景时段：傍晚`等原文支持的标签；已有`场次 N-N：地点 傍晚 外`标题时也可由标题取得。后续镜头沿用同一场景与连续性场次的最近时段，切镜、换景别和分包不推进时间。原文明确次日、黎明或蒙太奇推进时，在变化镜头写新的`场景时段`和`时段变化依据：原文对应描写`，后镜沿用新时段，不能把整集统一锁成白天或傍晚。

这两个字段各写至多一次且有实际内容；变化依据须与本镜明确时段同用。工具按标签比较，不验证依据真伪；同义标签先核对并统一。编译会将派生的`时段连续性`及光照要求补进每镜，并在时段变化处分包；直接写卡须自行将原文时段带入每个独立包，不能只在前包首镜写夕阳，或把台词提到的“昨晚”当成当前时段。实际准备缺少可继承时段时，`first_pass_review`返回`scene_time_missing`待复核；若原文确实未说明，按上下文核对并记录仍待确认的信息，不编造时段来消除警告。

实看实际选用场景图的天光、主光方向及明暗关系；空间布局适用不代表光照适用。明确沿用布局与锚点、按本镜原文时段呈现光照；母版与目标时段存在实质冲突时先解决素材适用性，不能靠一句“傍晚”保证改光成功。审片对照同场各包及接缝检查天空、太阳方向、环境光与人物受光，近景曝光变暗不直接等于入夜，画面平均亮度也不证明时段正确；无原文依据不得由暮色变正午或突然入夜。

`drama_shot`与`muse_production`报告声明格式、未解释的同场变化及复杂动作准备缺口；后续同场包自动带入已声明的前序状态。直接写卡也须自行带入；原生`prepare_video`的`first_pass_review`检查实际准备提示词的发声、动作阶段、连续性及包含估算的总时间。`needs_review`须在首轮提交前解决或核实具体冲突；`text_checks_passed`仅表示本次受支持的文本检查无问题，`media_acceptance=false`且未核项目保持可见。不能把它当成素材实看、原文覆盖或成片合格的凭证。警告不是成片判定，同义表达和合理变化须核实；工具不理解图片、物理尺度或依据真伪，填字段不能替代实看。

## 实际准备与复核

免费准备后读取`payload.modelConfig`，核对镜头边界、动作阶段、同场状态、原台词及OS含义、素材顺序和包时长。预算行留本地，正文保留实际动作顺序，不把整包镜头压成无边界长句。冲突回到写卡源头修正并回读，沿当前准备和其原幂等key提交；旧任务未知沿原key核对，不重复收费。

出片先确认当前文件及哈希，再按相同关键项看动作开始至落点的连续片段。拼图只定位疑点；硬判“没坐起”“没踩凳”前回看躯干角度、鞋底支撑的原片片段与全尺寸帧，并核对反证。前后景轮廓重叠不直接证明接触或穿模；不同机位、近景裁切和遮挡不直接证明对象消失。

核对同一道具在手中、悬挂处及切镜两侧的身份与形态，检查消耗后突然恢复、挂回时额外增加另一件。动作出现不能抵消状态穿帮。平均亮度不代替时段和光源判断，音轨非零不代替台词、说话人及口型核对；未听校的声音保持待验，不签发整包或整集通过。

需要证据时优先用原生`video_inspect`的metadata及局部sample，概览用`video_contact_sheet columns=3 rows=2`；继续检查未查看的时间点，输入收据不等于理解或验收。需要离线导出连续片段或缺少原生工具时，使用巡检技能的`video_review_evidence.py`：连续片段保留现有音轨，每页最多六帧，记录源文件及证据哈希，`review_status=pending`只表示待实际审片。确认缺陷、待核疑点和审美偏好分开记录；收费返工前复核硬失败依据及最小影响范围。不能临时增加“只能挂一件”“灯具必须特写”等要求改变原文。
