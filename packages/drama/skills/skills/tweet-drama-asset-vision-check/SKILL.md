# 资产自动视觉审核

对每个候选图实际查看原图，不能只读提示词或任务状态。审核结果写入 manifest 和独立 review 报告。

审核前先调用 `drama_project action=read`，核对当前用户明确要求与 `project_bible.style` 已一致，并读取已有的受众定位与创作说明。short-drama 预设名、本技能旧称、参考图媒介和模型名称都不提供默认风格。媒介或关键观感缺失、冲突且影响验收时集中确认；需要补充定位时沿[受众与影视风格方法](../tweet-drama-project-bible/references/audience-and-style.md)从已读剧本提出有依据的方案。仅缺可从当前方向确定的设计细节时自主具体化，不要求用户逐项补齐，也不为每张图另开分析轮次。受众假设不能代替用户要求或成为额外审校门禁。

仿真人审核允许与真人摄影质感融合的电影级玄幻生物与特效，不要求灵兽复制现实动物，也不因其具有温和、祥瑞的风格化造型就要求切换动画媒介。审核依据是项目约定的质感与观感，不能只因“很真实”而忽略温暖项目中的恐怖化偏差。

已确认 3D 动漫、三维动画或 3D 漫剧项目先加载 `anime-3d-assets`，以其人物版式、画风参考、PBR 材质及逐图验收规则制作资产。沿用既有项目圣经和清单；本技能的真人模板与真人审核规则不用于该分支。

## 审核维度

- 角色：身份、年龄、性别、地域、五官、体型、发型、妆容、服装完整度和场次状态；以项目要求的设定板为生成目标，检查脸部和服装是否清晰、不同视图是否为同一身份及同一服装、关键身体特征是否可辨。
- 动物与灵兽：物种、剧本尺度、头部与身体比例、关键外形、鳞纹或毛色和跨视图一致性；按剧情用途核对识别特写与完整体态，不强套人类面部或无面容三视图，不为亲和感改变物种，也不为体现体量放大原文设定。
- 场景：功能、年代、地域、布局、动线、陈设、光线、材质和后续竖屏取景可用性；必须是正常 16:9 空场景单图，不能误用角色设定板排版。
- 道具：类型、形制、尺度、材质、颜色、关键状态和剧情可识别性。
- 通用：与已确认项目风格一致、构图、肢体、文字、字幕、Logo、水印和明显生成瑕疵。真人项目审核真人感并排除动漫脸、塑料皮肤；动漫、国漫、二维动画、三维动画和 3D CG 项目审核其造型比例、线条或材质、渲染方式与项目风格一致，不得因缺少真人感判失败。
- 题材与观感：对照项目已定的情绪体验，实际查看轮廓、目光与口部状态、材质、光色和姿态。温暖、祥瑞项目若被明显的攻击姿态、湿黏猎奇细节或阴森用光主导，须记录具体位置与影响；悬疑或惊悚项目按其自身约定判断，不统一强加亲和要求。不能只读“仙气”“友好”等提示词就认定画面符合方向。
- 硬性禁用项：中国国徽、党徽、国旗等国家或政党徽标；军警制服、红袖章、革命标语、领袖画像等革命或政治标志物；人民币、外币等实体纸币或硬币；世界地图或可识别国界地图；天安门、故宫、长城、东方明珠等现实标志性建筑与地标。任一出现即判该资产 failed。

道具以正常 16:9 单件单图为目标，审核关键形制与后续生成可用性。除用户明确指定必须严格验收的版式外，排版、视角、留白和背景按可用性判断：干净浅灰或米白背景不因 RGB 非纯白判失败；左侧清晰的 3/4 侧脸可以接受；视图间距或排列的小偏差不单独触发重生。身份、服装、关键形态与项目核心观感符合要求且后续镜头所需信息足够时记录 pass，在报告注明偏差及适用范围，不为追求模板一致重复付费。身份或物种错误、服装版本错误、明显肢体畸形、关键部位遮挡或裁切导致无法用于目标镜头、背景严重干扰主体，或有可见证据表明明显违背项目已定的核心观感时，按具体影响判 fail；不能把轻微版式偏差或模型个人偏好升级成这些内容错误。

禁用项判定只看画面实际出现且可辨认的内容，不因提示词已声明禁止而放行，也不因题材联想就推定存在。支票、汇票、协议、合同、证件、银行卡等金融或法律文书**不属于现金**，不得据此判失败；无徽标的普通红色布料、包装或装饰同样不判失败。发现禁用物必须指出它在画面中的位置和具体是什么。

证件与文书类道具允许出现剧情必需的金额、日期、姓名，但出现国徽、真实机关名称或真实凭据编号规则时判 failed。

每项记录 pass/fail、分项分数、可观察证据和失败原因。失败时先核实原任务已终止并对账费用，再针对原因改写提示词；改写必须保留 `project_bible.style` 的完整原文和原提示词中的角色身份、外貌、服装与状态，不得跨到另一风格分支。仅在当前项目付费授权及剩余预算覆盖新请求时重生，review_attempts 加一。max_review_attempts=3 限制同一候选及其定向修正，三轮仍失败就阻断下游并给诊断，不自动降低标准或清零计数重投。找到新的合格参考图或明确根因并修正后，保留旧候选及三次失败记录，用新的 generation_version 和 idempotency_key 建立可区分的新候选与新收费决定；仍 pending、unknown 或已受理的旧任务必须先按原 key 回读，不能借新候选重复收费。

审核通过只写 asset_status=approved、official=false。随后必须用剧变插件的 `jubian_asset` `confirm_casting` 调用确认出演并回查；只有远端证据成功后才写 asset_confirmation=verified、official=true。镜头与视频只能使用正式资产。
