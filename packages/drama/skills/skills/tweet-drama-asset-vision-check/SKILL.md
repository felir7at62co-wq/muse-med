# 短剧资产视觉判断

实际查看候选图，结合已读剧本、用户明确要求、认可的参考和当前项目风格，判断它能否服务故事、传达情绪并产生视觉吸引力。沿用已知项目设定，仅缺必要信息时读取项目；不为每张图重做受众分析或新增报告。具体方法按本次任务决定。

人物魅力、形象与妆造，场景氛围，道具辨识度，以及跨资产的整体观感都可以影响短剧效果。3D 动漫默认保留次世代 CG、PBR 的风格方向，仿真人可融合电影级玄幻生物与特效，分别按本剧审美判断；只在需要 3D 风格参考时加载 `anime-3d-assets`。用户已定的温暖、祥瑞、浪漫或紧张观感应在实际图像中成立，不凭风格标签或任务成功宣称达标。

保持人物身份、剧情关键设定、物种与尺度、服装版本、重要道具功能和必要的多视图连续性。妆造与非关键视觉细节允许影视化设计。资产版式以当前系统提示词和用户要求为准；结合目标镜头可用性处理轻微偏差，避免机械重生。明显畸形、身份错误、关键部位遮挡或无法支持剧情的结构问题，应指出其具体影响。

简短说明实际看见的主要优点、影响使用的问题及调整方向，复用现有项目记录，不要求固定分项分数或独立审校报告。保留用户已经认可的设计，聚焦真正影响吸引力、情绪与故事的问题；美术判断不自动触发付费重生。

## 道具与剧情动作适配

先依Core的[动作依据与用途规则](../tweet-drama-core/references/first-pass-production.md#动作依据用途与手部状态)确认原文确有本次操作及正确执行者，再评估图像适配；区分台词教学与实际示范、故意失误与模型错误。道具用途、容器内容、真实取用口与落点也须符合原文及场景布局，不能仅以外观和尺寸相符判定适用。

角色需要站上、承托、装入、穿过、抓握或搬运道具时，先从本集原文确定使用者、动作、结果和必要的相对尺度，再实看本次选用的母版。核对动作涉及的有效空间、结构、接触点与使用方式；如脚能否站稳秤台、容器能否装下目标物、手能否握住把手、搬运方式是否与体量相容。支架底座不等于承载平台，秤台与计量机构的连接也须成立，不能让人踩一块独立铁板、另一台桌面小秤代为读数。只检查该动作需要的条件，不为普通摆件强加尺寸表。名称、正式资产身份和绑定成功均不能证明道具可用。

优先用脚掌、手掌、人体、门框等已知参照判断比例；透视、裁切或缺少参照导致大小不明时保留待核对，不能把特写占画面大当作实体大。剧本没有给尺寸时，只补充使原动作成立的必要相对比例，不编造精确米数、承重认证或改写剧情。称量量程与站立支撑能力分别核对：人站上可站人的秤台后超量程可以符合原文，小型手提秤缺少站立平台则不适用；不能为适配错误母版，把踩秤改成提秤、让角色缩小或额外夸张表演。

在现有资产或镜头记录中简短保留原文动作依据、选用的资产版本、实际看见的结构/比例及适用结论；分镜沿用该结论。结构无法支持剧情时暂停受影响镜头，先找已有适用正式资产；仍缺时定向修正母版并按既有授权生成和确认，不先付费试视频。证据不足只保留待核对，不能猜成通过。必要的功能看不出来时说明待核对条件，不把图片当作实物测量。提示词写“大型”不能抵消已绑定的小型母版。

成片复核关键动作开始、接触/受力和结果，以及道具首次出现到实际使用的相邻包；抽帧不足以判断动作过程时查看相应视频段。核对人物与道具比例、有效接触、道具结构和状态连续性，避免只认出物品就通过。影响剧情成立的冲突属于未修缺陷；用户暂缓修改只保留原视频和缺陷，不把它改判通过，也不据此触发收费重做。

## 禁用项与正式采用

- 硬性禁用项：中国国徽、党徽、国旗等国家或政党徽标；军警制服、红袖章、革命标语、领袖画像等革命或政治标志物；人民币、外币等实体纸币或硬币；世界地图或可识别国界地图；天安门、故宫、长城、东方明珠等现实标志性建筑与地标。任一出现即判该资产 failed。

禁用项判定只看画面实际出现且可辨认的内容，不因提示词已声明禁止而放行，也不因题材联想就推定存在。支票、汇票、协议、合同、证件、银行卡等金融或法律文书**不属于现金**，不得据此判失败；无徽标的普通红色布料、包装或装饰同样不判失败。发现禁用物必须指出它在画面中的位置和具体是什么。

证件与文书类道具允许出现剧情必需的金额、日期、姓名，但出现国徽、真实机关名称或真实凭据编号规则时判 failed。

失败时先核实原任务已终止并对账费用，再针对原因改写提示词；改写保留 `project_bible.style` 的用户已定方向、角色身份、剧情关键设定及已认可的外貌和服装；针对本次实际偏差调整妆造或表现，不跨到另一风格分支。仅在当前项目付费授权及剩余预算覆盖新请求时重生，review_attempts 加一。max_review_attempts=3 限制同一候选及其定向修正，三轮仍失败就阻断下游并给诊断，不自动降低标准或清零计数重投。找到新的合格参考图或明确根因并修正后，保留旧候选及三次失败记录，用新的 generation_version 和 idempotency_key 建立可区分的新候选与新收费决定；仍 pending、unknown 或已受理的旧任务必须先按原 key 回读，不能借新候选重复收费。

审核通过只写 asset_status=approved、official=false。随后必须用剧变插件的 `jubian_asset` `confirm_casting` 调用确认出演并回查；只有远端证据成功后才写 asset_confirmation=verified、official=true。镜头与视频只能使用正式资产。
