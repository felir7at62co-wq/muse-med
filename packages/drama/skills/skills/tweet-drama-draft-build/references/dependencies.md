# Draft build dependencies

The spoken-cue builder uses the Python standard library. Editable Jianying drafts require compatible `pyJianYingDraft`; `pydub` is optional for audio analysis. Media inspection also requires the draft library's dependencies, including MediaInfo where its distribution requires it. Desktop can supply these through its separate bundled media runtime; other installations must configure a compatible Python environment. The skill source package itself contains no site-packages, vendored Python libraries, executables, models, fonts or media.

Windows Desktop locks `GuanYixuan/pyJianYingDraft` 0.3.1 in its media payload and exposes `jianying_draft` without a shell. The library is Apache-2.0; its wheel is hash-locked by the desktop media preparer. The build smoke creates and saves a video draft and compares the saved JSON with the library output. Native-editor open/save and effects still require acceptance on the target Jianying build; reading encrypted existing projects is separate from generating a new project.

Use FFmpeg/ffprobe from the Desktop media runtime or a separately configured installation. `scripts/paths.py` resolves `DSH_FFMPEG_PATH` / `DSH_FFPROBE_PATH`, then `FFMPEG_PATH` / `FFPROBE_PATH`, then PATH. The `jianying_draft` tool configures the library's FFmpeg environment before importing it. Tail-frame extraction resolves `DSH_FFMPEG_PATH`, `FFMPEG_PATH`, `FFMPEG_BINARY`, then PATH; it decodes the selected video interval and compares RGB frame hashes before adding the editable image. `MUSE_DRAFT_DECODE_TIMEOUT_SECONDS` owns each FFmpeg process deadline (default 120 seconds); the value must be finite and positive. A deadline stops and reaps the child process, reports a draft input error, and removes only the new candidate draft. Raise it explicitly for a deployment that requires longer decoding; existing drafts remain intact. Keep this skill adjacent to `tweet-drama-core` for its project video-ban checks.

`scripts/align_subtitles.py` defaults to Muse cloud receipts supplied through `--cloud-transcripts`; it reads validated word timestamps and requires no local speech model. Offline use requires explicit `--model-dir` or `--model-url` with `--model-sha256`, separately installed `faster-whisper`, and a compatible model. The model resolver also understands `MUSE_WHISPER_MODEL_DIR` and `${DSH_HOME:-~/.dsh}/cache/models/faster-whisper`; `--cache-dir` overrides the cache. Desktop does not bundle the model or inference libraries. Explicit model downloads and writable caches stay outside installed skill resources.

Final cues require measured actual speech timing; 9-effective-characters-per-second estimates are draft-only. Supply each episode's reviewed multi-track BGM mix through `bgm`, separate from the clean dialogue in `audio`; the generator does not select or mix music.

Third-party code is not redistributed here. Verify the license and compatibility of the installed `pyJianYingDraft`, pydub, MediaInfo and FFmpeg build before use; licenses of the excluded local vendor copies were not established. Fonts, BGM and ending media require separate usage rights. No separate upstream license was present among the maintained skill files; this migration does not grant rights to excluded dependencies or media.
