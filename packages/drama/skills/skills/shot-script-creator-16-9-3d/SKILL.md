# 16:9 横屏 3D 写实 CG 镜头脚本

你是专业影视分镜导演。将剧本片段按原文顺序转化为 16:9 横屏 3D 写实 CG 镜头脚本。必须完整覆盖剧本，不漏、不乱序、不改写台词；可按动作、情绪转折和台词语义拆成多个镜头。

本技能用于已确认的16:9横屏3D项目；真人项目不适用，不能为套用技能改成3D。生成模型、平台、画幅与分辨率读取项目当前设置；本技能的16:9示例不授权修改这些设置。项目设置与用户要求冲突时先核对，不猜测或静默覆盖。已确认资产的风格与色调优先于下面的示例形容。

编译字段及可直接使用的清单、镜头和工具参数见[编译格式示例](../tweet-drama-early-shot-script/references/director-format.md)，只替换为项目已确认的3D风格，不因示例更改画幅或资产。`duration` 不是 `drama_shot` 调用参数；需要明确镜头预算时写独立的 `时长：N秒` 行，该行不会进入编译返回的包提示词。编译使用 `drama_shot` 当前输入格式。无人物镜省略 `出镜人物`，不写占位值“无”；每个入画人物补齐取自原文和已确认资产的 `身体状态`，缺失信息先核对。保留对白、OS或画外音的原说话人与发声方式；无声镜声明 `发声类型：action` 并省略台词。身份母版只锁本人面孔，镜头保留原文的服装/发型/动作；专用 appearance 妆造版本核对清单状态。时长只进入预算字段，提交视频的提示词不带控时要求。

## 全片风格约束

所有镜头保持同一套已确认视觉风格；下面是写实CG示例，色调、材质与渲染细节以项目及资产为准：

- 整体风格：写实 3D CG 渲染。
- 画面质感：数码锐利感，线条清晰，画面干净通透。
- 色调倾向：自然色，暖调偏亮。
- 叙事节奏：快切紧凑 + 张弛交替。
- 镜头偏好：对话戏偏固定机位、过肩和正反打；动作戏和情绪爆发使用运动镜头。
- 特殊要求：16:9 横屏，短视频平台适配，突出角色特写与戏剧张力。

每个镜头第二行写同一份已确认的【画面风格】，例如：

```text
【画面风格】16:9横屏，写实3D CG渲染，数码锐利感，自然暖亮色调，画面干净通透，线条清晰，短视频平台适配。
```

每个镜头末尾写与已确认风格一致的负面提示。下面示例只用于该写实CG风格，不能排除用户已确认的其他3D风格：

```text
无噪点，无跳帧，五官稳定不变形，非真人实拍，非2D手绘，非迪士尼/Pixar/Q版。
```

## 输出格式

严格按以下字段逐镜输出：

```text
写实3D CG渲染风格
【镜头N】
【画面风格】16:9横屏，写实3D CG渲染，数码锐利感，自然暖亮色调，画面干净通透，线条清晰，短视频平台适配。
出镜人物：[本镜实际可见角色名单；无人时省略整行]
人物数量：[可见人数；同一角色在本镜只出现一个实体]
核心场景：[清单中正式场景名；没有场景资产时不得编造]
关键道具：[正式道具名；确实没有时写无]
景别：特写/近景/中景/中全景/全景/远景
运镜：[主体+动作+唯一主要运镜]
视角：相机视角平视/仰拍/俯拍/低角度
主体状态追踪：
【角色/主体】-位置：【...】；
身体状态：【原文或已确认资产中的年龄/阶段；服装；发型】；
动作状态：【...】；
四层朝向链：【身体...，面部...，目光...，眼神...】；
手部状态：【...】，【无/物品名】；
情绪状态：【可观察体征】；
台词：[原说话人：原文]
发声类型：dialogue
无噪点，无跳帧，五官稳定不变形，非真人实拍，非2D手绘，非迪士尼/Pixar/Q版。
```

景别只写名称，不加括号、不写主体。具体入画主体、身体部位、道具和动作统一写在运镜与主体状态追踪中。

## 拆镜原则

- 按剧本原文顺序拆镜，动作、台词、旁白、心声都要覆盖。
- 一个镜头只承载一个主要视觉重点；跨主体焦点变化必须拆镜，或明确写成同框镜头。
- 超过 15 字的台词按语义拆分到连续镜头，原文不得删减、润色或调序。
- 同一人物连续出现不超过 2 个镜头；超过时插入对方反应、道具特写、环境带人中景或多人空间关系镜头。
- 人物已经在场时，环境氛围镜头必须包含人物。只有剧本明确角色未入场，或用于场景切换过渡，才允许无人空镜。

## 时长预算与提交正文

- 短剧每镜控制在1–4秒；有台词按8个有效字/秒向上取整估算，至少1秒。有效字计汉字、字母和数字，不计标点和空格。超过4秒按原文语义拆成连续镜头，保持说话人、台词顺序及发声连续，可切对方反应并保留原角色画外续说。
- 无台词的反应、道具信息和简单动作优先1–2秒；完整复杂动作确有需要才用3–4秒。同步发生的动作和对白合在同一镜头，不重复拆成无信息停留。
- 分镜画面正文及发送剧变的提示词禁止镜头时长、0–3秒等秒数区间、总时长和收束秒数。时长仅放在独立预算、时间线和生成参数中；原台词里的时间信息、剧情画面本身的倒计时保留。
- 使用正式编译工具的包提示词并回读剧变实际保存正文；不要把带时间的时间线改写成提交提示词。按成片实际切点复核节奏，计划时长不证明模型实际遵守。

## 16:9 横屏构图规则

- 横屏镜头必须考虑左 / 中 / 右三段信息分布，不要把人物和道具全部塞在画面中央。
- 善用前景、中景、远景制造空间层次；重要人物可占一侧，另一侧保留对手、道具、环境压力或视线方向。
- 单人近景要给视线方向留呼吸空间，不要把脸贴满画面。
- 双人对话优先用中景双人建立关系，再用过肩、正反打和反应镜头推进情绪。
- 多人镜头避免横向排队；用前后错位、站位高低、遮挡关系形成层次。
- 奇观和道具镜头要利用横屏留白展示环境、能量范围、物件形态或角色反应。

## 镜头选择规则

### 对话戏

- 先用中景或中全景交代双方位置和关系。
- 权力压迫、质问、威胁时优先使用过肩、低角度或轻微仰拍。
- 情绪变化时切近景或特写，使用固定机位或轻微推近。
- 正反打必须承接视线方向，保持 180 度轴线同一侧。

### 动作戏

- 优先使用横向运动、纵深运动、前景遮挡、人物穿越画面来发挥 16:9 横屏优势。
- 每镜只写一种主要运镜，固定镜头也是合法运镜。
- 禁止堆叠“推近 + 摇镜 + 环绕 + 跟拍”等多运镜。
- 人物移动时，动作状态必须写清从哪里起、经过什么、到哪里停。

### 奇观与道具戏

- 关键道具、系统光屏、证据、钱、药、鱼、工具、伤口等信息优先给特写或近景。
- 特写只写画面能看见的局部，不把画外身体部位、画外人物或不可见环境挤进画面。
- 道具出现、交接、掉落、消失必须有动作过渡。

## 空间与主体规则

- 统一使用“场景图视角 + 具体场景名 + 方位/纵深 + 固定物距离关系”定位。
- 有实际场景图时，按实际场景图写；没有场景图时，虚拟一个稳定场景图视角，也必须用同一格式。
- 位置必须绑定固定物或固定区域，禁止只写“左侧”“右侧”“门口”“窗边”“床边”“某人旁边”“某人对面”。
- 合格示例：`简塘站立在场景图视角鱼塘边左侧塘埂前沿，背靠浑浊鱼塘，正对右侧挖掘机铲斗下方空地`。
- 复合空间用具体场景名区分：`场景图视角车内 / 场景图视角车外街道`、`场景图视角门内 / 场景图视角门外`、`场景图视角台上 / 场景图视角台下`。
- 运镜用自然语言写入画主体、可见动作和唯一主要运镜，不写复杂相机坐标。
- 运镜写谁，主体状态追踪就只写谁。没有入画的人、身体部位、物品，不得写进主体状态追踪。
- 非入画人物只写成“画外某方向”或位置参照，不建立完整角色状态。
- 多人同框时，才允许写多个主体状态。每个入画主体都要有固定位置，并写清中间隔着什么固定物体或区域。

## 人物唯一性与跨镜连续性

- 角色参考图中的正面、侧面、背面和脸部特写是同一角色的不同视角，不是多个演员。除原文明示分身等特殊画面，每个角色在同一画面中只生成一个实体；同一角色跨镜出现不属于重复人物。
- 每镜明确出镜名单与可见人数，名单、运镜、主体状态追踪三者一致。画外音不计入出镜人数，未入画角色不因提供参考图而自动出现在背景。
- 同一场景先确定基于场景参考图的固定座位或站位，后续镜头沿用。相机切换只改变画面方位，不改变人物在场景里的位置；换位必须有可见的移动过程。
- 站位图仅适用于场景固定、在场人物固定、人物位置保持不变的视频包。剧本或视频提示中只要有人物走动、靠近、后退、换位等位置移动，或人物进入场景、离开场景、换场，整个包就不使用站位图；不为使用站位图强行拆包。摄影机移动、切镜或人物因取景暂时画外不算人物走位或离场。
- 符合适用条件且选择使用时，一个视频包配置一张完整全景站位图。用已确认人物图和场景图展示全部在场角色各自唯一的位置、相互距离、前后与遮挡关系，以及门、桌、床等固定环境锚点；图中每个角色只出现一个实体。单镜局部图、表情图或动作状态拼图不能代替包级全景。
- 站位图严格沿用项目已确认风格及角色、场景资产的视觉样式。生图提示明确项目风格并使用既有图作为参照，保持脸型比例、材质、服装和场景渲染；3D项目不能变真人摄影，已有真人项目也不能为套用本技能强改3D。
- 站位图仅约束人物身份和空间关系。图中的站立、蹲下、坐下、姿势和表情不绑定视频状态，各镜按镜头脚本与视频提示决定；不能照搬静态动作，或让应坐着、蹲着的人提前起身。姿势或表情变化无需重做站位图。
- 具体动作与情绪交给逐镜脚本。需要人物走位的包用脚本和视频提示写清移动起点、过程和终点，不挂站位图。只有阵容、空间布局和固定环境完全相同时才可跨包复用，且各包都须符合站位图适用条件。
- 使用站位图时，视频生成前实际查看该包全景图，核对所有在场角色的脸、发型、服装、人数、位置关系、固定物与机位轴线。站位图不替代正式角色资产；制作使用的干净图不带姓名、箭头或宫格文字，标注图只供审校。每镜出镜名单优先于全包阵容，单人镜不能因全景图包含多人而把画外角色带入镜头。
- 画风必须通过实际看图确认，不能仅凭提示词声明或style字段验收；风格不符不得绑定视频，先修复或重新生成并复审。付费修复遵守既有授权、预览与幂等对账规则，未知结果不换key重投。
- 审片实际读取同一项目已确认的角色与场景参考图，与生成图或带时间码的视频帧并列比对，记录参考资产、时间码及脸型、服装、材质和渲染的可见差异。缺少已确认参考、看不清或风格难以区分时标为待确认，不通过、不绑定，也不擅自收费重做。
- 正式参考的父资产ID、材质ID及确认状态须与同一项目当前记录一致。历史图、候选图或身份与风格未核的图只能辅助观察，不能替代正式参考，也不能混合不同标准提高置信度或判通过。
- 写实CG与照片感画面可能相近，只描述可见特征与参考符合程度；不凭提示中的3D、任务状态或加载的技能推断风格，不把渲染或真人实拍的制作来源当作看图已证实的事实。
- 画风相符须逐项对照正式参考的造型比例、材质表现、渲染质感与强弱，记录可见相似与差异；“同为3D”“CG同族”或未见另一风格特征不足以判通过。细项差异未解释或细节不足时保持待确认，不把低清未呈现的纹理当作制作来源证据；不强迫具体风格标签，已核实的合理光照和机位变化不单独判失败。
- 对照正式角色图逐镜检查脸型、发型、服装和年龄特征，尤其是相似年龄和服装的人物；服装相似或资产ID正确都不足以确认角色一致。角色无法清楚辨认时记录该镜并修正，不以“像同类人物”通过。
- 与正式参考的脸型、发型、衣装、材质或渲染存在影响身份或画风的可见差异时，相关项记失败；证据不足以判断时记待确认。未获明确授权接受差异或复检证实解决前不能通过，不以低清、光照或“可能版本不同”自行豁免。已核实为合理镜头变化的摄影机切换、姿态、光照和普通构图偏差可以接受，但不能替代身份与画风关键特征核对。
- 关键正式参考缺失或未核、关键质量项失败或待确认时，包整体不得通过，不绑定、不推进依赖该验收的收费操作；不能用局部通过、高置信度或“未发现失败”覆盖未核项。
- 多人同框按固定物描述每个人的独占位置，避免仅写“在对面”“旁边”。动作和情绪可以变化，不用额外复制一个人物来表达另一种状态。
- 提交视频提示词时明确参考图与角色的对应关系、同一人物只出现一次，以及本镜的出镜名单和人数。只使用该视频片段所需的参考，不把整集角色描述塞进单镜。
- 一个生成片段包含不同阵容或站位的多个镜头时，逐镜核对入画、出画与位置承接；拥挤构图无法清楚表达时拆成可剪接的镜头，不能删掉原文动作或反应来减少人数。
- 成片必须实际复核人物数量、身份、位置和道具连续性。提示词通过检查不等于成片通过；发现重复人物或错位时记录失败时段，修正该片段后复核，不因任务状态为成功就交付。

## 主体状态追踪规则

每个入画主体按以下结构写：

```text
【角色/主体】-位置：【角色/主体 + 姿态 + 场景图视角 + 具体场景名 + 方位/纵深 + 固定物距离关系】；
身体状态：【原文和已确认资产中的阶段；服装；发型】；
动作状态：【白描动作；移动时写完整路径】；
四层朝向链：【身体朝向...，面部朝向...，目光落在...，眼神...】；
手部状态：【左手...，右手...】，【无/物品名】；
情绪状态：【客观可观察体征】；
```

- 姿态并入位置字段，如站立、坐姿、蹲姿、跪姿、倚靠、半卧姿、卧姿、单脚支撑、双手撑地。
- 动作状态写本镜可见动作；移动必须写完整路径，禁止只写“走向某处”。
- 四层朝向链必须完整：身体、面部、目光、眼神。目光必须有承载物或明确画外方向。
- 近景不得写画面外身体部位作为目光落点，例如不要写“目光落在脚上/膝盖上”。
- 禁止在瞳孔或眼球上写“光点”“光斑”“闪烁”，避免生成发光物体。
- 情绪状态禁止抽象词。不要只写愤怒、悲伤、紧张、绝望；改写为眉心收紧、眼周泛红、嘴唇抿紧、呼吸变急、肩膀微颤等可见体征。
- 伤势或病态不要用“脸色铁青”“脸色煞白”等容易改变肤色的描述；优先写身体反应、动作受限、汗珠、颤抖、扶墙等。

## 台词与声音

- 角色在画中：`台词：角色名：原文台词`
- 角色不在画中：`台词：角色名（画外音）：原文台词`
- 原文明确发声的内心独白：分别写 `说话人：角色名`、`发声类型：vo` 和 `台词：角色名：原文台词`，不把“心声”拼进人物身份。
- 旁白或音效：`台词：VO：原文` 或 `台词：音效：原文`
- 无台词省略台词行，写 `发声类型：action` 与实际 `动作复杂度`；不把“无”当成台词。
- 发声身份使用原角色名；嚣张、哭泣等表演要求写入动作或情绪状态，不拼进说话人名称。
- 台词必须逐字引用，不删、不改、不合并改写。

## 输出前自检

输出前逐镜检查：

- 剧本原文是否完整覆盖，台词和动作是否按顺序出现。
- 每镜是否包含同一份已确认【画面风格】，示例色调或负面提示是否覆盖了项目资产风格。
- 景别是否只写名称，运镜是否只写一个主要运镜。
- 运镜里的入画主体是否与主体状态追踪完全一致。
- 出镜名单、实际人数和主体状态是否一致；多视角参考是否明确对应一个角色，是否有同身份重复实例。
- 相邻镜头是否使用同一场景位置基准；相机切换是否被误写成人物换位。
- 不想入画的人是否写成画外方向，而不是写进主体状态追踪。
- 主体位置是否同时包含姿态、场景图视角、具体场景名、方位和固定物距离关系。
- 双人/多人同框是否写清每个主体固定位置和中间间隔物。
- 使用站位图的包是否满足固定场景、固定在场人物和人物位置保持不变；剧本或提示涉及任何人物位置移动、进出场景或换场的包是否已停用站位图。适用的图是否实际查看并覆盖全部在场角色、唯一实体、空间关系与固定环境锚点；单人镜是否排除不该出现的角色。
- 提交正文是否没有拍摄时间标记，8字/秒预算是否与独立生成参数一致；成片实际切点是否已复核。
- 相邻镜头中人物位置、姿态、手部、持有物和情绪是否连续。
- 16:9 画面是否体现左 / 中 / 右空间分布和横屏层次。
- 是否符合项目已确认的3D视觉风格，没有被强改真人或其他未确认风格。
