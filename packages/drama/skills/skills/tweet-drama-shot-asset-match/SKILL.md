# 镜头正式资产匹配

镜头设计与资产选择是一个逻辑阶段。写每镜时就从当前剧变项目“主体设定”的实时父资产中确定角色服装版本、场景状态和关键道具，禁止从本地候选目录、旧分镜、历史视频或名字相似项猜图。

**先写角色状态卡，再绑定；状态卡现在是机器可校验的字段。** 每个角色每集先写明本集**体型**（孕周、年龄段等）、服装版本、发型和时段，全部取自剧本原文或已确认大纲；剧本写明孕周的，状态卡记下那个周数。状态卡落到实处就两处，两处都要写：

1. **镜头侧**：每个入画主体的 `主体状态追踪` 段落里写一行 `身体状态：【阶段；服装；发型】；`（与 位置/动作状态 同级，不带角色名前缀）。没有体型变化也要写 `非孕期`。
2. **资产侧**：`assets_manifest.json` 的每一行写 `episodes`（具体集号数组，如 `[25]`；全剧通用母版写 `["all"]`）和 `state_or_costume`（阶段/体型语义 + 服装，如 `孕早期（孕八周）、孕期职场装、长发`）。

`drama_shot` 的 `validate`/`preview`/`compile` 会逐镜比对两侧：孕期阶段与年龄段必须写同一组且同值，服装/发型等文字必须能在资产登记里找到；只有一侧写了就是未标阶段，直接判失败并点名资产 id 与修法。设定板是孕晚期身形、剧本写孕八周，就是挂错了版本——**不得因为资产名带「孕期」就照用**。清单里根本没有该状态的版本时，`validate` 会给出补料需求（角色/阶段/服装/用于哪几集）与补料路径：从 `jubian-asset-library` 复用，或生成后登记，再跑 `drama_assets reconcile`，然后重新校验。跨集跨越时间（「数月后」「五年后」）时状态卡按集变化。每个分镜在 `jubian_storyboard` 的 `select_assets` 与 `drama_shot` 的 `compile` 之前跑一次带 `episode` 的 `drama_shot validate` 取 `ok`，不一致先停下换资产或补资产，再提交。

每个绑定至少包含正式名、类型、适用集和场、视觉提示词、数字 `jubian_asset_id/materialAssetId`、剧变 URL、`official=true` 和主体设定实时详情证据。生成资产还必须包含 `jubian_material_id`、确认时间和确认出演响应；`isLocal=1` 的主体设定直接上传资产可以没有生成 material ID，但必须属于同一 `scriptId`、`delFlag=0` 且实时父资产 URL 有效。

matched JSON 只能记录主体设定当前版本；分镜中的 `materialAssetId`、`assetId`、URL、名称/缩略图和提示词映射必须共同指向该版本。生成资产的字符串 `assetId=asset-...` 不得当作父资产查询 ID。

候选图、仅自动审核通过的生成图、缺确认响应的生成图一律拒绝。人物必须选择当前场次正确服装和阶段；场景、道具必须符合当前时空。同一镜头引用顺序必须和视频提示词中的人物映射一致。出现新旧字段混合、已删除资产或缺少核心资产时，回到主体设定重新选择或资产生成与确认出演，不得用相似图顶替。
