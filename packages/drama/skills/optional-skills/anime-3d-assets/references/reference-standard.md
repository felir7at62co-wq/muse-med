# 图二画风基准与严格交付审查

女主质量补充基准见 [女主画面参考](female-quality-reference.md) 与其中原图，仅学习 CG 表现质量，不扩大身份或版式继承范围。

## 本轮参考对应关系

`male-quality-layout.png` 为本轮图二，学习质量及无头身体版式；`target-quality.png` 为本轮图三，仅学习质量，不继承带头身体版式。下文旧称“图二基准”指两张正向图的质量标准。

[本轮图一拒收样本](images/rejected-flat-cg.png)：面部细节与骨相明暗偏弱，头发密集均一，服装虽有布纹但折叠、缝口和表面层次不足。无头版式正确不能抵消材质不达标。截图底边被截，不能据此推断原文件鞋底缺失，须检查真实输出。棉衣厚薄由剧本决定，不靠换薄衣、露肤或复制参考脸提升质感。拒收图仅用于本地审查，禁止作为生成风格输入或身份母版。

## 必须实际读取的图片

- [新增男主画风与版式参考](images/male-quality-layout.png)：用户提供的《屏幕截图 2026-10-08 170847.png》。学习自然骨相的表现精度、皮肤微纹理、织物厚度和白底展示，以及左侧肖像、右侧无头身体正侧背至鞋底的区域组织；禁止继承五官身份、盘扣服装、束腰、发型或截图水印。左侧原图是近景胸像，正式交付允许完整头顶至胸部，也允许延伸至上衣／外衣下摆，不再强制到腰部；只参考右侧无头范围与版式，不照抄颈部截面。

- [目标图二](images/target-quality.png)：用户提供的《屏幕截图 2026-10-07 131804.png》，是画风、造型细致度、材质和光照层次的必达基准。
- [拒收图一](images/rejected-cartoon.png)：用户提供的《屏幕截图 2026-10-08 154218.png》，仅用于审核对照，禁止作为正向参考传入生成服务。界面按钮与叠加水印不属于角色造型；不能仅因截图分辨率和界面覆盖判定原始资产质量。

每次创作和验收都实际打开目标图，不以文件名或文字摘要代替看图。用户要求“完全按照图二”锁定的是同档画风与质量；人物身份、年龄、服装和时代按剧本，不能靠复制夹克、眉疤或同一张脸冒充风格一致。目标属于自然比例、适度风格化的高精度三维 CG，允许细腻的物理材质与皮肤微纹理；不能为了“非真人”把骨相、皮肤和毛发降为简化卡通。图一式夸张眉眼、光滑均一皮肤、过度简化造型不得作为本标准的合格替代。

## 参考图必须进入实际生产链路

将目标图归档到当前项目的参考目录，记录来源为用户提供、用途 style、文件路径与实测 SHA256；仅作为本项目制作参考，不宣称取得未核实的外部分发许可。在 `generation.references` 记录目标图和实际提交的参考文件或服务端引用标识。生成工具支持视觉参考时，必须传入用途隔离的目标风格参考；完整图或不含人脸的派生局部均须记录实际使用方式，不能为满足传图要求而引入参考身份。图二只能标为 style，不得标为 identity、角色换装基图或保脸参考。identity 只能使用按当前剧本独立设计并通过审核的本项目人物母版；尚无母版时先创作新脸，禁止用图二人物顶替。服装按剧本限定。工具不能隔离风格和身份时，先使用不含人脸的材质／光照局部参考或支持风格隔离的工具；不得把完整图二当人物底图要求保脸换装。局部参考保留来源与实际处理记录，图二原图仍用于质量审核。

上述完整人物图的用途隔离不等于场景输入已合格。生成场景另执行 [无人物实际参考输入](scene-assets.md#实际参考输入)，不把人物设定板或仅去脸仍留人形的裁剪传入场景请求；图二和人物母版保留作本地画风对照。

工具不支持图片参考或图片传入失败时，不得静默退回纯文字后声称严格匹配；可交付待生成提示词与能力缺项，但不提交声称满足本标准的正式资产。先验证一个身份候选的画风质量，通过后再派生同一角色其他视图和换装；未通过的图一式候选不得成为新的身份或风格基准。保留实际模型、尺寸、完整提交文本和参考使用记录，不猜测模型或参考权重。

## 与目标图逐项对照

在同等显示尺度比较候选原图与目标图，检查整体、面部和材质细节；截图缩放不能替代原图检查。记录比较文件、观察区域与具体差异，不用“都是 3D”“有 PBR”“高清”作为通过理由。

| 维度 | 图二基准 | 拒收偏差 |
|---|---|---|
| 造型 | 自然比例的五官，眉弓、眼眶、颧颌和唇鼻有细致连续转折，保留剧本年龄和个体差异 | 用夸张眉眼、大眼、过度收尖下巴或简单卡通块面替代细致骨相 |
| 皮肤 | 柔和皮下色层、局部肤色变化、细微表面起伏及粗糙度差异，明暗有厚度 | 均一橙色、蜡像油亮、橡胶感、磨皮到无纹理；为回避真人而压掉细节 |
| 毛发 | 发束有疏密和走向，束内细丝、发梢与边缘层次清楚，反光随方向变化 | 塑料壳、密实均一毛毯、整齐针刺、平面糊发；具体发型仍按年代和剧本 |
| 服装 | 可辨纤维、厚度、缝线、折边、受力褶皱，局部磨损有层次，各面料反射不同 | 有一层布纹就算通过、贴图式褶皱、纸片衣领、统一塑料高光；新衣无须强加做旧 |
| 光照 | 大形明暗与局部层次并存，柔和过渡、适度轮廓和接触阴影，材质细节可读 | 平光压平骨相，过曝掩盖纹理，强锐化或噪点假装精细 |
| 场景与道具 | 延续上述 CG 体积、材质厚度、粗糙度层次与光照逻辑，保持空间与交互尺度 | 低模卡通环境、平面纹理、实拍背景拼接或人物与环境质感断层 |

图二不含场景，不能宣称已有场景样本验证；场景须与通过的人物基准对照验收。自然比例与皮肤微纹理本身不是“真人失败”，禁止实拍替代不等于禁止精细 CG。

## 验收记录与采用条件

沿用 schema 2 的 `review.quality_checks`，加入 `reference_style_match`、`delivery_layout`、`aspect_ratio`，每项记录 result（pass/fail/not_checked）、证据与文件路径；`pbr_material_quality`、`market_readability`、`era_consistency` 等既有检查继续生效。`reference_style_match` 按上表逐项写证据，任何关键偏差均判 fail，不能以其他高分抵消。

没有实际图片、原图不可访问、缺少必要视图或未对照目标图时记 not_checked。不得把生成成功、上传成功或“导入资产库”按钮当成通过；只有适用必查项全部 pass 才可正式采用。身份母版阶段先查本图与目标，跨资产组合在配套文件齐备后单独验收，不能形成必须先有已通过场景才准审核人物的循环。

场景资产默认 16:9 横向单图；其他比例先询问使用者，已有明确指定或确认则直接沿用并记录依据。不得从竖屏成片比例推断场景比例。具体执行 [场景优化规范](design-and-prompts.md)。画幅由本次明确资产要求决定，与视频成片比例分别记录。16:9 场景图必须横向，提示词与实际工具的比例或宽高参数一致；不允许竖屏项目覆盖。下载后读取实际 width/height，确认宽大于高并符合请求比例；供应商近似档位须明确记录并按精确交付要求处理，不静默当成精确 16:9。错误方向、漏视图、错误视图和错误头部范围都属于交付失败，不能按轻微留白偏差放行。

修正按既有最多三次新生成与预算规则执行；持续失败则保留候选和诊断，不降低基准、不无限重试。技能约束提交和验收，不承诺生成模型每次都能匹配。

## 人物正式交付版式

默认单张 16:9 横向白底设定板，左侧为同一角色正面半身像，右侧依次为无头身体正面、严格侧面、背面三视图。用户明确指定其他画幅时保持该比例，但仍须满足全部内容范围。

- 左侧人物展示须保留完整头顶、发型、面部与颈肩，正面展示；取景下边界可到胸部，也可延伸至所穿上衣／外衣下摆，胸部至下摆之间（含腰部）的自然取景均可。无需统一固定到腰部，不因合格胸像或下摆取景而重生。不得裁掉头顶，或用仅脸部特写替代。右侧无头身体正面、严格侧面、背面至完整鞋底的要求不变。
- 身体三视图均不展示头部，不出现脸、眼、耳、下巴、头发；从颈根／衣领肩部至完整鞋底，衣领和肩线不能裁没，不出现血腥断面或漂浮头部。
- 正、侧、背各一张，同体型、同服装、同尺度和脚底基线；侧面不能以三分之四斜侧替代。手部、裤脚和鞋底完整，无遮挡、额外肢体。
- 半身与身体三视图的衣领、纽扣、袖口、口袋、主色和材质一致，饰品和补丁按角色自身左右一致。身体图不含头部，脸部身份仅由半身与母版核对，不虚称已检验三角度面部一致性。
- 图二只提供画风和质量标准，不继承其中带头全身三视图的旧版式，不用仅头部三视图替代身体三视图。

`delivery_layout` 分别记录正面半身范围、三种身体视角、三张均无头、完整鞋底、同尺度基线、同版服装及左右连续性。任一错误均 fail，缺图或看不清记 not_checked。不得以整体美观或轻微排版偏差豁免。无法一次生成时可基于同一通过母版分图制作后排版，保留原图与处理记录，再检查接缝和一致性；禁止拉伸身体或裁掉鞋底凑版。

场景验收除 aspect_ratio、era_consistency 外，必须执行 cross_asset_style_consistency，实际对照已通过的人物母版检查造型、材质和光照质量；无人物基准时不能宣称已完成匹配。scene_condition 使用既有 quality_checks 结构，记录场次依据和实际环境状态；正常农村被无依据做成破败废墟、过度污损或以跨时代装修换取整洁时判 fail，缺少图像或依据时记 not_checked。其他比例未取得使用者明确要求或答复时不得提交生成。

无人场景的 `scene_clean_plate` 和 `scene_reference_isolation` 按 [逐图验收](scene-assets.md#逐图验收) 执行；人物很小、模糊、位于远景或只出现在倒影中也不能按轻微偏差放行。提示词写无人不能替代看图，参考标签写 style 不能替代实际输入核对。


## 五官独立设计与参考污染拒收

图二仅提供画面风格、渲染质量、材质与光照表现；不提供五官身份、脸型模板、固定发型、眉疤或衣服。先从剧本、已确认人物设定和用户提示词形成脸部设计，按下沉准则落实清爽、耐看、眉眼有神及符合经历的气质。明确记录脸部宽长关系、颧颌轮廓、眉形、眼形眼距、鼻型、唇形与年龄线索。剧本未规定的细节可原创设计并标记为美术选择，不编造剧本依据，不固定成图二同款脸。

禁止“同图二人物、保留参考五官、参考人物换装、照图二脸生成、图二身份一致”等指令；允许保留的同脸只针对本项目独立设计且已通过的身份母版。审核新增 `face_design_compliance`：先对照剧本／设定，再对照图二检查是否出现明显同脸、近似换装复刻或仅更换肤色发型的变相复制。逐项写五官组合与骨相的可见证据，不编造人脸相似度数值；单一共同特征不判失败。明显高度相似、与设定冲突则 fail，不确定则 not_checked，不得放行。已经形成图二近似脸的候选须回到独立脸部设计，不得继续派生换装。

## 无头身体视图的提交与逐格复核

此处“无头”是服装身体展示的取景范围：头部在该视图画面之外，画面从颈根衣领／肩部到鞋底；不是断头角色、透明头、模糊脸、黑色遮脸或带头剪影。只有左侧正面半身像显示完整头部。任何右侧身体视图出现头颅、脸、耳、下巴或发丝即 fail，不因参考原图带头而放行。

生成前将版式分成 A 正面半身、B 身体正面、C 身体严格侧面、D 身体背面，标签仅用于提示词和审核记录，不绘制到图上。生成后分别打开或放大 B/C/D，逐格记录可见上边界、头部是否完全排除、衣领肩线、双手和完整鞋底；整板缩略图不足以通过。A 单独检查正面、完整头顶及胸部至上衣／外衣下摆之间的自然取景；不将未到腰部作为失败理由。

若整板生成仍出现带头身体，改用同一已通过身份母版分别制作 A/B/C/D 后排版；B/C/D 以衣领肩部至鞋底的独立视图制作。必要裁切只移除头部区域并保留衣领、肩线、手和鞋，不允许拉伸、模糊遮脸或整体裁切同时损坏左侧半身像。若裁切无法满足范围，定向重做对应视图。处理仍受既有尝试与预算上限约束，最终合成板重新逐格验收，不以处理完成代替通过。

## 多次生成的五官差异要求

执行 [五官结构对照、提交核对与视觉验收](face-differentiation.md)。它同时覆盖同剧不同角色、独立选角和跨项目新主角；同一已采用身份的后续版本保持原脸。沿用 face_design_compliance 与既有预算，不因新规则自动采用或重生旧资产。
