# 可观察的 CG 材质与灯光

本页把材质和灯光要求落实到可看见的表面、构件与光源，用于人物、场景、道具的首轮提示词与返修。风格仍按 [现有 CG/PBR 标准](style-and-quality.md)，不得借术语切换摄影写实或简化卡通。

## 材质描述写出部位和行为

| 材质 | 可用描述 | 需要避免的混淆 |
| --- | --- | --- |
| 棉布／粗织物 | 织纹随布面转向，接缝有厚度，受力折痕与衣领袖口磨白局部可读 | 每处同样锐利的假纹理、皮革式镜面高光 |
| 木材 | 木纹沿构件生长方向，榫接和边缘倒角有厚度，触碰部位适度磨光 | 所有表面覆相同贴图、为年代感全屋腐烂 |
| 抹灰／砖土 | 颗粒尺度适中，灰缝有深度，受力接触阴影成立 | 放大噪点、夸张剥落或实拍背景拼贴 |
| 裸金属／涂层金属 | 裸金属反射与粗糙度相关；涂层表面按漆、釉或搪瓷表现，露底处才出现底材 | 把白搪瓷杯整体写成镜面金属；把氧化层写成统一金属高光 |
| 玻璃／陶釉 | 杯壁厚度、透明／不透明、曲面高光与内腔分别说明 | 所有材料都透明、为了高级而让普通杯发光 |
| 皮肤／头发 | 克制皮下色层，局部粗糙度保留体积；发束分组与细丝随走向变化 | 用放大毛孔油汗做实拍人像；硬壳发型或宝石皮肤 |
| 玉石／水 | 厚薄相关的有限透光、环境反射与真实接触关系 | 未有剧情依据就自发光、额外光束或魔法效果 |

只写当前画面真的需要的几种材料，不把整个术语库堆进每条提示词。材质质量与时代材料、制造工艺和角色获取条件一起核对；“PBR”不能证明某道具在该年代存在。

## 光源与固有色分开

记录实际光源位置、方向、色温倾向、阴影软硬和反射补光。人物身份与道具设定图使用利于辨认的中性柔光；剧情空间按真实门窗、天气和已有灯具用光，不把白底三点布光复制为每间厨房的光源。

可以按场景选择：窗光加室内反射补光、阴天漫射光、已有煤油灯的局部暖光、夜晚弱环境光；选择须符合已锁定空间与剧本。未知朝向用窗在参考图中的位置说明，不虚构太阳方位。夜景保留门洞与关键物件可读，不用统一蓝滤镜重涂材质。环境变体的固定项按 [场景继承](scene-continuity.md) 保留，不新增灯具来补光。

## 示例：搪瓷掉瓷与雨夜木门

搪瓷杯局部掉瓷：素白不透明釉面保持原轮廓与柔和高光，仅指定掉瓷处露出暗灰底材；边缘有薄层高度差，底材更粗糙。不要同时把整杯写成镜面、哑光、透明玻璃和自发光。完整示例见 [道具变体](production-examples.md#同一道具的完好与掉瓷)。

木门雨夜：灰蓝漆色与木纹沿用白天版，露天门外侧湿润形成局部更清楚的环境反射；室内侧仍按真实遮蔽保持干燥。环境变暗改变明暗和高光，不增加破洞、改门框或使整间屋子淹水。

## 返修与工程限制

审核逐材质描述失败部位和可见问题；局部釉面错误优先限定材质或局部编辑，全局画风冲突先查参考与模型。保留成功结构和身份，每次写出允许改动范围；同类错误重复且无改善时保留诊断，沿用预算与重试限制，不自动追加次数。

自动总分不能覆盖脸型、道具功能、物体连接、场景继承或人物误入；逐格／逐图对照母版才可采用。图像中的材质观感不证明真实着色器、网格、骨骼或贴图通道。模型交付的 base color、normal、roughness、metallic 及实际材质连接另按 [三维工程](editable-3d.md) 检查。
