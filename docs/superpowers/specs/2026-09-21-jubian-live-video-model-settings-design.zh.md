# 剧变实时视频模型设置设计

[English](2026-09-21-jubian-live-video-model-settings-design.md) | 中文

## 目标

让分镜原生视频准备沿用剧变实时分镜已保存的模型、比例、分辨率、生成类型、生成数量和时长，并在任何付费提交前，通过当前账号模型目录验证这一完整组合。

当前验收案例是项目 2708 第 11 集：Seedance 2.5（`doubao-seedance-2-5-260628`）、FANG_ZHOU、9:16、480p、genType 3、genNum 1，以及最长 30 秒的分包。

## 范围

- 替换分镜原生准备流程中固定的 Seedance 2.0 / 720p 解析器。
- 以实时分镜保留调用方的配置意图。
- 对照实时 taskType=1 目录解析完整模型组合。
- 支持 Seedance 2.5 最长 30 秒的内容时长。
- 未验证扩展时长能力的模型保留现有限制。
- 更新分镜读取、预览验证、提交验证、schema、说明与针对性测试。
- 保留现有身份、素材顺序、项目绑定、快照核对、幂等及单次 PUT 计费保护。

不在范围内：改变图像生成、增加提供方、绕过分镜原生提交、弱化素材身份检查，或重新设计剪辑流水线。

## 配置解析

`prepare_video` 读取实时分镜 modelConfig 并提取：

- platformId
- modelId
- standardId
- genType
- modelGenerationTypeId
- videoStandardId
- ratio
- resolution
- genNum
- duration

每次准备都查询实时 taskType=1 目录。解析要求唯一模型行同时匹配 platformId 与 modelId，唯一生成类型匹配 genType，唯一视频标准匹配 ratio 与 resolution。解析器从该实时目录行刷新 standardId、modelGenerationTypeId 与 videoStandardId，不会静默改变模型、平台、比例、分辨率或 genType。

没有匹配项或存在多个语义有效匹配项时，在任何付费请求前失败并报告不支持的组合。

## 时长能力

提供方 modelConfig 中的时长仍为正整数。生成内容时长为 `duration - 1` 秒，因为最后一秒保留现有自然停顿。

- Seedance 2.5（`doubao-seedance-2-5-260628`）：内容时长 1–30 秒。
- 其他当前支持的 Seedance 模型：内容时长 1–14 秒，除非之后加入已验证的扩展能力。
- 现有直接 `generate` 路径保留 4–14 秒约定；本次改变仅适用于主体视频使用的分镜原生准备与提交流程。

能力规则由预览构建和预览验证共用一个函数，避免各层的限制不一致。

## 安全与数据流

1. 创建或保存分镜时设置 `isGenerate=0`。
2. 可以通过 `jubian_model preview/apply` 修改模型设置，同时保留提示词与素材。
3. `prepare_video` 读取实时分镜、实时主体素材和实时模型目录。
4. 验证完整模型支持、时长能力、素材身份、提示词键顺序、scriptId 与项目绑定。
5. 写入不可变预览，包含完整付费 PUT payload 与指纹。
6. `submit_video` 验证预览、重读实时状态、执行任务双快照核对，并最多发起一次付费 PUT。
7. 结果身份与任务费用按原有方式回读。

## 第 11 集生产计划

验证插件改动后：

1. 使用已编译的第 11 集六个分包作为源素材。
2. 创建六个远端分镜，正确填写 scriptName、episodeCount=11 与 episodeId=46744，不触发生成。
3. 通过 `jubian_model preview/apply` 将六个分镜全部设为 Seedance 2.5、9:16、480p、genType 3、genNum 1。保留现有分包时长，除非之后单独验证重新分包。
4. 为每个分包选择并验证有序的官方素材。
5. 准备六份分镜原生预览，并用对应指纹提交。
6. 回读任务 ID、身份字段、结果 URL 与 realCost。
7. 审查视频，按需清理字幕，对低于交付分辨率的结果按需超分，按实际音频时间制作字幕，组装整集，并渲染固定交付格式。
8. 验证最终文件为 1440×2560、60 fps、H.264，测得总码率至少 4.6 Mbps。

首轮生产保留现有六个分包，因为它们已通过导演分镜与素材门禁。基础设施改动支持 30 秒，并不构成跨场景或时间边界合并已验证分包的理由。

## 错误处理

- 不支持的模型或标准组合：在预览创建前停止。
- 目录匹配过期或歧义：停止，不替换模型。
- 时长超出模型能力：在预览创建前停止。
- 远端写入超时或结果未知：使用相同幂等键核对，不发起第二次 PUT。
- 素材身份缺失或素材顺序改变：终止为 `subject_identity_lost`，返回素材选择。
- 视频任务失败或未完成：先读取父子任务状态，再考虑受保护的重试流程。

## 测试

加入针对性测试验证：

- Seedance 2.5 / FANG_ZHOU / 9:16 / 480p 解析为实时目录 ID。
- Seedance 2.5 的 30 秒内容分包通过。
- 31 秒内容分包失败。
- 不可用的分辨率失败，不回退。
- 平台不匹配失败，不回退。
- Seedance 2.0 保留现有时长限制。
- 现有素材身份、提示词顺序、预览指纹、篡改检测与单次 PUT 提交测试继续通过。
- 工具说明不再声称 prepare_video 固定使用 Seedance 2.0 / 720p。

## 完成条件

针对性的剧变 API 与工具测试通过；第 11 集可通过受支持的模型配置路径设置为 Seedance 2.5 / 480p；六份预览全部无需绕过检查即可准备；付费提交返回保留身份的任务 ID；向用户呈现已验证的最终整集。
