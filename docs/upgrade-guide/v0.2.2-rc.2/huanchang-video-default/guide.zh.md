# Muse 桌面版多媒体制作

[English](guide.md) | 中文

## 变更

桌面版从右侧栏打开镜流。剧本、素材、分镜设置、生成任务和交付都归属于选定的镜流项目。桌面版原有的剧变制作工具与会话视频模型选择器归档。历史会话、项目文件和已经下载的媒体保留在原位置，已经提交的任务归属于原服务。

## 迁移

1. 要跟进已有的剧变任务，用原服务和原任务编号查看进度。保存希望带入镜流项目的媒体文件。
2. 将 `MUSE_JINGLIU_ORIGIN` 设为镜流 HTTPS 站点后启动 Muse。在右侧栏的「浏览器」下方打开「镜流」并登录。本地开发可使用回环 IP 地址上的 HTTP 服务。
3. 打开或新建目标镜流项目，导入需要的文件，在工作台中选择制作设置。要通过聊天操作，在 Muse 会话运行 `/jingliu-login`，完成飞书授权后回到该会话再运行一次。让 Muse 读取指定项目的剧本即可核对连接。
