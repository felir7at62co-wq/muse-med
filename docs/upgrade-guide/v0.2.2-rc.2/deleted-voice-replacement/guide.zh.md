# 替换已删除的共享声线

[English](guide.md) | 中文

## 变更

Muse 账号网关只有在独立核验项目、角色、时期及精确音频资产均匹配且资产明确已删除后，才会退役已就绪的声线登记。随后，新操作可以预留替代登记。原账号及操作 key 永久禁止再次创建，网关重启后仍然有效。已提交操作依然不会过期。

私有目录 `MUSE_VOICE_SLOTS_DIR` 除了当前槽位回执，还会保留 `retired-<hash>.json` 回执。替代登记回执及发给原操作所有者的响应增加 `replaces_asset_id`。旧版网关会拒绝这些元数据；降级需要运维审查，并且必须保留已退役记录。只删除或恢复当前回执可能重新开放已退役操作。

客户端使用替代登记许可前，要求完整清单中存在匹配的已删除槽位。删除证据缺失、矛盾或未经共享登记跟踪时，登记仍保持待处理。音频删除回读现在既认可成功的 `data:null`，也认可经过校验的已删除条目；删除字段互相矛盾时仍视为未知。

## 迁移

1. 停止网关写入进程，备份完整的私有目录 `MUSE_VOICE_SLOTS_DIR`，包含已退役回执及待处理锁。保留原本地操作账本。
2. 同时升级网关及客户端。不要清空已提交回执，不要在写入进程仍运行时移除中断锁，也不要为结果不确定的登记换 key 重试。
3. 对已明确删除、此前已就绪的声线，使用新获授权的替代操作及其独立 key 登记。旧网关不能授权替代登记，升级后的客户端还会要求已删除清单证据。资产缺失或状态不明确时，需要对账而非再次登记。
4. 确认新音频资产独立回读为活跃状态，且网关重启后原操作仍然关闭。当前回执及已退役回执必须一起备份。声线待处理仅影响该参考音频，独立制作工作可以继续。
