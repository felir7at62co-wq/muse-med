# 作用域技能调用

[English](guide.md) | 中文

## 变更

隐藏或被覆盖的 `skill` 工具不再处理显式 `/<技能名>` 消息。此前，即使会话使用另一个作用域加载器或隔离的技能注册表，该消费者仍可能注入全局指令。现在仅当前实际可见的消费者处理此手势，沿用其技能可用性与调用权限。

## 迁移

1. 检查限制或覆盖 `skill`、但仍依赖其显式调用处理器的 Profile 和预设。
2. 在目标作用域恢复可见的 `@deepseek-ai/dsh-tool-skill` 行，并在该作用域注册允许的技能提供方。使用隔离注册表时，将提供方与工具挂载到同一个 `skills` realm。
3. 启动会话并调用一个允许用户调用的技能，确认仅选定作用域的指令进入对话。未知或不可用名称保持普通文本。
