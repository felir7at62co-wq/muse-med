# 聚变原生视频预览

[English](guide.md) | 中文

## 变更

原生准备在已保存设置缺失或为 null 时补入 `backupModelList: []`，保留显式列表并拒绝其他类型。列表参与冻结请求体与指纹。缺少该字段、尚未提交的旧预览不再与当前准备结果一致。

`submit_video` 在尝试 PUT 后报告 `put_sent: true`，包括提供方拒绝或传输失败；此前发生异常时会错误地报告 false。结果新增 `put_error`，携带已去除凭据的提供方诊断或通用本地错误。两个字段都不确认任务或费用；结果不明的请求保留预约金额，原键不能重复提交。

## 迁移

1. 尚无账本记录的预览重新运行 `prepare_video`，审阅新文件并使用它自己的键。
2. 已有记录的键保留原预览，以同一键只读对账。不要只为重试结果不明的请求而换键。
3. 将 `put_error` 展示为提交诊断；回读到匹配任务后才能声称已生成。验证重放不再发送 PUT。
