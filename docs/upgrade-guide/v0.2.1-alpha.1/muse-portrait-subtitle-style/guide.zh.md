# Muse 竖屏输出使用产品字幕样式

[English](guide.md) | 中文

## 变更

打包版 Muse 的竖屏短剧输出使用随包朱雀仿宋字体和产品视觉配置。已有项目及时间线的 `subtitle`、`subtitle_visual` 和 `draft_style.subtitle` 覆盖不再决定此路径的输出样式。可编辑剪映草稿使用独立校准的编辑器默认值，不照搬 FFmpeg 字号单位。已有源文件和项目配置保留不变。横屏和方形画面保留原有样式解析规则；未启用 `enforceSubtitleVisual` 的集成保留原有覆盖行为。

显示候选会清除普通对话标点和换行，保留具有语义的数字分隔符及词内撇号、连字符。纯标点字幕会被省略并附核查信息。只有可用的实测宽度和匹配字词时间同时具备时才拆分长句，否则保留原句供核查。派生 SRT 全空时，草稿导入仍需要有效字幕输入。此策略不去除原视频中已烧录的字幕，也不作用于任意 Shell FFmpeg 命令。

## 迁移

1. 通过 Muse 标准 `drama_render` 工作流生成新预览。可编辑草稿使用返回的显示字幕候选，同时保留原 SRT。
2. 比较实际 MP4 与重新打开的剪映草稿，包含长句样本。核验字体选择、位置、字号、时序和文字可编辑性，不能仅凭已保存的配置值判断。
3. 如有另外提出的自定义字幕样式需求，在可编辑剪映草稿中调整。已有成片需重新渲染才会采用产品样式，升级不会重写它们。
