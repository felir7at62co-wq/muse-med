# 核对说话人括注中的引语

[English](guide.md) | 中文

## 变更

短剧 Core 的 `episode_coverage.py` 命令将说话人括注中的引语保留为待核对。此前，识别到表演词时可能在说话人比较中去掉整个括注，即使其中含有额外发声。已有验收记录不能覆盖当前原文检查。

已确认身份使用跨题材的成对表演括注，不要求命中动作词，支持嵌套分组和多种人物表标签。没有人物表时可由独立无括注对白确认身份，待判括注不能自证身份。单独明确的OS/VO标记保留原义，精确结构标记保留为标题行，原文与分镜保持不变。诊断区分未支持格式或备注与身份、时期、发声方式、引语和相邻说话人歧义；末尾发声引导要求紧邻同一已列角色的对白。

标记动作行也对单引号、双引号和直角引号统一检查。此前，某些引语或冒号内容可能被当作动作或说话人名称的一部分。成对引号内受支持的物件拟声，有明确声响后缀或物理撞击依据时仍可识别为动作；剩余的发声提示、引语或冒号内容须核对。此例外不适用于说话人括注引语或人物喊声。存在人物表时，显式动作行发声不能把描述文字编成新身份。矛盾的分镜发声标签不能通过，泛指画外音仍须核对。见[原文分类规则](../../../../packages/drama/skills/skills/tweet-drama-core/references/io-contract.md#episode-work-scope-and-coverage)。

## 迁移

1. 保留原文。从本次加载的 Core 目录运行 `episode_coverage.py <project> source-scan`扫描声明工作范围，再运行`source-lines <ID>`和`preflight <ID> --script <shot-script>`。
2. 对待核对括注或动作行查看整行原文及其发声、身份和发声方式含义，保留全部引语。未支持的格式须补充解析支持后重新检查；不删除括注凑格式，不以人工备注替代验收，也不提供跳过门禁的选项。
3. 分类、映射和发声核对通过后，重新签发验收并运行门禁。已授权的单集续做使用 `accept <ID> --episode-only`，再运行 `gate <ID> --episode-only`。确认 `status: passed` 后再沿既有授权进行收费制作；这些检查不会提交视频。
