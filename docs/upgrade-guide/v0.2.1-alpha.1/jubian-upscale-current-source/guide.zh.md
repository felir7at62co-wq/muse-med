# 剧变转高清选源

[English](guide.md) | 中文

## 变更

`jubian_video method=upscale` 按提供方创建时间倒序读取子结果，跳过明确未完成或失败的结果，并提交首个可用结果的当前视频地址。此前按提供方原顺序取首个有视频地址的结果，优先使用原始地址。已经去字幕的版本现在会保留为高清转换的输入。去字幕的选源规则不变。

随包高清流程在指定分集和视频包内选择最新生成结果。高清结果成功、归属匹配且有当前输出地址后直接采用；仅在另行要求时检查画面、音频和元数据。既有付费授权与幂等规则继续适用。

## 迁移

1. 新建会话或重新加载更新后的后台成片技能，使用新默认规则。
2. 保留已有任务 ID 和幂等键。复用已记录的键会返回原结果，不会对更新的视频再发起一次转换。
3. 对新授权的转换，确认源任务属于指定分集和视频包。用户明确要求旧版本时仍须精确选源；默认规则不覆盖该要求。
