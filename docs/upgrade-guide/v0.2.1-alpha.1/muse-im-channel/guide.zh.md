# Muse IM 通道设置

English | [中文](guide.md)

## 变更

Muse 使用 `@xmanrui/dsh-im` 连接即时通信平台，默认桌面 bundle 挂载此规范名称的提供方。机器人管理入口移至设置 → IM机器人。原 `feishu-channel` 配置只导入一次已启用的飞书凭证，之后由原生 IM 存储管理设置。桥接包的根入口现在明确报错，`./client` 入口不再提供，`@wenbin_wb/dsh-bridge/remote` 继续提供账号远程访问。

消息和卡片只使用原生 IM 策略，旧名单和仅主人可操作卡片的限制不再生效。已登记的主人保留原生特权。获准发送消息的成员无需命令权限，即可回答自己任务的提问，包括自定义答案；其他用户会收到明确提示。管理按钮要求命令权限。群访问不改变 Agent 工具权限或沙箱设置。

同一飞书机器人的私聊和群聊使用其 IM 设置中选择的工作区，共享文件和素材，各聊天分别保存 Session 历史。单个聊天的目录覆盖不再生效。启动时会解除已有记录中 Session 工作目录与机器人工作区不同的绑定，不移动或删除对应的 Session 日志和文件；目录匹配的绑定保留原 Session ID。无法读取 Session 元数据时会拒绝复用，并保留绑定。对话命令不能单独为某个聊天指定其他工作区。

## 迁移

1. 完成正在运行的任务，再于更新后重启 Muse。profile 准备过程会备份包清单并替换旧飞书 bundle。迁移成功前，保留原凭证 patch、Session 日志和 `feishu/accounts` 目录。
2. 打开设置 → IM机器人 → 飞书，核对机器人连接、私聊与群聊消息权限及命令权限。使用获准成员的账号，在群中精确 @ 当前机器人并确认收到回复。关闭命令权限：该成员仍能回答自己任务的提问，包括自定义答案，但不能使用管理按钮。其他成员不能代答该问题。旧名单不再覆盖保存的设置。
3. 在机器人设置中核对当前工作区，选择私聊和群聊需要共享的文件与素材所在目录。修改此选项会影响该机器人所有聊天的后续工作，不会搬迁旧文件或改写历史。
4. 从原有已授权对话发送消息。目录匹配时保留原 Session ID；原绑定指向其他工作目录时，下一条消息会在所选工作区新建独立 Session。旧私聊绑定还需要真实消息证明旧聊天 ID 与已授权发送者的对应关系。确认私聊和群聊都使用所选目录，且各自保留独立历史。其他已配置的原生机器人及设置不会被覆盖。
5. 在 IM机器人中管理连接。自定义 profile 须将桥接包根入口的插件行改为 `@xmanrui/dsh-im`；账号访问保留 `./remote`。如果导入提示主人不明确或数据无效，先修正旧配置再重试；导入器保留原文件，并维持关闭的访问权限。
