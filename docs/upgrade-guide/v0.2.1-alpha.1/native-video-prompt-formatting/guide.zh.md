# 原生视频提示词格式

[English](guide.md) | 中文

## 变更

`jubian_storyboard.prepare_video` 保留已保存任务卡提示词内部的换行和空格，只裁去首尾空白。此前准备步骤会压平空白。载荷指纹仍覆盖实际提交的完整内容。因此，升级后，由多行任务卡生成的未提交预览可能无法通过实时内容比较。

已有提交保留原有 key，并继续只读对账。账本中存在等价的压平提示词或图片在前、音频在后请求时，新准备的预览不能再次收费提交；尚未结算、远端任务暂不可见的预约也受此保护。

## 迁移

1. 保留项目 `video_tasks/` 下的已有文件和提交账本。已有提交使用原预览及 `idempotency_key` 对账；不能因提示词格式不同重新生成。
2. 未提交预览因实时内容比较被拒绝时，对同一卡片重新调用 `jubian_storyboard.prepare_video`。这是免费只读操作。核对新预览 `payload.modelConfig` 中的提示词、素材顺序和时长。
3. 在既有授权内提交核对过的预览，确认原样使用该预览的 key。旧 key 冲突会返回 `original_idempotency_key` 且不发送新 PUT；沿原 key 只读对账，不能绕开账本。
