# 选择可用的 Muse 共享模型

[English](guide.md) | 中文

## 变更

部署后的指定目录包含两个官方 DeepSeek 模型和六个云映模型，其他托管模型将被撤回。仍选择已撤回模型的会话，需先选择可用模型才能继续。个人提供方、凭据和会话历史保持不变。空白配置在登录 Muse 后默认选择官方 DeepSeek Flash，供应商 API Key 保留在网关。各模型的默认思考档位现在进入准备后的实际请求与日志，用户显式选择的受支持档位仍会保留。

## 迁移

1. 部署人员使用[指定模型配置工具](../../../../services/muse-accounts/README.zh.md)准备私密目录，并保留原文件的完整备份。候选配置与对应网关代码一起部署；只合并客户端代码不会启用共享凭据。
2. 登录 Muse，或在 MUSE 账号设置中刷新。确认共享模型选择器包含指定的官方 DeepSeek 和云映目录。
3. 如果会话仍使用已撤回模型，请在会话模型选择器中选择可用的 Muse 模型，再继续任务。使用个人凭据时可保留个人提供方默认值。
4. 通过已部署网关验证真实回答与工具续接。如果部署验证失败，请恢复保留的私密原文件备份并重启网关。
