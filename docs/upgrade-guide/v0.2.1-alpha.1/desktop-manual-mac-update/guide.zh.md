# Mac 更新安装

[English](guide.md) | 中文

## 变更

未使用 Developer ID 构建的 Mac 包获得完整的临时应用签名和封装的手动安装模式。更新器验证下载的 DMG 与内部应用，在用户确认安装并完成正常运行任务检查后打开安装包。用户在应用程序目录替换应用。Developer ID 包继续使用原生 Squirrel 的签名验证与覆盖流程。

缺少完整资源封装的 Muse 1.0.2 包无法通过现有原生更新器取得这次迁移。其校验要求绑定旧可执行文件签名，完整封装的新临时签名应用因此需要一次手动安装。详见[桌面安装行为](../../../../apps/desktop/README.zh.md#unsigned-installers)。

## 迁移

1. 从官方发布下载新的 Mac ARM DMG，安装前核对公布的校验值。
2. 完成或保存当前工作并退出 Muse。打开 DMG，在应用程序目录替换现有 Muse 应用；保留用户数据目录。
3. 打开安装后的应用并检查版本。账号网关可能独立要求重新登录。
4. 后续手动模式更新中，分别确认下载和安装。经验证的安装包打开后，按提示替换应用；下载完成本身不覆盖应用。
5. 验证失败时保留错误详情，重新下载完整的官方安装包。不要修改签名资源或关闭原生签名检查。
