# 镜头脚本发声预算

[English](guide.md) | 中文

## 变更

`drama_shot` 的发声估算由每秒九个有效字改为八个：`max(1, ceil(有效字数 / 8))`。17字台词现在估算为3秒，原来为2秒。新的预览和编译结果可能有更长的时长及不同的分包。明确时长声明和已保存包的数值保持原样；历史会话和已生成视频不变。

创作与短剧模式的系统提示词在编写短剧镜头脚本时建议每镜1–4秒、无声反应镜更快；多人入画前须核验站位参考图。拍摄时间放在预算元数据与生成参数中，不进入提交的视频提示词；原台词里的时间信息保持不变。估算不证明成片的实际时长。

## 迁移

1. 对准备新生成的脚本运行 `drama_shot preview`，保留原台词和已确认资产，按系统制作要求复核语义拆镜。
2. 重新编译受影响的本地包。各包返回的 `prompt` 写入 `modelConfig.prompt`，对应的 `submit_seconds` 与 `content_duration_ms` 写入生成设置。修改已保存分镜前先对账已提交任务。
3. 准备视频前回读保存的提示词和时长。检查生成视频的实际切点与人物身份，不能把新估算当作成片已经通过验收。
