# 群聊生成结果回传

[English](guide.md) | 中文

## 变更

旧构建在团队回传记录缺失时，可能仅依据 `jubian-generation-watch` 消息中的 `groupOrigin` 回传结果。现在团队仅按独立保存的回传记录路由。新建记录需要在执行 Bot 的 Session 历史中核对原始 `bot` / `room` 分工。同一回执不能更换原参与人。

普通通知及其元数据仍可读取。已有回传记录在重启后继续发给同一委派人。缺少可核实分工的通知保留在执行者会话中，并明确报告自动群聊回传待复核。

## 迁移

1. 迁移安装时，同时保留当前 Muse home 下的 Session 目录和 `muse-bot/state.json`。不要编辑通知元数据来重造回传记录或改发结果。
2. 接续原宿主生成监看任务。执行者原始持久化分工与当前群聊 Session 一致时，可重建缺失的回传记录。
3. 原始分工不可用时，在执行者会话中读取结果，人工核对项目与委派人后交回。不要仅为恢复通知而重新提交收费生成。
4. 确认原委派人只收到一次接续，或缺少证据的告警仍明确可见。无需转换 Session 格式；[持久化确认记录](../../../persistence-changes/2026-11-06-generation-watch-attribution.zh.md)记录了同版本新增。
