# 编辑模式工具与指导

[English](guide.md) | 中文

## 变更

编辑身份句为 `你是muse-med编辑智能体，由{{model}}驱动`。Harness 通用系统段、工作目录、运行时上下文快照和匹配技能先加载指导继续可用。预设自身不挂载子代理、Team、工作流代理或 `screenplay_project` 工具；继承工具与后续注册保留注册表的通常可见性及指导。当前 Agent 自主检查并交付普通稿件；编辑技能仅在当前模式实际提供受管项目工具时要求受管审批。其他预设与已有项目验收记录保留各自策略。剧本、大纲等文字稿件默认交付检查后的 Word（`.docx`），Markdown 保留为可编辑源稿。用户明确指定的格式优先；分场剧本沿用已有导出工具转换，不重新转写或重写正文。转写完成不自动将剧本写入知识库，Muse 按任务、用户要求、授权范围和复用价值自主决定；入库及知识页合成不作为本地交付条件。决定写入时仍须读回核验并准确报告状态。

## 迁移

1. 在更新后的应用中开启新的编辑对话。已有对话可能仍包含已加载的委派、受管项目或默认入库指令。
2. 保留已有受管项目及验收记录。自主修订另存为旧项目目录之外的新项目，不沿用旧受管 `final/` 或导出参数。需要继续受管验收时，使用提供该能力的预设。
3. 检查导出的请求：应包含 Muse 身份和 Harness 通用指导，且没有本预设自身挂载的委派或受管项目工具。父级组合或扩展贡献的工具仍按注册表通常规则可用。确认文件、媒体、技能和文档工具仍可用。
