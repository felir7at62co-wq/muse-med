# 编辑模式单句身份提示词

[English](guide.md) | 中文

## 变更

`editing` 预设的完整系统提示词为 `你是muse-med编辑智能体，由{{model}}驱动`，请求时替换为当前选择的模型 ID。预设不再以系统文本自动提供流程、参与登记、知识库、工作区或通用工具指令，并关闭动态运行时上下文快照。工具目录、技能发现和 DSH 的匹配技能加载指导仍然可用。受管工具校验与已有项目的验收要求继续生效。

## 迁移

1. 在更新后的应用中开启新的编辑对话；已有对话历史仍可能包含之前加载的技能和指令。
2. 明确提出需要的流程或附加要求，或让智能体选择匹配技能。个人预设覆盖如需附加系统文本，须先关闭 `persona.config.complete` 再添加系统段。
3. 检查新对话导出的 `system/message`，其中应只有替换了当前模型 ID 的身份句。确认工具与技能目录仍可用。
