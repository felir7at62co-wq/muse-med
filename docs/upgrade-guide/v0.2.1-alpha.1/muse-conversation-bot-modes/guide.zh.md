# 分开会话与 Bot 模式

[English](guide.md) | 中文

## 变更

Muse 默认使用 `autoSessionBots: false`。打开 Bot 模式不再将普通会话或分支自动登记进团队名册。侧边栏底部与 MUSE 账号同行的入口用于切换会话与 Bot，并分别保留最后选择。

已有 Bot（包括旧版自动登记的条目）保留身份、会话和记忆。会话日志、记忆文件及默认模型不做迁移或删除。为保持兼容，Bot 的底层会话仍可从原生历史访问。

## 迁移

1. 普通交互使用会话模式，长期团队成员使用 Bot 模式。采用 Muse 内置配置的用户无需手动迁移数据。
2. 需要把会话变为 Bot 时，使用设置 → Bots → 使用已有会话；登记后保留原有历史。
3. 自定义部署如需保留自动登记，可在自己的 `ds-bot` 条目显式设置 `autoSessionBots: true`；Muse 内置桌面配置要求使用 `false`。
4. 确认新建普通会话不会增加 Bot 名册条目，且切换模式及重启后已有 Bot 和记忆仍可访问。
