# 参考音频总时长

[English](guide.md) | 中文

## 变更

过去分别检查每段参考音频是否不超过十五秒，现在整个参考音频组的已知时长之和必须不超过十五秒。此规则影响音频绑定、保留音频的图像选用和原生视频准备。既有文件不改写；未知时长仍未核，缺失值不能当作零秒。

## 迁移

1. 测量每段已选参考，保留实际 audioDuration。
2. 每角色截取实际讲话约两秒，可保留背景声，不将整段长混合音轨上传为声线。
3. 总时长控制在十五秒以内；缩短样本或选用本包实际需要的参考。保留原分镜和收费操作 ID。
4. 用现有音频预览及回读验证。超限组必须在绑定 PUT 或视频提交前被拒绝；缺少测量时不能声称时长已核。
