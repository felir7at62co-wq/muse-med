# Muse 内容与字体验收

[English](guide.md) | 中文

## 变更

短剧交付不再把技术渲染检查、ASR文字一致或调用方写下的通过声明当作完整内容验收。要求源片审查的项目还需当前源片及成片的实际观察，覆盖物理逻辑和连续性，并验证当前输出的试听回答。普通工作渲染仍可使用；证据不足时交付保持待验，不自动弹出用户问题。

草稿请求字体不再静默退回编辑器系统字体。草稿后端保留请求身份并验证保存的字体引用。资源缺失或绑定能力不支持时保留待修候选，不报告已成功交付所请求字体。产品的 `fontsDir` 与 `subtitleFontFamily` 传递内置字体，无需在系统中安装。

## 迁移

1. 续做旧制作会话时重新读取当前草稿及渲染技能。保留原素材与已付费任务身份；这些变更不要求重新生成视频。
2. 使用当前原生工具与所选字体重新生成受影响的可编辑草稿。检查返回的候选和字体状态，不通过编辑状态把已保存待修候选改成交付成功。
3. 按[内容审查要求](../../../../packages/drama/tool-episode-render/README.zh.md)完成实际源片和成片观察，同时检查生成包内部切点与包间接缝，保留物理、发声内容和连续性方面的未决问题。
4. 试听回答只适用于其精确输出摘要和完整时长。ASR吻合与模型自行填写的试听声明不能替代它。当前流程无法建立实际试听证据时，该集保持待验，继续处理独立工作。
5. 媒体修复并复验后再次运行 `stage_delivery`。素材、字幕、字体资源或审查记录变化会使相应旧证据失效。归档会保留绑定摘要的原始草稿，用于复核初次字体。后续在剪映里编辑草稿，不会使未变化且已验收的 MP4 失效；修改稿标为 `modified_unverified`，原始字体证据不认证修改后的草稿。原生编辑器兼容性和创作质量仍与文件创建分开验证。
