# Muse 会话入口

[English](guide.md) | 中文

## 变更

Muse 不再展示预设选择器。即使此前保存过用户默认预设，新建普通会话仍使用短剧预设。固定主会话在启动时或通过 Muse 入口打开，不再出现在工作区会话列表中。主会话历史和已有普通会话仍然保留。任务浮层和侧栏任务徽章不再展示，完成回报通过主会话消息返回。

## 迁移

1. 打开 Muse 查看保留的主会话和此前对话。从其他对话返回时，点击“新会话”下方的 Muse 入口。
2. 使用“新会话”开始短剧工作，并像以前一样从工作区打开已有普通会话。已保存的历史会话预设不变。
3. 自定义 profile 如需沿用先前的用户默认选择行为，检查其 `agent-preset-registry` 配置，仅在需要时设置 `allowUserDefault: true`。
