# 公司媒体保留期账本

[English](guide.md) | 中文

## 变更

公司媒体网关将私有 SQLite 账本从 schema 1 升级为 2，保留任务并新增传输占用、导入确认、删除隔离标记和审计记录。schema 1 网关拒绝升级后的数据库。桌面 Session 日志和账号存储不变。

## 迁移

1. 替换网关前，使用 SQLite backup API 备份媒体账本。保持账号服务运行，受理新的媒体请求后保留当前账本。
2. 部署新网关，先不启用保留期循环，核对就绪状态报告 `schema_version: 2`，再按照[保留期流程](../../../../services/muse-media/gateway/README.zh.md)关闭独立上游清理并开始预演观察。
3. 使用最终策略和运行代码连续预演 24 小时后才批准。观察缺失、失败或中断时继续禁用删除。旧客户端按七天保护，更新后的客户端只在本地验证后确认导入。
4. 恢复时使用新网关，关闭保留期循环或设为预演。不能用旧网关打开 schema 2，也不能用旧账本覆盖新受理的请求。删除结果未知时保持隔离，直到核对完成。
