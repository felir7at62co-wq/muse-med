# 使用聊天视频卡片与会话菜单

[English](guide.md) | 中文

## 变更

Muse 移除悬浮视频气泡及其浮层播放器。聊天视频卡片保留视频选择、播放、镜头轨道、缩放和修改草稿。普通会话顶栏新增会话视频菜单；选中已记录来源后，在 Chat 顶部展示同款视频卡片，也支持原消息尚未加载的视频。通用设置项改名为视频卡片与轨道，沿用已有的 `ui-session-video.enabled` 值。

## 迁移

1. 直接使用已交付或已生成视频卡片上的控件。
2. 查找已记录视频时，打开顶栏的会话视频菜单并选择名称，查看完成后关闭历史视频卡片。
3. 在设置 → 通用 → 视频卡片与轨道中启用或停用增强界面。确认停用后恢复原生已交付视频播放，再次启用后恢复卡片与菜单，且不再显示悬浮气泡。无需迁移会话、草稿、媒体文件或配置键。
