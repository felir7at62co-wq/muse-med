# 原生视频完整提示词

[English](guide.md) | 中文

## 变更

原生视频准备保留完整已存 `modelConfig.prompt`，包括首尾空白和 CRLF 换行。此前准备会裁去首尾空白。含这些空白的卡片现在产生不同的冻结载荷和指纹，因此使用裁边文本准备的未提交预览可能过期。

已记录的裁边、压平或图片后音频分组 key 仍用于只读对账。命中旧 key 时，不新增预约或付费 PUT，即使原预览文件或远端任务缺失。返回的 `outcome` 属于旧 key，不代表本次精确格式请求已生成视频。预览和预算文件不提供提交授权。

## 迁移

1. 保留 `video_tasks` 中的全部原预览与提交 key，不改写 Session 日志或账本记录。
2. 对未提交且没有费用意图记录的预览，回读当前卡片并重新调用 `prepare_video`。确认新预览的 `payload.modelConfig` 包含完整已存提示词，之后仅按用户最新请求继续。
3. 如果某 key 已有 accepted、unknown 或待定账本记录，保留原预览并以原 key 只读对账。新预览返回 `original_idempotency_key` 时，对账该旧 key；本次结果不发送付费 PUT，也不认领新任务。
4. 原预览缺失时，从保留副本恢复，或调查既有收据与远端任务。文件或任务缺失不授权换 key 或再次收费。只预览请求到展示结果结束。
