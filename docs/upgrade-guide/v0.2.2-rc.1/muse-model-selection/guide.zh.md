# Muse 在请求组装前修复模型选择

[English](guide.md) | 中文

## 变更

此前，个人提供方缺少凭据时，Muse 在准备请求期间把已保存的直连提供方替换为同一模型的 Muse 路由。现在，账号目录刷新成功后或 Agent 创建期间，Muse 会在首次请求之前记录这项替换。已经捕获模型选择的请求保留原路由及其正常凭据错误。

修复会保留较新的提供方、模型或推理选择，也会保留已配置凭据的个人提供方，以及 Muse 目录中没有的模型或显式推理档位。省略推理等级时继续采用适配器默认值。此行为不需要手动修改 Session 文件。

## 迁移

1. 继续已有对话前，通过**设置 → MUSE 账号**登录并刷新账号模型目录。
2. 如果对话仍选择未配置凭据的个人提供方，请在对话模型选择器中显式选择对应的 **Muse** 模型，或在**设置 → 模型**中配置个人提供方凭据。
3. 重试前确认选择器显示目标提供方和模型。已经组装的请求可能仍因原凭据错误而结束；后续步骤使用已记录的选择。已有请求不会被静默改到另一提供方重新执行。
