# 编辑与项目历史

[English](edit-migration.md) | 中文

配套平台通过原子版本比较保护原生项目、分集、角色、场景、道具、分镜、媒体及复用素材库的普通编辑。独立工作台不连接供应商项目，也不迁移其数据。

## 编辑与冲突

原生 GET 响应保留原字段，并为每条可编辑记录添加 `muse_edit`：数据库身份、实体类型、原生 ID 和快照 SHA256。更新、删除和分镜关系保存必须提供该原版本及稳定 `x-muse-operation-id`；原生工具调用提供 `expected_database_id`、`expected_snapshot` 和 `operation_id`。版本比较、原生写入及不可变回执位于同一 SQLite 事务。相关记录变化会使批量替换和分镜关系编辑失效。原生响应拒绝或回执失败会回滚写入。

HTTP 409 表示原编辑版本已过期。浏览器在后台读取后仍保留最初版本和未保存输入，展示当前字段与本地字段，供用户明确合并。取消会保留本地修改；确认合并会使用新检查的版本及新操作身份。重复原操作会返回原回执，不覆盖后续编辑。网络结果未知不能作为更换操作身份的理由。

保护覆盖已声明的原生路由，不覆盖任意 SQL、文件系统修改或未注册的扩展路由。版本恢复仍是独立操作，有自己的内容字段限制。私有 `muse_edit` 配置限制快照字节数、关联记录数和回执字节数，默认分别为 8388608、10000、8388608；无效限制在写入前失败。

## 项目归档

在工作台导出和恢复原生项目。归档包含项目内容及其保留的媒体。做部署备份时，应一并保留数据库、媒体和操作回执。查看历史版本不会改写当前提示词，也不会调用生成服务。
