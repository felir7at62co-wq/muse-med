# 完整整集合成

[English](episode-merge.md) | 中文

一集由多个独立生成、按顺序排列的分镜包组成。模型单次生成的时长上限不限制整集时长。`planEpisodeMerge` 移除固定的 100 段上限，本地 FFmpeg concat 清单在配置的资源范围内接受全部已选视频包。

## 完成与恢复

合成必须按分镜顺序完整包含当前全部分镜，每个出现一次，并使用已采用且保存到本地的视频。缺片、选源变化、文件不可读或编码、画面、音轨、时间参数不兼容时明确失败。本实现不静默归一化不兼容来源，也不以第一段代替整集。

FFprobe 实测每段的帧数与时长。输出必须包含相加后的全部视频帧，时长误差须在配置容差内，并由 FFmpeg 完整解码视频和音频。任务验证记录每个分镜、来源 SHA256、帧数、时长及输出 SHA256，不把卡片时长当作媒体实测值。这些核查确认技术合成完整，画面连续性、对白及最终交付仍需审查。

未请求后期选项时，视频流复制，所选片段原有的音频对齐合成时钟并编码为 AAC，不丢弃声音，原文件不变。明确启用对白／旁白选项时只使用已采用的音频文件，不调用 TTS 供应商。缺少必需音频、语音长于片段、没有请求的旁白文本、字体资源无效，或字幕、水印、混音处理失败时，合成保持失败。只有对应语音文本为空的槽位才能补静音；整集没有已采用对白音频却请求对白时失败。请求的音频会替换合成音轨，不自动与原声音叠混。

只有完全验证的结果才更新整集。处理中若分镜清单、已采用视频或整集输出发生变化，拒绝过期发布。失败保留原生成来源，并在原任务的 `recoverable_candidate_url` 保存已经验证的原始合成候选；该候选不会采用为最终成片。修复来源或选项后再请求免费重新合成，不重新提交图片、视频或语音生成。

每次尝试使用私有临时目录和 UUID 输出名；成功或失败后清理临时文件。在存储文件系统中通过排他硬链接发布，不覆盖已有输出，原始与后期验证文件继续保留以供检查。

## 部署限制

在配套后台的私有配置 `muse_merge` 节设置下列可选字段。它们限制资源，不限制分包数量或模型生成时长。

| 字段 | 默认值 | 接受值 |
|---|---|---|
| `timeout_ms` | 900000 | 整数，1000–3600000；验证、合成与后期处理的总期限 |
| `max_input_bytes` | 2147483648 | 不小于 1024 的整数；全部选源字节之和 |
| `max_output_bytes` | 2147483648 | 不小于 1024 的整数；已验证输出上限 |
| `duration_tolerance_ms` | 250 | 整数，1–5000 |
| `max_process_bytes` | 2097152 | 整数，1024–16777216；子进程诊断输出总量 |
| `font_file` | 自动系统字体 | 管理员选定的可选 TrueType/OpenType 水印字体文件 |

需要 FFmpeg、FFprobe 及存储硬链接支持。子进程异步运行，只接受本地文件协议，超时终止后仍等待退出。磁盘上限属于准入／输出核查，不是操作系统硬配额。不同格式的来源须先明确归一化，才能进入本合成路径。

## 验证

安装固定版本的后端依赖和 FFmpeg／FFprobe 后，运行 `node --test integrations/localminidrama/tests/episode-merge.test.mjs`。夹具使用真实 SQLite、本机生成的视频／音频及 103 包的一集，解码每个有序视频帧、核对实测时长，并验证缺失／损坏／不兼容来源、请求的后期失败、并发选源变化及保留的不同输出，不调用供应商或付费 API。
