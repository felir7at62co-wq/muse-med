# Muse 生成提交

[English](admission.md) | 中文

## 概要

原生制作请求在重试、页面刷新和重新登录后保留同一提交标识。**生成提交记录**可以读取原回执和任务引用，不会再次生成。HTTP 响应失败不代表供应商没有收费。创建另一个版本需要明确授权，并引用先前已结束的操作。

## 提交与核对

每个受保护的原生请求都需要 `x-muse-operation-id`。服务器先提交占位记录，再执行原处理器。指纹包含归一化的方法和路径、排序后的输入及上传文件 SHA，不包含操作标识和凭据键。日志保存指纹、接口与结果回执，不保存原请求正文。图片及视频回执保留原记录引用，不复制提示词或临时媒体地址。

相同标识和输入会读取原回执，同一标识携带不同输入会失败。即使使用新 UUID，相同指纹已有操作时也会失败，包括处理中和未知结果；清除浏览器存储或重新登录不能绕过检查。浏览器选择标识前会核对服务器指纹。缓存持久化失败会停止提交。

JSON 成功回执先持久保存，再返回成功。生成中可以显示流式增量，但完整回执提交前不会发出 `done`。回执过大或保存失败会标为未知结果，不会把截断结果当成成功。连接断开后保留原活跃处理器，原结果完成后仍可记录。进程重启时未完成的占位操作转为未知，不会自动重新派发。

重试前先读取原操作。界面仅在原生操作已结束后允许另一个版本。此许可只预留已授权标识，不调用供应商；用户需要返回原生成按钮主动提交。失败的原生任务也可能已经收费。未知结果不能获得此许可。原生任务记录缺失或已删除时仍视为未确认。

## 覆盖范围与供应商用量

导出的[原生接口目录](compatibility/muse-admission.mjs)涵盖图片、视频、角色和场景及道具生成与描述提取、故事、分集分镜、帧提示词、提示词润色和小说 AI 改写。仅规则的小说导入不要求生成占位。旧的付费 `GET /storyboards/episode/:id/generate` 返回 405；调用方需改用受保护的 `POST /episodes/:id/storyboards`。本地编辑、本地图片放大、轮询、下载及采用不属于付费提交。

独立 TTS 和 Fal 后期处理保留各自的持久操作服务，不重复包裹。此服务不涵盖原生制作目录以外的供应商请求，包括配置探测或素材服务注册。它不修改上游客户端的内部供应商重试策略，也不能保证供应商自身会去重请求。

原生文本客户端会按供应商调用保留实际 JSON/SSE 用量回报。同一次调用后续的用量块覆盖先前快照，不把累计块重复相加。缺少的 Token 字段保持 `null`；真实回报的零仍是零。批量中的多次调用分别保留，部分回报不当成完整计费。其他未接入观测的协议保持未回报，不估算费用。用量写入失败会显示观测异常提示，不伪造零用量。

`recordResourceUsage(db, kind, id, payload, providerTaskId)` 将实际图片或视频轮询回报记到其原生资源的原提交名下，即使重启或手动轮询没有请求上下文也能记录。每个资源保留一份累计快照；后续仅引用该资源的操作不会重复领取用量。仅接受非负安全整数 Token 值。记录失败会标记用量异常并返回 `false`，不因记录失败丢弃已经付费的媒体结果。

## 集成与持久化

`planMuseAdmission(root, readSource)` 在前缀、声音、编辑记录及后期处理 planner 之后运行。它读取待应用源码，在原生处理器前安装检查，并拒绝重复应用或源码锚点变化。通过 SQLite 触发器和请求异步上下文关联原生生成资源，包括没有立即返回资源 ID 的批量后续任务。每个执行写入的连接都必须注册此服务的 SQLite 函数。

所属表使用单调递增的 `muse_admission_schema` 第 1 版和完整 SQL，不修改上游迁移文件。`muse_admission.max_receipt_bytes` 默认为 2,097,152，接受 1,024 至 16,777,216 的整数。worker 使用 `getActiveOperationCount(db)` 在 HTTP 连接断开后保留原请求；历史未知记录不会让空闲 worker 永远常驻。请同时备份数据库和媒体存储。

HTTP 路径以前缀 `/api/v1/muse/admission` 开始：`GET /capabilities` 返回数据库身份与接口目录；`GET /lookup?request_sha256=…` 查找原操作；`GET /` 列出近期操作；`GET /:id` 读取原回执；`POST /:id/next-version` 接收稳定的新 `{operation_id}`。许可引用先前标识，拒绝未知或活跃操作，也拒绝并发竞争的新许可。此服务不在浏览器保存供应商凭据。

## 验证

运行 `node --test integrations/localminidrama/tests/muse-admission.test.mjs`。测试使用独立真实 SQLite 数据库、原生视频路由代码、回环供应商、真实 JSON/SSE 解析器、HTTP 断线以及实际浏览器缓存模块，检查占位、跨 UUID 去重、批量资源关联、明确许可、存储失败、回执大小限制、流完成及实际回报用量。不使用供应商密钥或付费生成，也不验证供应商权限。[预期失败输出](tests/expected/muse-admission.json)保留在所属目录。
