# Skill 拒绝与产品反馈独立处理

[English](README.md) | 中文

本无密钥 SDK 场景通过随产品提供的配置运行文件任务，并创建两个没有工具权限的原生复盘会话。两次复盘均返回无效的 Skill 名称和独立有效的产品反馈。插件记录 Skill 校验失败，不创建提案、版本或技能文件。生产账号客户端向夹具拥有的本地回环意见箱发送一次认证请求，保存收据，并抑制重复候选。

夹具通过原生权限命令等待复盘空闲。夹具工具调用生产状态处理器，检查其校验失败和反馈状态，并根据日志中实际的复盘输入核对审计哈希，再向模型返回稳定的观测结果。普通反馈管理工具也会展示保留的收据和重复结果。完整工作区保留任务文件和一份证据摘要。本场景不修改归一化规则或历史会话夹具。

专用回放服务商不会回退到真实模型。模型后端和中央意见箱使用本地夹具；复盘持久化、Skill 校验、账号传输和反馈保留使用生产代码。`MUSE_SKILL_EVOLUTION_PACKAGE` 可选择解包后的插件归档进行打包检查。意见箱收据只确认收到反馈，不代表已有 PR、修复合并或版本发布。
