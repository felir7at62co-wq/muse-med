# 原生 Skill 学习与产品反馈

[English](README.md) | 中文

本无密钥 SDK 场景让内置配置持续运行，已完成的文件任务触发无工具的原生复盘会话。第一次复盘创建自有 Skill，并通过正式 Muse 账号服务向私有本机意见箱发送一条有长度限制的产品建议。第二次已完成任务提出相同产品反馈，已保存的本地候选阻止再次发送 POST。后续普通回合发现并加载生成的 Skill。

夹具封装现有原生 `/permission workspace-write` 命令，在回合之间等待空闲复盘结束。该同步点不会创建提案、Skill 或反馈记录。独立断言检查真实 Skill 字节、已认证的意见箱请求和匹配回执、两个无工具的原生复盘会话、来源模型路由，以及没有复制会话摘录或凭据。完整最终工作区包含任务文件、Skill 和有长度限制的证据摘要。意见箱保存回执不代表已创建 PR、修复或发布。

专用 `snapshot-skill-feedback` 模型提供方没有真实 API 回退。仅模型后端和中心意见箱由本地实现替换；账号传输、本地候选持久化和 Skill 发现沿用正式代码。可用 `MUSE_SKILL_EVOLUTION_PACKAGE` 指定已构建并解包的插件，验证其打包入口。导入根据实际 SDK 启动方式选择源码或已构建的依赖，不在两者之间回退。
