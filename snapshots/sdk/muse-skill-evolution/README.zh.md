# 原生 Session 的 Skill 学习

[English](README.md) | 中文

这个无需密钥的 SDK 场景让正式配置的进程在两轮对话之间保持运行。纯聊天轮次不会触发复盘。普通根会话写入并重新读取真实文件后，后台根据已完成工作的证据，在相同模型路由上创建持久化且无工具权限的原生复盘 Session。复盘返回的 JSON 提案创建真实的插件所有 Skill，下一轮普通根会话通过原生 `skill` 工具发现并加载它。

在两轮之间，测试包装现有的原生 `/permission workspace-write` 处理器，先等待插件已有的后台队列，再执行原本的权限命令。这个原生命令仅作为不调用模型的同步等待点。等待不会创建复盘、提案或 Skill。隔离工作区包含实际生成的 `SKILL.md`、已验证的任务文件和独立证据摘要。只替换模型后端；请求头、复盘输入、响应、目录发布和工具结果仍记录为原生 Session 数据。专用的 `snapshot-evolution` 提供方没有真实 API 回退路径，回放加载失败时不会向外部发送模型请求。

默认测试导入插件源码。将 `MUSE_SKILL_EVOLUTION_PACKAGE` 设为已经构建并解包的插件目录，可以通过相同 SDK 配置验证该产物导出的 `src/index.js`，测试期间不执行编译。测试将包复制到私有 home，并从与 Host 相同的工作区解析依赖：TSX 启动时使用源码，普通 Node 启动时使用已构建的导出，不安装软件源中的依赖。
