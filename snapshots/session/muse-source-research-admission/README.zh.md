# 保留来源指标与项目容量

[English](README.md) | 中文

这个无密钥 Headless 场景使用正式的来源研究工具、真实红果客户端和本地文件系统读取合成公开页面。非空但无法解析的指标在不可覆盖的快照保存并经过 `read` 后，仍保留完整原文、null 数值和来源的 `unparseable` 原因。夹具在下一次模型请求前核对实际文件字节与回执。

两个子 Agent 使用独立工具作用域和相同项目目录。受控传输屏障让两个客户端都在发布前进入采集。设置 `maxSnapshots: 1` 时，只允许一个作用域请求成功，另一个报告已达到配置的容量上限；之后两个作用域都能列出并读取唯一保存的快照。完整最终工作区使用独立构造的预期结果。取消、释放、其他产物类别和历史适配版本的读取由单元测试覆盖。

原生回放提供方从选定的父子规范 Session 读取全部助手回复。夹具仅替换精确公开页面传输和时钟，不生成模型回复或伪造研究结果。私有安装包副本用于原始代码的负向验证。不联系真实网站、账户、付费模型、ASR 或生成服务。这些检查覆盖同一 Host 内的发布准入，不代表跨进程协调或原生界面验收。
