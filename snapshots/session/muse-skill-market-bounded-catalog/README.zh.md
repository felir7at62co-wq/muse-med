# 市场 Skill 摘要与完整目录

[English](README.md) | 中文

已发布的 Headless 配置挂载实际不可变市场发行包和 Session 激活服务。公开配置从三个保留市场发行包中选择两条摘要，同时完整保留三个未配置来源的对照项。目录将所选摘要与发现完整性分别记录，元数据目录仍由同一个活跃加载器提供。

实际元数据查询遍历所有可用项、找到未展示的名称，并排除私有正文和禁止模型调用的对照项。随后加载该 Skill 会返回所选发行包的完整指令。每个完整实际结果都与下一次模型请求观察到的已记录 Tool 结果相等。Native 工具调用使用上一页实际返回的 nextCursor。外部会话、过期和无效的续页输入由普通工具管线拒绝，正文加载权限保持不变。

独立工作区凭据记录目录成员、完整元数据页、保留发行包绑定、正文加载和被拒绝的禁止模型调用。不会发起外部供应商请求或运行付费生成。
