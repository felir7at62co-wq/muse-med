# Bounded market Skill catalog

English | [中文](README.zh.md)

The shipped Headless profile mounts actual immutable market publications and Session activation. A public configuration selects two of three retained market publications while keeping three unconfigured-source controls visible. The resulting catalog records selected summaries independently of discovery completeness. The metadata-only directory remains available through the same active loader.

Actual metadata queries visit the full eligible directory, find an omitted name, and exclude private instruction text and a model-disabled control. A subsequent Skill load returns the omitted publication’s complete instructions. Every complete actual result equals the logged Tool result observed by the next model request. Native tool calls consume the actual nextCursor returned by the preceding page. Foreign, stale and malformed continuations are refused through the ordinary tool pipeline; instruction-loading permissions stay unchanged.

The independent workspace receipt records catalog membership, complete metadata pages, retained release bindings, body loading and the refused model-disabled load. No external provider request or paid generation runs.
