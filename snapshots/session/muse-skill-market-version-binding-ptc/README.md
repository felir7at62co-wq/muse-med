# Skill release selection through PTC

English | [中文](README.zh.md)

The shipped Headless PTC profile runs the [Native lifecycle](../muse-skill-market-version-binding/README.md) through actual tools.skill and tools.market_version dispatches. Each program prints the full actual typed result. The primary Session loads version one before and after the default changes to version two. A previously blank Session and a fresh Session each load version two on their first task.

All three real Agents expose their complete Skill results to a subsequent model request. Required binding events, projections, archive identities and selected resource bytes are checked independently of program prose. The primary also receives each complete lifecycle result, including default changes and child binding observations. The workspace proof records the same exact version decisions as the Native case.
