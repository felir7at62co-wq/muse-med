# 英文编辑意图与已核实回执

[English](README.md) | 中文

本无密钥 Headless 场景以“Edit the screenplay and give me a Word file.”开始。未登记的 `present` 须返回 `MANUSCRIPT_DELIVERY_REQUIRED`。后续仅用文字声称文件已完成时，会收到已记录的缺少回执提醒。写作者随后实际写入并回读文件，通过原生审校对照不同路径的原稿与候选，登记已复核交付，并使用返回标签交付。

夹具核对子审校收到的完整真人要求、一次恢复提醒、一次成功交付、文件字节及完整交付账本。候选采用 Markdown，并明确说明这一限制。本场景验证编辑意图、对照与回执行为，不声称已完成 Word 导出或创作验收。

生产稿件和交付服务通过随产品提供的 Headless 配置运行。模型服务商回放编写的响应，不会回退到真实模型。仅供夹具使用的构建库覆盖项允许通过隔离副本执行有界回归对照，不修改交付库或历史夹具。
