# Offscreen roster advice

English | [中文](README.zh.md)

The ordinary Loader and shipped Headless profile invoke the production `drama_shot` tool once in advisory compile mode. One explicitly offscreen subject on the visible roster produces `offscreen_character_listed`; visible inner speech and partial visibility do not. The complete actual report reaches the next model request. Assertions preserve source and manifest bytes, authored rosters, voice types, dialogue, position text and the single referenced character identity; they also compare the saved advisory source and report. The independent workspace proof records these observations. Recorded model decisions are controlled inputs, and no generation or media review occurs.

The [PTC sibling](../muse-shot-offscreen-roster-ptc/README.md) exercises the same assertions through `tools.drama_shot` and prints the complete report.
