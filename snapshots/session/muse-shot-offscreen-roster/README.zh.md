# 画外名单建议

[English](README.md) | 中文

普通 Loader 和随包 Headless profile 在 advisory 编译模式下调用一次生产 `drama_shot` 工具。出镜名单中的一个主体明确位于画外，产生 `offscreen_character_listed`；可见人物的内心声音和局部可见不产生该提示。完整实际报告进入下一次模型请求。断言保留源文件与清单字节、原始出镜名单、发声方式、台词、位置文字和单一引用人物身份，并比较保存的检查源稿与报告。独立工作区凭据记录这些观察事实。记录的模型决策是受控输入，不执行生成或媒体审查。

[PTC 相邻场景](../muse-shot-offscreen-roster-ptc/README.zh.md) 通过 `tools.drama_shot` 执行相同断言，并打印完整报告。
