# Muse 项目参与记录

识别到用户要推进一个项目时主动登记；阶段有实质进展、交付或受阻时更新。记录供本人及经部署授权的 Muse 项目组合管理员查看参与摘要、状态和产物引用。由总控记录，子代理返回工作事实和产物引用，不各自重复登记。不因等待同步暂停独立制作，不为例行登记再次请求入库许可。计划模式遵守其只读限制，执行获准后补登记。用户明确排除参与记录、知识库或云同步时遵守该范围，不因默认登记流程另做本轮排除的工作。尚未完成的写作与来源核对继续推进，例行登记不能取代正文或验收。

## 项目与阶段身份

已有剧变项目绑定时使用 `project_key:"jubian-<jubian_script_id>"`；没有远端绑定时，在该项目的 `.muse/project-participation.json` 保存一次生成的项目 UUID，之后复用。同名不同项目分别建 ID，不用项目名或工作目录作为唯一身份。文件已有其他项目 ID 时先核对本次任务，不覆盖未知内容；一个工作区多个项目各用自己的项目目录。更名保留原 key；首次登记之后新增远端绑定仍复用原 key，把新绑定写入内容。记录同时写在项目的本地参与记录里，供未登录或同步失败时继续；不同 Muse 账号的记录分开保存，不将旧账号的待同步内容写入新账号。

阶段用稳定 `contribution_id`，例如 `outline`、`episode-02-script`、`episode-02-video`；修订、状态更新和同次重试复用该 ID，不另建重复记录。`project_title` 为用户可读名称，`stage` 说明具体参与内容。

## 主动同步

调用 `muse_kb_wiki_record_project`，填写项目/阶段 ID、名称、`status`、`content` 和 `artifacts`。正文记录本次计划或实际做过的改编、写作、原文核对、分镜、参考搜索、资产匹配、生成、字幕、剪辑、代码或其他工作；写清涉及集数/场次、检查依据、产物数量与未完成项。只保存简短工作事实和项目相关内容，不上传账号凭证、推理文本、整段会话或无关文件。

- `planned`：计划参与，还没执行。
- `in_progress`：正在处理；视频提交、排队和等待远端结果仍属此状态。
- `completed`：该阶段交付物已检查，注明实际完成范围；一集完成不能写成整部完成。
- `blocked`：说明缺口和影响范围，保留已完成工作。
- `cancelled`：用户取消的工作。

`artifacts` 只传项目相对文件路径和实际远端任务引用，例如 `deliverables/EP02.md`、`jubian:499887`；先核对文件/任务，再引用。不传绝对磁盘路径、带令牌 URL 或只存在于计划里的文件。完成状态来自 Muse 的阶段汇报，工具保存并读回记录，不替代产物审核。尚无产物时可以传空数组，正文如实说明。

工具返回 `status:"synced"` 和 `verified_readback:true` 后才称云端项目记录已更新。`partial` 表示参与详情已保存、项目概览未同步；按原项目/阶段 ID 重试。网络失败或工具不可用时保留本地记录，说明待同步，恢复后核对当前账号再补传。不能把本地保存当作云端入库成功。

## 用户查看

用 `muse_kb_wiki_project_portfolio({})` 分页列出参与项目和各阶段状态，按 `next_start` 读完；再传项目列表返回的 `project_key` 查看具体参与内容和产物引用。普通登录查看本人记录；经部署单独授权的组合管理员可汇总所有启用账号，按返回的 `owner.id` 传 `account_id` 筛选。工具返回 `access` 说明本次权限，普通用户不得通过切换 ID 读取别人项目。组合查询只返回参与记录，不返回原始资料、会话或其他私人 Wiki；完成状态仍是阶段汇报，不是独立成片验收。

本人也可用 `muse_kb_wiki_directory({scope:"private",folder:"projects"})` 浏览项目概览，用 `muse_kb_wiki_read` 读取。概览最多展示 50 条链接，完整参与详情在它给出的 `project-contributions/muse-<project_key>` 目录，继续分页浏览。共享知识库向所有 Muse 用户开放，不会让用户项目公开；参与记录可由本人和指定组合管理员查看。

标准、PTC、创造、编辑和短剧模式按此流程使用工具。极简模式或自定义模式未暴露 Wiki 工具时只留下本地待同步记录，明确尚未入库；切回具备 Wiki 工具的模式后补同步。
