# 创作预设中的市场 Skill 版本

[English](README.md) | 中文

已发布的 Headless 配置加载实际创作预设、隔离的 Skill 注册表、创作适配器及工具策略。夹具刻意选择不在创作内置允许列表中的 Skill，仅通过显式选中的市场发行包提供它。主 Agent 加载版本一。在下一次模型请求的屏障处，外部夹具操作者创建空白创作 Agent，将实际激活默认值切换为版本二，再启动该空白 Agent 及新建的创作 Agent。两者均加载版本二；主 Agent 随后再次加载版本一。

四次实际 tools.skill 分派均保留不变的创作守卫。每个完整的类型化 Skill 结果都在其所属 Session 中进入下一次模型请求。夹具检查三个必读绑定事件、投影、精确归档标识、原始参考资源字节、目录元数据及 muse-creation 提供器结果。独立工作区凭据记录三、二、二次模型请求。没有夹具工具绕过策略，也不执行资源或供应商请求。
