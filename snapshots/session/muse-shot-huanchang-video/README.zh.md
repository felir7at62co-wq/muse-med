# 欢畅视频选择与分镜检查

[English](README.md) | 中文

此手写、无密钥场景通过发布的 Headless 配置运行真实 `drama_shot compile` 工具。只有模型响应和账号目录传输使用夹具。目录采用已记录的 `FZ_HUAN_CHANG` 行，配置默认值为 `doubao-seedance-2.5`、480p。

场景核对完整持久化输出、请求头侧车和最终工作区。检查报告须保留精确型号与渠道、标准 93 及 30 秒上限；原文 20 秒镜头保持完整，加自然收束后形成 21 秒包。建议式编译写出检查报告和逐字相同的原文副本，不写正式生成包，也不提交媒体生成。人物身份歧义仍列为警告，不虚构资产匹配。

工作区预期仅展开已声明的原文、资产清单和两个检查文件路径；其他报告值及全部工作区文件保持完整比较。此场景不验证收费提供方响应、已安装桌面应用或生成视频质量。
