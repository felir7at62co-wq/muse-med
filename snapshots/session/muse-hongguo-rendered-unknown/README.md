English | [中文](README.zh.md)

Valid zero and supported unit counts remain known, and verified card identities and ranks are preserved.

The native replay provider derives the assistant script from the selected canonical Session; fixture code supplies no model responses or business results. The recorded final reply reports unknown values rather than inventing counts.

A strict fixture transport replaces only the expected public-page request. No real website, account, paid model, ASR or generation service is contacted. A fixture-only package-root override supports an isolated original-parser negative control without modifying shipping source or the scenario. These checks establish parser and model-input behavior, not live website availability or real-model compliance.
