# 保留渲染榜单中的未知指标

[English](README.md) | 中文

本无密钥 Headless 场景使用实际注册的红果榜单工具、生产客户端和解析器读取合成的渲染 HTML。带负号、指数、不支持前缀及非数值的指标保留完整可见 `raw` 原文，数值为 null，原因为 `unparseable`。有效零值及支持的单位数仍为已知，已核验的卡片身份和排名保持不变。

夹具核对实际工具结果及下一次模型请求。分页覆盖可以完整，指标覆盖仍不完整。原生回放服务商从选定的 canonical Session 派生助手脚本，夹具代码不提供模型响应或业务结果。录制的最终回复报告未知值，不编造计数。

严格的夹具传输只替代预期的公开页面请求，不访问真实网站、账号、付费模型、ASR 或生成服务。仅供夹具使用的包根目录覆盖项支持隔离的原解析器负向对照，不修改交付源码或本场景。这些检查验证解析器和模型输入行为，不代表实站可用性或真实模型始终遵守规则。
