# 普通改稿措辞与交付依据

[English](README.md) | 中文

本无密钥 Headless 场景通过“修改下剧本”验证实际的稿件交付规则。仅对最终文件进行一致的内部审校时，已复核交付须返回 `MANUSCRIPT_DELIVERY_BASELINE_REQUIRED`。第二次原生审校以所选原稿为 `current`、不同路径的最终稿为 `candidate` 进行对照，再登记并交付实际保存的文件。

场景通过只读包装复用已有的改稿依据夹具。夹具回放编写的模型响应，并核对完整真人要求、已审材料、交付标签、回执及完整工作区。请求先进行规划，再通过明确续接继续处理。保存的候选采用 Markdown；本场景检查改稿保护，不验证 Word 导出或创作品质。

随产品提供的 Headless 配置使用生产工具和稿件服务，录制模型服务商不会回退到真实 API。已有会话输入、预期输出和归一化保持不变，新写入器预期仅属于本场景。
