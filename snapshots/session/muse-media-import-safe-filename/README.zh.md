# 原样导入安全清单文件名

[English](README.md) | 中文

本无密钥 Headless 场景在归属明确的云端任务清单中返回 `video (1).mp4`。改写后的别名不属于清单，会收到 `not-found`，且不读取文件字节。按原始名称导入时，生产账号客户端和受管辅助进程核对字节数、SHA-256、实际 FFprobe 元数据及 FFmpeg 完整解码，发布文件和来源回执后，模型才进行展示。

夹具核对准确的编码请求地址、一次认证文件读取、未变化的发布字节、完整解码证据，以及仅含媒体文件与回执的目录。完整工作区预期保留带空格和括号的路径；适配器只展开这条明确选定的路径。已有场景输入、输出和归一化保持不变。

模型服务商回放编写的响应，由夹具拥有的本地回环服务代替中央账号网关。视频来自已有合成夹具，不执行真实平台下载、生成、ASR 或云端写入。仅供夹具使用的构建库覆盖项支持隔离的原校验规则负向对照，不修改交付库。这些检查验证本地导入行为，不代表生产部署或创作品质。
