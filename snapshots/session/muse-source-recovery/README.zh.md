# 来源恢复快照

[English](README.md) | 中文

此无密钥场景使用固定本地文本、普通 `read` 工具、工具结果裁剪器、当前会话的 `source_recover` 工具，以及普通 `write` 和 `present` 调用。它检查恢复页面能否重组已记录的结果，并确认没有新增系统提示词段落。

恢复功能只覆盖成功的普通 `read` 事件。它不能恢复 shell 或 PTC 输出、图像内容，或原始读取时已省略的文字。

独立期望值依据已提交的来源字节和规范化工作区路径校验完整读取结果、裁剪、恢复索引、分页文本、Unicode 长度、哈希和 token 计价。重放会完整比较其他会话记录。
