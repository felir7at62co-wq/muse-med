# Local Skill publication through PTC

English | [中文](README.zh.md)

The shipped Headless PTC profile runs the [Native lifecycle](../muse-skill-market-local/README.md) through eight actual tools.market_local dispatches. Each successful program prints the complete service result. The corrupt-import program catches the actual ToolCallError and prints its complete public name, toolName and message; its message retains every public RemoteError field from the real service failure. The logged nested dispatch remains an error, and the following programs continue with the original archive.

The fixture observes the full logged program output in each subsequent model request and counts eight dispatch starts and settlements. Its independent workspace proof checks the same original resource bytes, archive SHA roundtrip, disabled installation identity, rejected-import storage preservation and record removal as the Native case. No error stack normalization or cloud service is required.
