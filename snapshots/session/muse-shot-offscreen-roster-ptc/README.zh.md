# 通过 PTC 检查画外名单

[English](README.md) | 中文

本场景是[原生场景](../muse-shot-offscreen-roster/README.zh.md)的相邻场景，选择随包 PTC 执行器。一次 `run_code` 调用等待生产 `tools.drama_shot` 的 advisory 编译结果，并打印完整 JSON 报告。共享观察器检查实际派发、保存的检查报告、源文件字节、保留的台词与身份，以及下一次模型请求。整个人物位于画外产生提示；可见人物的内心声音和局部可见不产生提示。工作区凭据记录相同观察事实。不执行生成或媒体审查。
