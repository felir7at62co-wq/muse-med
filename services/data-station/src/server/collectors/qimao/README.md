# 七猫公开榜单采集器

`collectQimao()` 默认读取男女频道的大热、新书、完结日/月榜，以及收藏、更新榜，共十六个官方榜单。每榜先核对官网首屏，再按平台声明的总数读取完整公开分页；当前允许最多一百名，每页二十条。可用 `channels`、`boards` 和 `periods` 缩小范围；收藏、更新没有月榜。不是七猫全平台作品库，不把分类书库排序当作官方榜单。

保留已有十二个榜单名称和历史：原“新书榜”“完结榜”没有周期后缀时表示日榜，新增月榜使用“· 月榜”后缀。大热榜继续明确标注“· 日榜”或“· 月榜”。收藏榜按收藏总数排序，更新榜按三十天内更新总字数排序，不能称为每日收藏数或当天更新榜。

## 来源核对与分页

每个榜单先读取固定的 `/paihang/{channel}/{board}/{period}/` HTML，检查频道、榜型、日/月 active 标签、官方名次连续性和规范作品 ID。随后读取官网使用的 `/qimaoapi/api/rank/book-list` JSON，第一页全部作品 ID 必须与所选 HTML 首屏逐项相等；接口中的 `rank_type` 固定为大热 1、新书 2、完结 3、收藏 4、更新 6，`date_type` 为日 1/月 2。

HTML 声明的总数、每页数量和月份必须与每个 JSON 页一致。后页请求固定同一平台月份；页码必须回显所请求页，条目数必须覆盖这一页的全部位置，整榜不能重复作品 ID。公开 API 没有单独的排名字段，名次采用已通过官网浏览器验证的展示规则 `(page - 1) * page_size + index + 1`，不按本库热度重排或推算。日榜请求也保留官网的默认月份参数，该参数不代表作品更新月份或日榜统计截止日；月榜的实际月份写入批次覆盖记录。收藏和更新榜没有月份，按来源保留为空，不填入本机月份。

任何一个页面访问、解析或验证失败都拒绝整个批次，由调用方保留上次成功数据。较短的合法榜单按平台声明的总数收录，未完成的分页不能作为完整榜发布。没有来源的历史不补造。

## 请求与字段

只访问固定七猫官网的公开 HTTPS 元数据地址，不发送账号 Cookie，不跟随重定向，不执行脚本，不访问章节正文。相邻元数据读取默认间隔一秒，请求时限和响应字节数均有上限。严格 HTTP 读取优先；仅已知 HTTP 头或 Content-Length 解析异常允许请求级兼容读取，继续验证 TLS、固定域名和路径、对应 HTML/JSON Content-Type、身份编码、Content-Length、完整结束及字节数。Node 将折叠头报成无错误码的 `HTTPParserError` 时，仅确认特定空白头错误且包含观测到的 CSP/X-Frame-Options 折叠头才允许兼容；网络、TLS、403/429 和其他解析异常不触发兼容。兼容请求属于同一次元数据读取，覆盖记录的读取次数不等于底层 HTTP 请求总数。

作品 ID 始终为字符串。封面、作者、类别、状态、字数、简介和作品最近更新时间来自对应规范 ID 的公开数据，`sourceUpdatedAt` 保留来源的作品更新时间，不冒充榜单统计截止日。大热、新书、完结的 `number + unit` 解释为热度；收藏、更新接口里的 `number` 是名次，不能转换为热度或收藏总数。累计人气值、阅读次数、在读人数和作品发布时间没有取得时保持 `null`，不以其他指标替代。不同榜单保留独立观察。

## 独立书库发现

`createQimaoDiscovery()` 逐页读取官网书库，与完整榜单刷新分别运行。每周期回访全部书库的点击排序和最近更新首页；从页面真实 `categoryList` 发现男生、女生原创小说的二级分类，出版分类不映射为原创小说。历史分类及后页使用稳定任务键，已处理任务不因新周期重新排队；最近更新首页按 `latestCategoriesPerCycle` 轮转分类，默认每周期八个，周期任务优先于历史待办。下一页仅在当前页通过验证并由调用方成功发布后才加入队列。

书库路径严格按官网字段顺序生成，仅开放全部书库或已发现分类的点击、最近更新排序及有界页码，不接受任意来源、其他筛选组合或章节 URL。沿用榜单读取器的 TLS、请求时限、响应字节上限、取消、禁止重定向和请求级兼容头检查。现有特殊受限路径保持兼容。

序列化 Nuxt 状态使用 Acorn 静态解析，只接受单一赋值中的单个返回对象、数组、字面量、原始值别名和负数字面量；不运行页面脚本，不接受额外语句、任意调用、成员读取、计算属性、展开、访问器或原型属性。书库筛选和排序必须回显请求参数，分页状态与页面按钮一致；每页十五条，末页可以较短。作品 ID、规范链接、书名、作者、类别、状态、字数和更新日期须与同页 DOM 逐项匹配；状态文本先按浏览器显示方式合并连续空白、去掉首尾空白再比较，因为官网状态中的书名和作者可能含连续或尾随空格，而页面显示为单个空格。入库保存显示形式的书名和作者；空白以外的差异仍拒绝。核验失败、访问拒绝和重复页不在本轮重试，只有网络错误、超时与服务端错误使用队列重试次数。重复页保留当前任务等待核对，不跳过游标。

保留 `14124273_0` 等完整字符串 ID。作品最近更新时间取来源 `update_time_txt`，缺失时保留页面日期原文，不推算作品发布日期。书库的列表位置不写成名次，`board` 为空，`rank` 及未独立提供的热度、人气、阅读次数、在读人数均为空。全书库显示的 9,990 部只是当前可见窗口；分类彼此重叠，覆盖记录只说明已核对页面和来源声明，不表示七猫全库完成。目录观察由调用方按既有发布规则保存，不覆盖已保存榜单的指标及其原观测时间。
