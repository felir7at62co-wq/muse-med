# 抖音公开作品监测

`collectDouyin()` 访问抖音官方 `https://jingxuan.douyin.com/m/video/<字符串视频ID>`，读取 HTML 内的 JSON 数据，不执行远程脚本、不读取浏览器 Cookie、不登录账号、不调用现有 Muse 的桌面浏览器桥、不使用第三方数据站或收费解析服务。

当前实现是所选短剧创作者的公开近期视频窗口或指定视频监测，不是抖音全站短剧热榜、剧集库或全集采集。记录以单条视频为单位，标题和简介保留原始视频文案；榜单名称明确为“公开短剧作品监测（视频粒度，非榜单）”，排名为空。播放和点赞来自官方精选页的视频详情，明确标为“精选页播放”和“精选页点赞”，不视作全抖音或整部剧汇总；评论、收藏、分享和全集集数未由该来源提供时保留未知。

初次预设包含十三个创作者窗口和四个指定视频，涵盖原有八位作者及新增真人、AI 连载与合集，见[来源核验说明](SOURCES.md)。剧情段子、游戏或教学账号不为凑数导入；视觉形式不明的候选也不自动标为 3D 或仿真人。创作者模式每次读取公开近期窗口，定位视频不自动入库；指定视频模式只采该视频，不宣称已取得作者全部作品。每条详情核对身份；已绑定 ID 时同 ID 改昵称不误判，错 ID 则拒绝，没有稳定作者 ID 的合集只作指定视频监测。

原八个作者默认每次最多八条，新增作者窗口最多十条，指定视频为一条；管理员可设置一至二十条，总来源最多三十二个，实际窗口可能更短。关键词按具体来源配置：例如《安宁大厦生存守则》正片标题含“直播间”，保留剧名筛选并排除制作教程，避免把剧情中的直播误判为账号直播。相同定位视频可以分别用于作者窗口和指定合集，配置 ID 包含模式，作品入库仍按平台视频 ID 去重。

正式入口每次从本项目独立数据库读取管理员启用的来源快照，支持指定视频和作者窗口，空列表与禁用配置不回退预设。验证仅采一条样本、不入库；新增和改变身份/筛选条件必须验证后绑定作者 ID。任一来源访问或身份失败使本批次失败，保留最后成功数据；可在管理页停用该来源后重试。覆盖说明列出前八个来源，其余合计，保持在持久化字段长度内。

`video_plays` 是精选页的真实视频播放口径，网页可按其做“本库播放排序”，未知排后。排序不生成平台排名，`rank` 和 `rankChange` 保持 `null`；原始发布时间含年份展示，避免较早视频被误解为今日热榜。当前未启动 DTK 服务，没有宣称主站互动字段或完整合集已接通。

请求只发送固定官方域名及构造的视频路径，使用普通移动浏览器 User-Agent，不携带登录凭据，不跟随重定向。响应有超时和大小上限，默认相邻请求间隔 800 毫秒。访问验证、空页、ID 不匹配、作者不匹配或任一页面失败会使整个批次失败，调用方保留上次成功数据，不把失败变成零作品。

## 当前访问边界

2026-11-13，普通 HTTP 和全新独立 Chrome 访问 `www.douyin.com` 及频道入口出现验证码页；`iesdouyin.com` 分享页可返回 JSON 壳但 `video_layout` 为空，正文提示在 App 观看，因此没有把这些页面当作成功来源。官方开放平台剧情榜需要申请权限和 client token，其口径也不是短剧全站榜，没有替代接入。

若以后需要更大范围的官方账号、合集或搜索，应单独准备本项目 `.data/douyin-browser` 的浏览器实例，由用户完成平台要求的登录或访问验证；不得复用现有 Muse/Chrome 用户数据，不得自动处理验证码。当前采集器无需该浏览器实例。
