《吸血鬼教授把我挂科了》第八集文案声明“大结局”，此次已逐条读取同作者第一至八集。该结果是素材覆盖证据，不是系统自动认定剧目完整：当前库仍保存独立视频，没有自动归组、校对遗漏、转写或生成续集。其他合集只表示文案注明的集数范围，不能推断整部剧完结。

Fel 的本人文案注明 AI 真人，云笺的本人文案含 3D 动画标签；其他创作者的 AI 声明也不自动等同于仿真人分类。此次未加入视觉形式不明、可能包含 2D 的福仔候选，未通过封面猜测其他视频的表现形式。网页表现形式分类尚未实现。

所有来源按官方页面返回的视频 ID、作者身份、原始发布时间及观测时间保存。播放、点赞为精选页单条视频口径；合集与分集重叠，不能相加声称整剧播放量。公开窗口不是完整账号历史，也不是全站榜单；后续窗口更新后需要按同样条件重新核验。没有稳定作者 ID 的两个指定视频以视频 ID 和作者名称校验，不延伸为账号采集能力。

“她见四季”的九条剧情在独立全量样本验证时成功，随后实际管理接口保存时一条详情返回 HTTP 404，后续只读核对又恢复 HTTP 200，原因尚未确定。本次没有启用或加入预设，保留为待复核来源；不把失败归为永久下架，也不通过忽略失败来发布成功批次。
